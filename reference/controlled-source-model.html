受控源与放大器二端口模型

一页纸版本：四种受控源的判别、单位、典型器件，以及放大器增益为什么总被“分压”砍两刀。打印出来夹在教材里。

B

类型关系式系数单位典型器件 / 场景

C

放大器二端口模型

输入端看进去是 Ri；输出端是受控电压源 AVvi 串联 Ro。

A = vo/vs = [Ri/(Rs+Ri)] · AV · [RL/(Ro+RL)] 输入分压 × 本征增益（开路增益）× 输出分压
量怎么读理想方向
R_i输入端口看进去的等效电阻越大，从信号源拿到的电压越多
A_V输出开路时的本征电压增益由器件和电路结构决定
R_o输出端口看进去的等效电阻越小，带负载后增益掉得越少
D

三个常见坑

  1. 把受控源当独立源置零。求戴维南/诺顿等效电阻时，独立源可以置零，受控源必须保留；用外加测试源求 vt/it（§1.2.3，书 p.9 / PDF p.20）。
  2. 只看系数不看单位。单位已经暴露类型；写关系式前先把单位写出来，能避免一半的方向错误。
  3. 把本征增益当实测增益。只要信号源有内阻、输出接负载，就一定有两次分压；先算 Ri、Ro，再算增益。
E

30 秒自测

1. 为什么 BJT 是 CCCS，而 MOS 是 VCCS？

BJT 的集电极电流由基极电流控制（i_C = β i_B）；MOS 的漏极电流由栅源电压控制（i_D = f(v_GS)）。输出都是电流，控制量不同，所以一个是 CCCS，一个是 VCCS。

2. R_s = 2 kΩ，R_i = 8 kΩ，A_V = 50，R_o = 2 kΩ，R_L = 8 kΩ，总增益是多少？

0.8 × 50 × 0.8 = 32。两次分压各 0.8；如果直接用 50，会高估 56%。

3. 求含受控源电路的戴维南电阻，第一步做什么？

把独立源置零，但保留受控源；在端口外加测试源 vt，求出流入的 it，则 R_th = v_t / i_t。不能直接把受控源短路或开路。

F

术语卡

术语一句话定义
独立源值不受电路其他部分控制，自己决定输出。
受控源值由另一条支路的电压或电流控制；分 VCVS、VCCS、CCVS、CCCS 四种。
跨导 gm输出电流与输入电压之比，单位 S（A/V）。
跨阻 rm输出电压与输入电流之比，单位 Ω（V/A）。
输入电阻 Ri从输入端口看进去的等效电阻；越大，从信号源分到的电压越多。
输出电阻 Ro从输出端口看进去的等效电阻；越小，带负载后增益掉得越少。
本征增益 AV输出开路、无负载时的电压增益，是受控源的系数，不是实测增益。
加载效应源内阻与负载分别对输入、输出电压分压，使实测增益低于本征增益。
