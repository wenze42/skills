Lesson 0005 — 随机过程基本概念

概率论 · 随机过程入门 · 约 35 分钟

从单个到一族——思维方式的跃迁 前三课我们讨论的都是单个随机变量 X：它取什么值、概率分布是什么。 而随机过程是无穷多个随机变量排成一排：X(t) 对每个时刻 t 都是一个随机变量。 这是从"静态随机"到"动态随机"的关键一步。

一、随机过程的定义

{ X(t), t ∈ T } 是一个随机过程，指的是：对每个参数 t ∈ T， X(t) 都是一个定义在同一概率空间上的随机变量。

这里有两个核心集合必须分清：

记号名称含义
T（参数集） 时间轴 离散 T = {0, ±1, ±2, …} 或连续 T = [0, ∞)
S（状态空间） X(t) 能取的值域 可数集（离散状态）或实数域 ℝ（连续状态）

直观上，随机过程就是"随时间演化的随机系统"。比如：

  • 某只股票每天的收盘价——参数集 T 离散（交易日），状态空间 S 连续（价格）
  • 布朗运动中某个粒子的位置——参数集 T 连续，状态空间 S 是 ℝ³
  • 医院急诊室的就诊人数——状态空间 S 是 {0, 1, 2, …}（离散）

样本函数（样本曲线 / 轨道）

固定一个样本点 ω（即一次完整的物理实现），让 t 在 T 上变化， 你会得到一个确定的函数 x(t) = X(t, ω)——这就是样本函数。 一次硬币抛掷序列、一次金融市场的价格轨迹、一个粒子从起点开始的具体路径—— 都是各自随机过程的一条样本函数。

随机过程本身是"抽象的概率集合"，但样本函数才是你在现实中看到的东西。 同一时刻可以画出许多条不同的样本函数——它们叠加在一起，就构成了过程的完整图景。

关键洞察 任意固定时刻 t₀，X(t₀) 是一个普通的随机变量； 固定样本点 ω，X(·, ω) 是一条普通的确定函数。 随机过程就是"时间轴"和"随机性"两个维度的结合。

二、参数集 × 状态空间——四类随机过程

离散状态 S（可数）连续状态 S（实数域）
离散参数 T 离散时间离散状态链
例：抛掷硬币序列		 时间序列
例：每日气温记录
连续参数 T 连续时间计数过程
例：电话总机来话数		 连续参数连续状态过程
例：布朗运动、股票价格

这个分类穷尽所有。考研里高频出现的，是离散参数链和泊松/维纳这两个连续参数特例。

例子 1：抛掷硬币——离散状态离散参数

抛掷一枚均匀硬币，设正面 X=1，反面 X=0。每次抛出后观测结果。 参数集 T = {0, 1, 2, …}（抛掷序号），状态空间 S = {0, 1}。

例子 2：随机相位正弦波——连续状态连续参数

设 X(t) = A·cos(ωt + Θ)，其中 A、ω 为常数，Θ ~ U(0, 2π)（均匀分布）。 对每个固定的 t，X(t) 是 Θ 的函数，因此是随机变量。但参数集 T = ℝ 连续， 状态空间 S = [-A, A] 也是连续的。三条样本函数（三种不同的 Θ 值）叠在一起就构成了过程。

均值函数 μX(t) = E[X(t)] = 0
自相关函数 RX(s, t) = E[A cos(ωs+Θ) · A cos(ωt+Θ)] = (A²/2) cos ω(t − s)

这个例子很重要——它告诉你 过程的统计性质可以通过有限维分布完全确定。

三、有限维分布函数族——随机过程的"全息照相"

单个随机变量用分布函数 F(x) = P(X ≤ x) 描述。对于随机过程，我们需要描述它在 多个时刻的联合行为。为此定义：

对任意 n ≥ 1 和 t₁, t₂, …, tₙ ∈ T，n 维分布函数
F(t₁, …, tₙ; x₁, …, xₙ) = P( X(t₁) ≤ x₁, …, X(tₙ) ≤ xₙ )

有限维分布函数族 { F(t₁, …, tₙ; x₁, …, xₙ) } 当 n 取遍所有自然数、 t₁…tₙ 取遍 T 中所有可能值时，这个族完全刻画了随机过程的概率性质。 它比均值、方差、相关函数包含更多信息——后者只是它的特殊边缘。

一致条件（Kolmogorov 相容性定理） 有限维分布族必须满足两个一致性：① 对任意排列 σ，F 的变量可以重排； ② 对任意 m < n，m 维分布是 n 维分布的边缘（令多余的 x → ∞）。 Kolmogorov 定理说：只要满足这两个条件，就一定存在一个随机过程以这些函数为有限维分布。 这是随机过程理论的存在性基础，考研中不会直接考，但你应当知道它是一切推导的前提。

四、数字特征——均值、方差、自相关、自协方差

数字特征是有限维分布族的"压缩表示"。最重要的是四个函数，它们都是关于参数的函数， 而不是常数：

名称记号定义
均值函数 μX(t) E[X(t)]
方差函数 DX(t) E[(X(t) − μX(t))²]
自相关函数 RX(s, t) E[X(s) · X(t)]
自协方差函数 CX(s, t) Cov(X(s), X(t)) = RX(s, t) − μX(s)μX(t)

注意几个常用推论：

  • 方差函数是自协方差的特例：DX(t) = CX(t, t)
  • 自相关函数总是对称的：RX(s, t) = RX(t, s)
  • CX(s, t) = 0 ⟺ X(s) 与 X(t) 不相关（注意：不相关 ≠ 独立，但正态过程两者等价）

五、两类常用过程

5.1 二阶矩过程

若对所有 t ∈ T，E[X(t)²] < ∞（即二阶矩有限），则称 {X(t)} 为二阶矩过程。 这类过程的均值函数和自相关函数一定存在，是随机过程分析中最基础的假设前提。

5.2 正态过程

若对任意 n ≥ 1 和 t₁, …, tₙ ∈ T，(X(t₁), …, X(tₙ)) 的联合分布是n 维正态分布， 则称 {X(t)} 为正态过程（也叫高斯过程）。

正态过程的极简定理 正态过程完全由均值函数 μX(t) 和自协方差函数 CX(s, t) 决定。 这是正态族最深刻的性质：联合正态 = 均值向量 + 协方差矩阵。 后面的维纳过程就是一个标准正态过程——抓住这两个函数就抓住了一切。

5.3 独立增量过程

若对任意一组不重叠的区间 (s₁, t₁], (s₂, t₂], …, (sₙ, tₙ]（即 tₖ ≤ sₖ₊₁）， 对应的增量 X(t₁) − X(s₁), X(t₂) − X(s₂), …, X(tₙ) − X(sₙ) 相互独立， 则称 {X(t)} 为独立增量过程。

若进一步增量的分布只依赖于区间长度而与起点无关， 即 X(t) − X(s) 与 X(t+h) − X(s+h) 同分布（∀ h > 0）， 则称过程是时齐的。 下一课的泊松过程和维纳过程都满足独立增量 + 时齐——这两条公理非常强。

过程类型核心特征典型例子
独立增量过程 任意不重叠区间的增量相互独立 泊松过程、维纳过程
时齐过程 统计性质不随时间平移而变 时齐泊松、时齐马尔可夫链
平稳过程（宽平稳） 均值函数为常数，自相关只与 s−t 有关 随机相位正弦波、白噪声
三个概念的层次关系 时齐性 ⊂ 宽平稳（二阶矩有限时）；独立增量 + 时齐 ⇒ 宽平稳（零均值时）。 但独立增量过程不一定是平稳的，因为均值函数可能随 t 增长（如泊松过程 E[N(t)] = λt）。
