Lesson 0002 — 方差分析基础（单因素）

概率论 · 数理统计 · 约 20 分钟

为什么需要方差分析

在 Lesson 0001 的诊断中我们见过 t 检验——它能检验两个总体均值是否相等。 但如果你要比较 三个或更多配方的平均产量呢？

t 检验的多重比较问题 假设有 r=5 组，两两配对要做 C(5,2)=10 次 t 检验。单次检验 α=0.05， 10 次下来整体犯第一类错误的概率 ≈ 1−(1−0.05)¹⁰ ≈ 0.40。 方差分析一次性检验所有均值是否相等，把整体 α 控制在 0.05。

方差分析（ANOVA, ANalysis Of VAriance）的零假设与备择假设：

H₀ : μ₁ = μ₂ = … = μᵣ   （所有组均值相等）
H₁ : μ₁, μ₂, …, μᵣ 中至少有两个不相等

名字里的"方差"不是因为我们检验方差，而是因为检验统计量 F 来自方差的比值。

单因素方差分析模型

只有一个因素（比如"配方"），有 r 个水平（比如 3 种配方），每个水平下做若干次试验：

xᵢⱼ = μ + αᵢ + εᵢⱼ，  εᵢⱼ ~ N(0, σ²) 独立同分布

含义：每个观察值等于总均值 μ加上第 i 组的效应 αᵢ（满足 Σ αᵢ = 0）， 再加上随机误差。模型假设所有组的方差都是 σ²——这是"方差齐性"的前提。

平方和分解

方差分析的核心是平方和分解公式：

S_T = S_A + S_E

其中：

符号名称公式自由度
S_T 总平方和 Σᵢ Σⱼ (xᵢⱼ − x̄)² n − 1
S_A 因素平方和（组间） Σᵢ nᵢ (x̄ᵢ − x̄)² r − 1
S_E 误差平方和（组内） Σᵢ Σⱼ (xᵢⱼ − x̄ᵢ)² n − r

x̄ 是总样本均值，x̄ᵢ 是第 i 组的样本均值，nᵢ 是第 i 组样本量，n = Σ nᵢ 是总样本量， r 是组数。

直觉 S_T 衡量所有数据点的离散程度。它被拆成两部分： S_A 衡量各组均值之间的差异（因素效应）， S_E 衡量各组内部的随机波动（纯噪声）。 如果 S_A 比 S_E 大很多，因素效应就显著。

均方与 F 检验

把平方和除以自由度，得到"均方"（Mean Square）：

MS_A = S_A / (r − 1)，   MS_E = S_E / (n − r)

在 H₀ 成立时，MS_A 和 MS_E 都是 σ² 的无偏估计，它们的比值服从 F 分布：

F = MS_A / MS_E  ~  F(r − 1, n − r)

检验规则：若 F > F_α(r − 1, n − r)，则拒绝 H₀。

完整数值例子

某化工厂研究三种配方的某种化工产品的得率。每种配方做 5 次独立试验，数据如下：

配方得率（%）均值 x̄ᵢ
A2527262824130/5 = 26.0
B3129323028150/5 = 30.0
C2426252723125/5 = 25.0

已知 r=3，n₁=n₂=n₃=5，总样本量 n=15。总均值：

x̄ = (130 + 150 + 125) / 15 = 405 / 15 = 27.0

手算平方和

第一步：总平方和 S_T，用简化公式 S_T = ΣΣ xᵢⱼ² − T²/(n) 更快：

ΣΣ xᵢⱼ² = 25²+27²+26²+28²+24² + 31²+29²+32²+30²+28² + 24²+26²+25²+27²+23²
= (625+729+676+784+576) + (961+841+1024+900+784) + (576+676+625+729+529)
= 3390 + 4510 + 3135 = 11035

S_T = 11035 − 405²/15 = 11035 − 164025/15 = 11035 − 10935 = 100.0

自由度 df_T = 15 − 1 = 14。

第二步：因素平方和 S_A，用简化公式 S_A = Σ Tᵢ²/nᵢ − T²/(n)：

Tᵢ 是各组数据之和：T₁=130，T₂=150，T₃=125。

S_A = 130²/5 + 150²/5 + 125²/5 − 10935
  = 16900/5 + 22500/5 + 15625/5 − 10935
  = 3380 + 4500 + 3125 − 10935 = 70.0

自由度 df_A = 3 − 1 = 2。

第三步：误差平方和 S_E：

S_E = S_T − S_A = 100 − 70 = 30.0

自由度 df_E = n − r = 15 − 3 = 12。

也可以直接验证 S_E = ΣΣ(xᵢⱼ − x̄ᵢ)²：

  • 配方 A：(25−26)²+(27−26)²+(26−26)²+(28−26)²+(24−26)² = 1+1+0+4+4 = 10
  • 配方 B：(31−30)²+(29−30)²+(32−30)²+(30−30)²+(28−30)² = 1+1+4+0+4 = 10
  • 配方 C：(24−25)²+(26−25)²+(25−25)²+(27−25)²+(23−25)² = 1+1+0+4+4 = 10

合计 S_E = 10 + 10 + 10 = 30.0 ✓ 和间接计算一致。

F 检验结论

取显著性水平 α = 0.05，查 F 分布表得临界值 F₀.₀₅(2, 12) ≈ 3.89。
计算得到的 F = 14.0，远大于 3.89。

结论 拒绝 H₀。三种配方的平均得率存在显著差异（p ≈ 0.0009 < 0.05）。 配方 B（均值 30）优于配方 A 和 C。

公式速查

项目公式
总平方和S_T = ΣΣxᵢⱼ² − T²/n，其中 T = ΣΣxᵢⱼ
因素平方和S_A = Σᵢ Tᵢ²/nᵢ − T²/n，其中 Tᵢ = Σⱼxᵢⱼ
误差平方和S_E = S_T − S_A （或直接算 ΣΣ(xᵢⱼ−x̄ᵢ)²）
均方MS_A = S_A/(r−1)，MS_E = S_E/(n−r)
检验统计量F = MS_A / MS_E ~ F(r−1, n−r)
