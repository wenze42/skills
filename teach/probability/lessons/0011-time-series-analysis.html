Lesson 0011 — 时间序列分析初步

平稳过程实战 · 离散时间 · 约 30 分钟

从连续到离散：时间序列

前两课讲的是连续时间平稳过程 {X(t), t∈ℝ}。 但实际工作中——经济数据、股票价格、天气记录、网络流量——我们拿到的几乎都是 离散采样的数据：

{Xₜ, t ∈ ℤ} = {..., X₋₂, X₋₁, X₀, X₁, X₂, ...}

这就是时间序列（Time Series）——离散参数的随机过程。 它是平稳过程理论在数据科学中的主战场。

宽平稳时间序列

宽平稳的条件和连续情形完全一致，只是 t 变成了整数：

  1. 均值常数：E[Xₜ] = μ（不随 t 变化）
  2. 自相关仅依赖间隔：γₖ = Cov(Xₜ, Xₜ₊ₖ)（自协方差）
  3. 二阶矩存在：E[Xₜ²] < ∞

注意：在时间序列中，通常用 γₖ 表示自协方差， 用 ρₖ = γₖ / γ₀ 表示自相关系数（标准化后的版本，|ρₖ| ≤ 1）。

自相关函数的样本估计

各态历经性保证了：一条足够长的样本序列 {x₁, x₂, ..., x_T} 可以用来估计自相关系数：

ρ̂ₖ = [Σ_{t=1}^{T−k} (xₜ − x̄)(xₜ₊ₖ − x̄)] / [Σ_{t=1}^{T} (xₜ − x̄)²]

其中 x̄ = 1/T Σxₜ 是样本均值。这就是我们在 Python/R 中调用 acf() 函数时底层在做的事。

三大经典模型

时间序列分析的核心思想是：用简单的模型来拟合数据的相关结构。 最基本的三个模型是 AR、MA、ARMA——它们是 Box-Jenkins 方法的基石。

白噪声：所有模型的"原子"

首先定义白噪声作为基本构件：

εₜ ~ WN(0, σ²)，即 E[εₜ]=0，Var(εₜ)=σ²，Cov(εₜ, εₛ)=0（t≠s）

白噪声是"完全无记忆"的序列——每个时刻独立于其他时刻。 所有平稳过程都可以看作白噪声经过某种"滤波器"产生的。

自回归模型 AR(p)

定义

自回归（Autoregressive）的思想：当前值是过去若干期的线性组合， 加上一点白噪声"创新"：

Xₜ = c + φ₁Xₜ₋₁ + φ₂Xₜ₋₂ + ... + φₚXₜ₋ₚ + εₜ

其中： φ₁, ..., φₚ 是自回归系数， c 是常数项， εₜ 是白噪声（独立于 Xₜ₋₁, Xₜ₋₂, ...）。

平稳条件

AR(p) 平稳的充要条件是特征方程的所有根都在单位圆外：

1 − φ₁z − φ₂z² − ... − φₚzᵖ = 0 的所有根 zᵢ 满足 |zᵢ| > 1

对于最常见的 AR(1)，这个条件简化为 |φ₁| < 1——非常好记！

ACF 性质：拖尾

AR(p) 的自相关系数 ρₖ 是拖尾的——要么指数衰减， 要么正弦衰减（取决于特征根是实根还是复根），但永远不会"突然截断"。

AR(1) 的例子 设 Xₜ = 0.5 Xₜ₋₁ + εₜ（φ₁ = 0.5 < 1，平稳）。 自相关系数可以递推得到：ρₖ = 0.5ᵏ。 这是一个完美的指数衰减，永远不会降到 0，只是越来越小。
图 1: AR(1) 模型 Xₜ = 0.6Xₜ₋₁ + εₜ 的自相关系数 ρₖ = 0.6ᵏ，展示典型的拖尾特征

滑动平均模型 MA(q)

定义

滑动平均（Moving Average）的思想：当前值是当前及过去若干期的白噪声的线性组合：

Xₜ = c + εₜ + θ₁εₜ₋₁ + θ₂εₜ₋₂ + ... + θ_qεₜ₋q

MA 模型和 AR 模型的"因果方向"相反：AR 是"过去的 X 影响现在的 X"， MA 是"过去的噪声影响现在的 X"。

MA 模型总是平稳的

只要 q 是有限的，MA(q) 一定是平稳的。但它有一个新条件——可逆性：

1 + θ₁z + θ₂z² + ... + θ_qz^q = 0 的所有根 zᵢ 满足 |zᵢ| > 1

可逆性保证了 MA 模型可以"翻转"成一个 AR(∞) 模型，方便分析。

ACF 性质：截尾

MA(q) 的自相关系数有一个非常鲜明的特征——k > q 时 ρₖ = 0！ 只有前 q 个滞后有非零自相关，之后突然截断。

这是因为 Xₜ 只和 εₜ, εₜ₋₁, ..., εₜ₋q 有关，而白噪声不同时刻独立， 所以当间隔超过 q 后，两个变量之间完全没有公共的"噪声源"。

图 2: MA(2) 模型的自相关系数——在 k > 2 时突然截断为零，这是 MA 模型的标志性特征

ARMA(p, q)：两者的组合

把 AR 和 MA 组合起来，得到自回归滑动平均模型：

Xₜ = c + φ₁Xₜ₋₁ + ... + φₚXₜ₋ₚ + εₜ + θ₁εₜ₋₁ + ... + θ_qεₜ₋q

ARMA 结合了两者的优点：用较少的参数（p 和 q 都不大）就能灵活拟合各种相关结构。 它的 ACF 是混合的——既有 AR 部分的拖尾，又有 MA 部分的影响。

ARIMA(p, d, q)：处理非平稳

现实数据经常有趋势（比如 GDP 逐年增长），这时序列不是平稳的。 解决方法是先差分：

ΔXₜ = Xₜ − Xₜ₋₁

做了 d 次差分之后，如果差分后的序列是平稳的，就对它拟合 ARMA(p, q)—— 整体就是 ARIMA(p, d, q)。

怎么选 d？ 最常用的方法是ADF 检验（Augmented Dickey-Fuller）—— 一个假设检验，原假设"序列有单位根（非平稳）"。如果 p-value 很小（< 0.05）， 就拒绝原假设，认为序列平稳；否则继续差分。

ACF / PACF 图形识别

这是 Box-Jenkins 方法论的核心——用 ACF 和 PACF 图来识别模型阶数：

模型 ACF 特征 PACF 特征
AR(p) 拖尾（指数或正弦衰减） 截尾（k > p 时为 0）
MA(q) 截尾（k > q 时为 0） 拖尾（指数或正弦衰减）
ARMA(p,q) 拖尾 拖尾

PACF（偏自相关函数）衡量的是"剔除了中间变量影响后，Xₜ 和 Xₜ₊ₖ 的直接相关"。 AR 和 MA 在 ACF/PACF 上是对偶的关系——AR 的 PACF 截尾，MA 的 ACF 截尾。

模型选择实战流程

  1. 看图 + ADF 检验判断是否平稳 → 不平稳则差分（记录 d）
  2. 算 ACF 和 PACF 图
  3. 根据"截尾/拖尾"特征判断 AR 还是 MA，估计 p 或 q
  4. 拟合候选模型（AR(p)、MA(q)、ARMA(p,q)）
  5. 用 AIC/BIC 信息准则选择最优模型
  6. 残差检验：残差应该接近白噪声
AIC/BIC 准则 两个都是衡量模型"拟合好 + 参数不要太多"的权衡：
  • AIC（赤池信息准则）= 2k − 2ln(L)，k 是参数个数
  • BIC（贝叶斯信息准则）= k·ln(n) − 2ln(L)，n 是样本量
值越小越好。BIC 对参数个数惩罚更重，倾向选更简单的模型。
