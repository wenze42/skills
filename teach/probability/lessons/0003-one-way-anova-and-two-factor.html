Lesson 0003 — 双因素方差分析

概率论 · 数理统计 · 约 22 分钟

为什么要双因素

上一课我们只考虑一个因素。但现实中很多问题需要同时考虑两个因素：

  • 产品得率 = f(温度, 时间)
  • 农作物产量 = f(肥料, 水分)
  • 零件强度 = f(材料, 热处理工艺)

两个因素同时作用时，有一个新概念：交互作用。交互作用意味着"一个因素的效果依赖于另一个因素的水平"—— 不是简单叠加。

两种实验情形

情形一：无重复试验（等号意味着无交互检验）

每个 (i, j) 组合只有一个观察值 xᵢⱼ。模型：

xᵢⱼ = μ + αᵢ + βⱼ + εᵢⱼ，  εᵢⱼ ~ N(0, σ²) 独立

其中 αᵢ 是因素 A 的第 i 个水平效应，βⱼ 是因素 B 的第 j 个水平效应。这种模型没有交互项， 因为只做了一次试验，无法区分"交互作用"和"随机误差"。

情形二：等重复试验（可以检验交互作用）

每个 (i, j) 组合有 m ≥ 2 个观察值 xᵢⱼₖ（k = 1, 2, …, m）。模型：

xᵢⱼₖ = μ + αᵢ + βⱼ + (αβ)ᵢⱼ + εᵢⱼₖ

其中 (αβ)ᵢⱼ 就是 A 和 B 的交互作用。这是本课的重点——它最常见也最能体现方差分析的威力。

平方和分解扩展

等重复试验（m ≥ 2），总平方和被拆成四部分：

S_T = S_A + S_B + S_A×B + S_E
符号名称自由度
S_T总平方和 abm − 1
S_AA 因素平方和（主效应） a − 1
S_BB 因素平方和（主效应） b − 1
S_A×B交互作用平方和 (a − 1)(b − 1)
S_E误差平方和 ab(m − 1)

其中 a 是 A 因素的水平数，b 是 B 因素的水平数，m 是每个单元格的重复次数。

自由度验证 df_T = abm − 1 应该等于后面四项之和：
(a−1) + (b−1) + (a−1)(b−1) + ab(m−1) = a−1 + b−1 + ab−a−b+1 + abm−ab
= abm − 1 ✓

简化计算公式

定义几个和号：
Tᵢⱼ = Σₖ xᵢⱼₖ   （单元格 (i,j) 的和）
Tᵢ. = Σⱼ Tᵢⱼ   （A 因素第 i 水平的合计和）
T..ⱼ = Σᵢ Tᵢⱼ   （B 因素第 j 水平的合计和）
T... = Σᵢ Σⱼ Σₖ xᵢⱼₖ   （全部总和）

校正项 C = T...² / (abm)。各平方和：

S_T = ΣΣΣ xᵢⱼₖ² − C
S_A = (1/(bm)) Σᵢ Tᵢ.² − C
S_B = (1/(am)) Σⱼ T..ⱼ² − C
S_A×B = (1/m) ΣᵢΣⱼ Tᵢⱼ² − C − S_A − S_B
S_E = S_T − S_A − S_B − S_A×B

三个 F 检验

检验均方F 值零假设
A 的主效应 MS_A = S_A/(a−1) F_A = MS_A / MS_E H₀: α₁ = … = αₐ = 0
B 的主效应 MS_B = S_B/(b−1) F_B = MS_B / MS_E H₀: β₁ = … = β_b = 0
交互作用 MS_A×B = S_A×B/((a−1)(b−1)) F_A×B = MS_A×B / MS_E H₀: (αβ)ᵢⱼ ≡ 0

交互作用示意图

下图是经典的"交互作用图"：横轴是 B 因素的两个水平（短/长时间）， 两条线分别对应 A 因素的两个水平（中/高温）。纵轴是单元格均值。

左图：两条线几乎平行 → 无交互作用，A 的效果在两个 B 水平下差不多。
右图：两条线明显不平行（交叉或收敛）→ 存在交互作用。

完整数值例子

某化工试验，因素 A = 温度（a=2 水平：低温 / 高温）， 因素 B = 时间（b=2 水平：短 / 长）。每个 (温度, 时间) 组合做 m=3 次独立试验， 产品得率 (%) 如下：

B：短时间B：长时间合计 Tᵢ.
A：低温 10, 12, 14T₁₁ = 36 18, 20, 22T₁₂ = 60 T₁. = 96
A：高温 8, 10, 12T₂₁ = 30 22, 24, 26T₂₂ = 72 T₂. = 102
合计 T..ⱼ 66 132 T... = 198

数据核对：Σxᵢⱼₖ = 36+60+30+72 = 198 ✓。Σxᵢⱼₖ² = 3692。

手算平方和

校正项：C = T...²/(abm) = 198²/(2·2·3) = 39204/12 = 3267.0

总平方和 S_T：

S_T = ΣΣΣ x² − C = 3692 − 3267 = 425.0，  df_T = 11

A 因素平方和（温度）：

S_A = (1/(bm)) Σ Tᵢ.² − C = (96² + 102²)/(2·3) − 3267
  = (9216 + 10404)/6 − 3267 = 19620/6 − 3267 = 3270 − 3267 = 3.0，  df_A = 1

B 因素平方和（时间）：

S_B = (1/(am)) Σ T..ⱼ² − C = (66² + 132²)/(2·3) − 3267
  = (4356 + 17424)/6 − 3267 = 21780/6 − 3267 = 3630 − 3267 = 363.0，  df_B = 1

交互作用平方和 S_A×B：

(1/m) ΣΣ Tᵢⱼ² = (36² + 60² + 30² + 72²)/3 = (1296 + 3600 + 900 + 5184)/3 = 10980/3 = 3660
S_A×B = 3660 − C − S_A − S_B = 3660 − 3267 − 3 − 363 = 27.0，  df_A×B = 1

误差平方和 S_E：

S_E = S_T − S_A − S_B − S_A×B = 425 − 3 − 363 − 27 = 32.0，  df_E = ab(m−1) = 8
一致性验证 S_A + S_B + S_A×B + S_E = 3 + 363 + 27 + 32 = 425 = S_T ✓
自由度：1 + 1 + 1 + 8 = 11 = df_T ✓

S_E 也可以直接算单元格内平方和，每个单元格内三个数据与单元格均值的偏差平方和都是 8，四个单元格合计 32，完全一致 ✓。

结论（α = 0.05）

临界值 F₀.₀₅(1, 8) ≈ 5.32。

检验计算 F临界值结论
A（温度）主效应0.755.32F < 临界值，不显著（p ≈ 0.41）
B（时间）主效应90.755.32F ≫ 临界值，高度显著（p ≪ 0.001）
A×B 交互作用6.755.32F > 临界值，显著（p ≈ 0.032）
怎么解读 温度主效应本身不显著——平均下来低温和高温的得率差不多（96/6=16, 102/6=17，差 1）。 但交互作用显著：高温在长时间下效果很好（均值 24），在短时间下反而略差（均值 10）。 这正是"交互作用图收敛"的情况！

无重复试验（无交互）公式

如果每个 (i, j) 只有一个观察值（m=1），则不能检验交互作用，平方和分解变为：

S_T = S_A + S_B + S_E ,   自由度分别为 ab−1, a−1, b−1, (a−1)(b−1)

此时 S_A×B 被并入 S_E，自由度是 (a−1)(b−1)。
