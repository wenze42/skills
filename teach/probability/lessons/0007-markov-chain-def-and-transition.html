Lesson 0007 — 马尔可夫链：定义与转移概率

概率论 · 离散时间马尔可夫链 · 约 40 分钟

核心思想：无记忆的"下一跳"规则 马尔可夫链是一个离散时间、离散状态的随机过程，但它加了一个极强的约束—— 未来只取决于当前状态，与过去无关。 这个"马尔可夫性"让链的概率结构大幅简化，考研中几乎所有随机过程计算题都围绕它展开。

一、离散时间马尔可夫链的定义

设 {Xn, n = 0, 1, 2, …} 是一个取值在可数集 S 上的随机过程。 如果它满足：

对任意 n ≥ 0，任意 i, i₀, i₁, …, in-1, j ∈ S，有
P(Xn+1 = j | Xn = i, Xn-1 = in-1, …, X₀ = i₀) = P(Xn+1 = j | Xn = i)

这个条件称为马尔可夫性（Markov property）或无记忆性。 直观解读：已知"现在"，过去对"未来"的预测没有任何额外帮助。 一旦你告诉我当前在状态 i，下一刻去哪里只由 i 决定，之前经历过什么全部可以丢掉。

满足马尔可夫性的离散时间离散状态过程，称为离散时间马尔可夫链 （Discrete-Time Markov Chain, DTMC）。

二、时齐性与一步转移概率矩阵

2.1 时齐性

如果进一步，转移概率不随时间 n 改变：

pij = P(Xn+1 = j | Xn = i) 与 n 无关

则称链是时齐的。考研中讨论的马尔可夫链几乎全部默认时齐—— 转移规则不随时间变化。后面我们也只讨论时齐链。

2.2 一步转移概率矩阵

把所有转移概率 pij 排成矩阵，就得到一步转移概率矩阵：

P = [ pij ]|S| × |S|

它有两个基本性质：

  • 每行和为 1：∑j∈S pij = 1（从 i 出发，必须跳到某个状态 j，包括留在 i）
  • 所有元素非负：pij ≥ 0

这样的矩阵叫随机矩阵（stochastic matrix）——行向量是概率分布。

2.3 例题：0-1 传输系统

一个通信系统传输 0 或 1。传真率 p，误码率 q（p + q = 1）。设 Xn 为第 n 次发送的信号， Yn 为接收信号。在无噪声条件下这是个平凡链；加噪声后状态仍是 {0, 1}，转移规则：

P =
→ 0→ 1
从 0pq
从 1qp

每行和 = p + q = 1 ✅。状态 0 和 1互通（双向可达），这是一个不可约链（第四课详解）。

三、科尔莫戈罗夫-切普曼方程（K-C 方程）

一步转移只描述"跳一次"。跳 n 次后呢？定义n 步转移概率：

pij(n) = P(Xm+n = j | Xm = i) ← 时齐下与 m 无关

K-C 方程把多步和一步联系起来：

对任意 n, m ≥ 1： pij(n+m) = ∑k∈S pik(n) pkj(m)
矩阵形式：P(n+m) = P(n) · P(m)
K-C 方程的矩阵意义 多步转移概率矩阵就是一步矩阵的幂：P(n) = Pn。 这是考研最常见的计算——给你 P，让你算 P²、P³ 或某个 pij(n)。 核心就是矩阵乘法。

证明思路：走 n+m 步从 i 到 j = 走 n 步到某个中间态 k，再走 m 步从 k 到 j。 对所有可能的 k 求和（全概率公式），再利用马尔可夫性保证两段路径独立。

3.1 验证：两状态链的 P²

继续 0-1 传输系统，P = [[p, q], [q, p]]。算 P²：

P² = P·P = [[p·p + q·q, p·q + q·p], [q·p + p·q, q·q + p·p]] = [[p²+q², 2pq], [2pq, p²+q²]]

检查每行和 = p² + q² + 2pq = (p+q)² = 1 ✅。P² 的 (0,1) 元素表示"从 0 出发，经两步后到 1 的概率"—— 走 0→0→1 或 0→1→1，两个路径概率相加 p·q + q·p = 2pq。这与 K-C 方程完全吻合。

四、初始分布与 n 步后分布

马尔可夫链的"起点"由初始分布 π₀决定：

π₀ = P(X₀ = i)，∑i∈S π₀(i) = 1

n 步后的边缘分布 πn = P(Xn = j) 由初始分布和转移矩阵决定：

πn = π₀ · Pn
即 πn(j) = ∑i∈S π₀(i) · pij(n)

推导就是全概率公式：Xn = j 只有 n 步前从某个 i 出发走过来一种可能， 对所有可能的初始态 i 加权求和。

五、典型例子

5.1 直线上的简单对称随机游动

状态空间 S = {…, −2, −1, 0, 1, 2, …}，每次以概率 1/2 左移 1，1/2 右移 1。 转移概率：

pi,i+1 = pi,i−1 = 1/2，pij = 0（其他）

所有状态互通，这是不可约链。但状态空间是无限的——第四课将证明， 它是零常返的（返回平均时间无限）。

5.2 赌徒输光问题——带吸收壁的链

初始有 a 元，每次以概率 p 赢 1 元，q = 1−p 输 1 元。赌到 0 元（破产）或 N 元（赢光）就停。 状态空间 S = {0, 1, 2, …, N}，其中 0 和 N 是吸收态（进入后再也出不来）。 转移规则：

  • i = 0（破产）：p00 = 1，p0j = 0（j ≠ 0）
  • i = N（赢光）：pNN = 1，pNj = 0（j ≠ N）
  • 0 < i < N：pi,i+1 = p，pi,i−1 = q，其他为 0

考研中赌徒输光概率是经典考点：已知初始 a 元，求破产概率 Pa。 结果是：

  • p ≠ q 时：Pa = (q/p)a − (q/p)N / (q/p)ᵃ − (q/p)ᴺ = 1 − (q/p)a / (1 − (q/p)ᴺ)
  • p = q = 1/2 时：Pa = 1 − a/N
对称情形的直觉 p = q 时破产概率 = 1 − a/N，线性递减。当 N → ∞（对手无限富），Pa → 1—— 这说明对称随机游动在一维是常返的，最终会被吸收到 0（或 N → ∞ 时必然访问所有状态）。

5.3 排队模型（birth-death chain）

状态 n = 当前排队人数。每秒要么来一个（概率 λ，"生"），要么走一个（概率 μ，"灭"）， 两者同时发生或都不发生概率为 0。这就是经典的生灭链（birth-death chain）：

  • p01 = λ，p00 = 1 − λ
  • pi,i+1 = λ，pi,i−1 = μ，pii = 1 − λ − μ（i ≥ 1）

生灭链在运筹学、计算机性能分析、生物种群模型中无处不在——后面第四节我们将给出它的平稳分布公式。
