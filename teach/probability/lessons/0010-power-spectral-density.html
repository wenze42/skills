Lesson 0010 — 功率谱密度

随机过程专题 · 频域视角 · 约 25 分钟

为什么需要功率谱？

前一课我们从时域看平稳过程——用均值、自相关函数描述它。但信号处理中有句名言： "时域看不到的东西，频域会告诉你"。

你有没有想过：一段随机信号里，不同频率成分各自有多大的"能量"？低频和高频哪个更强？ 这个问题在通信、雷达、语音处理、金融时间序列里天天要回答。

功率谱密度（PSD）就是回答这个问题的工具。它把平稳过程从时域变换到频域， 是维纳、辛钦等大数学家在 1930 年代奠定的理论。

功率谱密度的定义

维纳-辛钦定理

对于宽平稳过程 X(t)，其功率谱密度（简称功率谱） 是自相关函数的傅里叶变换：

S_X(ω) = ∫_{-∞}^{+∞} R_X(τ) · e^{-jωτ} dτ

而自相关函数可以通过功率谱的逆傅里叶变换得到：

R_X(τ) = 1/(2π) ∫_{-∞}^{+∞} S_X(ω) · e^{jωτ} dω

这一对变换关系被称为维纳-辛钦定理（Wiener-Khinchin Theorem）， 是平稳过程分析中最重要的结论之一。

为什么"功率谱"而不是"频谱" 普通信号的频谱是傅里叶变换，幅度平方反映能量分布。但平稳随机过程通常不是能量信号 （总能量可能无穷），而是功率信号——我们关心的是"单位频段的平均功率"， 所以叫"功率谱密度"。

功率谱的基本性质

① 非负性

S_X(ω) ≥ 0，对所有 ω

功率谱密度是频率的非负函数——你不可能有"负功率"。这是它的核心物理意义。

② 偶函数性质（实过程）

S_X(-ω) = S_X(ω)

对于实值过程 X(t)，自相关函数是实偶函数（上一课已讲 R_X(-τ) = R_X(τ)）， 所以它的傅里叶变换也是实偶函数。这意味着只需画 ω ≥ 0 的部分即可。

③ 全频段积分 = 平均功率 × 2π

∫_{-∞}^{+∞} S_X(ω) dω = 2π · R_X(0) = 2π · E[X²(t)]

功率谱曲线下的面积（乘以 2π）就是信号的平均功率。这是最直接的物理量联系。

典型过程的功率谱

例 1：白噪声

白噪声是最理想的噪声模型——它的功率谱在所有频率上都是常数：

S_W(ω) = N₀ / 2， 对所有 ω

常数功率谱意味着：

  • 它包含所有频率成分
  • 类比"白光"包含所有可见光波长，所以叫"白"噪声

对应的自相关函数是一个冲激函数：

R_W(τ) = (N₀/2) · δ(τ)

这意味着白噪声在不同时刻完全不相关——τ ≠ 0 时 R_W(τ) = 0。

例 2：窄带噪声

窄带噪声的功率谱集中在某个中心频率附近，比如通信中的带通噪声：

S_X(ω) ≈ N₀/2， 当 |ω − ω_c| ≤ Ω/2 或 |ω + ω_c| ≤ Ω/2

带宽 Ω 远小于中心频率 ω_c。典型应用：无线电接收机中的信号滤波。

例 3：随机相位正弦波

上一课讲的随机相位正弦波 X(t) = A cos(ω₀t + Φ)， 它的自相关函数 R_X(τ) = A²/2 · cos(ω₀τ)，对应的功率谱是：

S_X(ω) = (πA²/2) · [δ(ω − ω₀) + δ(ω + ω₀)]

功率谱是两个冲激（狄拉克 δ 函数），分别位于 ω = ±ω₀。这符合直觉： 纯正弦波只有单一频率，所以它的功率谱在那个频率点"尖峰突起"。

线性系统对平稳过程的作用

这是功率谱最实用的部分之一——如果一个平稳过程 X(t) 通过 一个频率响应为 H(ω) 的线性系统，输出 Y(t) 是什么？

输出也是平稳的

宽平稳过程通过线性系统后，输出仍是宽平稳过程。

输出功率谱公式

S_Y(ω) = |H(ω)|² · S_X(ω)

这个公式极其优雅：输出功率谱 = 输入功率谱 × 系统增益的平方。 注意用的是 |H(ω)|²——模的平方，因为功率是能量的体现， 复数相位不影响功率大小。

输出自相关函数

R_Y(τ) = R_X(τ) * h(τ) * h(-τ)

在时域，输出自相关函数是输入自相关函数与系统脉冲响应 h(τ) 的"二重卷积"。 这里 h(-τ) 是因为时间反转对应的频域共轭。

白噪声通过理想低通的例子

设白噪声 S_W(ω) = N₀/2 通过一个截止频率 W 的理想低通滤波器， 则输出功率谱：

S_Y(ω) = { N₀/2, |ω| ≤ W ; 0, 其他 }

输出自相关函数：

R_Y(τ) = (N₀·W/π) · sinc(Wτ/π)

其中 sinc(x) = sin(x)/x。这个 sinc 形状在通信理论中反复出现。

互谱密度

对于两个联合平稳的过程 X(t) 和 Y(t)，它们的互谱密度定义为：

S_{XY}(ω) = ∫_{-∞}^{+∞} R_{XY}(τ) · e^{-jωτ} dτ

其中互相关函数 R_{XY}(τ) = E[X(t)Y(t+τ)]。互谱一般是复数， 它包含了两个过程之间在频率域的幅度关系和相位关系。

互谱有什么用？
  • 系统辨识：测量输入输出的互谱可以估计频率响应 H(ω)
  • 相干分析：相干函数 γ²(ω) = |S_{XY}(ω)|² / (S_X(ω)S_Y(ω)) 衡量两信号在各频率的线性相关性
