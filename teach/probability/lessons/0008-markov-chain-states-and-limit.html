Lesson 0008 — 马尔可夫链状态分类与极限分布

概率论 · 状态空间结构与平稳分布 · 约 45 分钟

为什么要分类？ 上一课我们会算 P、会算 Pⁿ，但算出来的数字怎么解读？答案取决于链的"长期行为"—— 某个状态会不会被反复访问？访问的频率是多少？时间趋于无穷后，链最终会停在哪里？ 这一课用一套完整的分类体系回答这些问题，并给出平稳分布的计算方法。

一、可达性与互通

先定义两个最基本的关系：

可达 i → j：存在 n ≥ 1 使得 pij(n) > 0
互通 i ↔ j：同时 i → j 和 j → i 成立

互通是等价关系（自反、对称、传递），因此它把状态空间 S 划分成若干 互通类。每个互通类内部所有状态两两互通，不同类之间要么互不可达， 要么单向可达（从一个类可以到另一个，但回不来）。

一个状态属于哪个类，由 P 的非零元素结构决定 只需从每个状态出发，沿着 pij > 0 的箭头走，看能到达哪些状态。 考研中如果转移矩阵不大（3-4 状态），画一张状态转移图就能肉眼看出所有互通类。

二、暂留态 vs 常返态

2.1 首次返回概率

记 fii 为从状态 i 出发，最终回到 i 的概率。 这是区分常返性的关键量：

  • fii = 1 → 常返态：必然能回来，无穷多次访问
  • fii < 1 → 暂留态：有一定概率永远不回来，只能访问有限次

2.2 平均返回时间

对常返态，进一步看首次返回的期望时间 μi = E[Ti]， 其中 Ti 是从 i 出发首次回到 i 的步数：

  • μi < ∞ → 正常返态：虽然一定回来，但平均等待时间有限
  • μi = ∞ → 零常返态：虽然一定回来，但平均等待时间无限

三、周期性

状态 i 的周期定义为：

di = gcd{ n ≥ 1 : pii(n) > 0 }

gcd 是最大公约数。如果集合为空（即永远回不来），则 di 无定义（暂留态可能出现）。

  • di = 1 → 非周期（aperiodic）
  • di > 1 → 周期（periodic），即"每 d 步才能回到自己"

周期的直观例子：两步循环 0↔1，p00(1) = 0, p00(2) > 0, p00(3) = 0, p00(4) > 0, …，gcd{2, 4, 6, …} = 2，所以 d₀ = d₁ = 2，两状态链是周期为 2 的。

遍历态 = 正常返 + 非周期

这是最重要的一类状态，因为只有遍历态才会有极限分布（第四节详解）。

四、闭集与不可约性

若 C ⊆ S 是闭集，则：从 C 中任何状态出发，永远不可能跳到 C 之外。 等价条件：∑j∈C pij = 1 对所有 i ∈ C 成立。

如果整个状态空间 S 是唯一的闭集，链内部所有状态两两互通， 则称链是不可约的（irreducible）。否则可约。

对于不可约链，所有状态的常返性、周期性、正常/零常返属性都相同—— 这是一个非常强的结论。只需验证任意一个状态的属性，就知道整个链的状态类型。

五、有限状态链基本定理

当 |S| < ∞ 时，有几条结论非常简洁且高频：

  1. 有限状态链至少有一个常返态（不可能全部都是暂留态）
  2. 任何闭集中至少有一个常返态
  3. 暂留态全体不是闭集（必然会从暂留态跳到某个常返类里，然后再也出不来）
  4. 有限状态的不可约链中，所有状态必为正常返
  5. 有限状态不可约 + 非周期 → 所有状态遍历，极限分布存在
一个反例：无限状态 对称随机游动（一维，状态 Z 无限）不可约且非周期，但是零常返—— 一定回来，但平均要等无穷久。所以"有限"这个条件不能丢。

六、极限分布与平稳分布

6.1 极限分布定义

若对任意状态 i, j ∈ S，极限

πj = limn→∞ pij(n)

存在且与初始态 i 无关，则 {πj} 称为链的极限分布。

极限存在的充分条件 有限状态 + 不可约 + 非周期（即所有状态遍历） ⇒ 极限分布存在且与初始态无关。 考研中90% 的计算题都满足这个条件——给你一个 3×3 不可约非周期链，让你解 π。

6.2 平稳分布方程

如果存在一个概率分布 π = (π₁, π₂, …) 使得

π = π P， 即 πj = ∑i∈S πi pij，且 ∑j πj = 1

则 π 称为链的平稳分布。"平稳"的含义：如果初始分布就是 π，那么对所有 n ≥ 0， πn = π₀ Pⁿ = π 保持不变。

6.3 极限 = 平稳 = 唯一

在有限状态 + 不可约 + 非周期条件下，三者完全等价：

极限分布 = 唯一的平稳分布 = (π₁, π₂, …, π|S|)
且 πj = 1 / μj（与状态 j 的平均返回时间成反比）

这是马尔可夫链理论中最"漂亮"的定理之一——极限分布就是平稳分布，且唯一。 因此所有考研计算题都归结为：解方程 π = πP，外加约束 ∑πj = 1。

6.4 详细平衡方程（充分条件，非必要）

有时候直接解 π = πP 比较麻烦，若能找到满足

πi pij = πj pji， 对所有 i ≠ j

的 π，那么这个 π 一定是平稳分布。这个条件叫详细平衡（detailed balance） 或局部平衡。它比 π = πP 更强（对所有 i, j 对成立），但好解。 例如在生灭链中，详细平衡给出简洁的闭式解：πn ∝ (λ/μ)ⁿ。

七、完整数值例子：解一个 3×3 不可约非周期链

题目：设链有三个状态 {1, 2, 3}，转移矩阵：

P = [[ 0.4, 0.4, 0.2 ], [ 0.3, 0.5, 0.2 ], [ 0.2, 0.4, 0.4 ]]

(1) 验证这是不可约非周期链；(2) 求平稳分布 π = (π₁, π₂, π₃)；(3) 求各状态的平均返回时间。

解 (1)：不可约性——从 1 能到 2,3；从 2 能到 1,3；从 3 能到 1,2，所有状态互通 ✅。 非周期性——p₁₁ = 0.4 > 0 说明从 1 出发一步就能回到 1，所以 d₁ = gcd{1, 2, 3, …} = 1（非周期）。 不可约链中所有状态周期相同，所以整个链非周期 ✅。有限状态 + 不可约 + 非周期 ⇒ 遍历，极限分布存在且唯一。

解 (2)：由 π = πP，写出三个方程：

  • π₁ = 0.4π₁ + 0.3π₂ + 0.2π₃
  • π₂ = 0.4π₁ + 0.5π₂ + 0.4π₃
  • π₃ = 0.2π₁ + 0.2π₂ + 0.4π₃

化简第 1 个方程：π₁ − 0.4π₁ − 0.3π₂ − 0.2π₃ = 0 ⇒ 0.6π₁ − 0.3π₂ − 0.2π₃ = 0 …… (A) 化简第 2 个方程：π₂ − 0.4π₁ − 0.5π₂ − 0.4π₃ = 0 ⇒ −0.4π₁ + 0.5π₂ − 0.4π₃ = 0 …… (B) 第三个方程是前两个的线性组合（K-C 保证 π = πP 只有独立方程数 = |S| − 1），所以我们取 (A)、(B) 加约束：

  • (A): 6π₁ − 3π₂ − 2π₃ = 0（乘 10）
  • (B): −4π₁ + 5π₂ − 4π₃ = 0（乘 10）
  • (C): π₁ + π₂ + π₃ = 1

由 (A): π₃ = (6π₁ − 3π₂) / 2 = 3π₁ − 1.5π₂。代入 (B)： −4π₁ + 5π₂ − 4(3π₁ − 1.5π₂) = −4π₁ + 5π₂ − 12π₁ + 6π₂ = −16π₁ + 11π₂ = 0 ⇒ π₂ = (16/11)π₁ ⇒ π₃ = 3π₁ − 1.5×(16/11)π₁ = 3π₁ − (24/11)π₁ = (33/11 − 24/11)π₁ = (9/11)π₁

代入 (C)：π₁ + (16/11)π₁ + (9/11)π₁ = (36/11)π₁ = 1 ⇒ π₁ = 11/36 ≈ 0.3056 所以 π₂ = 16/36 ≈ 0.4444，π₃ = 9/36 = 0.25

验证：用 πP 的第 1 个分量：0.4×(11/36) + 0.3×(16/36) + 0.2×(9/36) = (4.4 + 4.8 + 1.8)/36 = 11/36 = π₁ ✅ 同理其他分量也验证成立 ✅

解 (3)：平均返回时间 μj = 1 / πj：

  • μ₁ = 36/11 ≈ 3.27 步
  • μ₂ = 36/16 = 2.25 步
  • μ₃ = 36/9 = 4 步
解方程的快捷步骤 π = πP 实际上是 |S| 个方程，但只有 |S| − 1 个独立。最稳妥的做法：
  1. 由 π = πP 写出第一个分量的方程，化简
  2. 用它把 π₃ (或某个分量) 用 π₁, π₂ 表示
  3. 代入第二个独立方程，再把 π₂ 用 π₁ 表示
  4. 代入归一化约束 ∑π₁ = 1，解出 π₁
  5. 回代得到所有分量
