Lesson 0009 — 平稳随机过程与各态历经性

随机过程专题 · 考研拓展 · 约 25 分钟

为什么需要平稳性

随机过程是随时间演化的一族随机变量 {X(t), t∈T}。但对于一个过程，我们需要回答： "它的统计规律是否随时间变化？"

平稳性就是对这个问题的回答。它是随机过程中最重要的概念之一——只有当一个过程是平稳的， 我们才能用有限的样本数据去推断它的长期统计规律。

平稳性分为两个层次：严平稳（强平稳）和宽平稳（弱平稳）。

严平稳（强平稳）

定义

如果随机过程 {X(t), t∈T} 的任意有限维分布在时间平移下保持不变， 则称该过程是严平稳的。

F(t₁+τ, t₂+τ, ..., tₙ+τ; x₁, x₂, ..., xₙ) = F(t₁, t₂, ..., tₙ; x₁, x₂, ..., xₙ)

对任意正整数 n、任意时间点 t₁,...,tₙ∈T、任意实数 τ，分布函数都相同。 这意味着：把整个过程"平移"任意时间，它的统计性质完全不变。

直观理解 严平稳过程没有"起点"——它从无穷久远开始，到无穷远后结束，永远以同样的统计方式变化。 比如热噪声、电力负荷的日周期分量（取合适的时间尺度后）。

宽平稳（二阶矩平稳）

定义

严平稳要求太强（所有有限维分布都不变），实际中更常用的是宽平稳，它只要求二阶矩满足三个条件：

  1. 均值函数是常数：E[X(t)] = μ_X（不随 t 变化）
  2. 自相关函数仅依赖时间差：R_X(t, t+τ) = R_X(τ)（不依赖 t，只依赖间隔 τ）
  3. 二阶矩存在：E[X²(t)] < ∞
两者的关系
  • 严平稳 + 二阶矩存在 ⇒ 宽平稳
  • 宽平稳 ⇏ 严平稳（反例存在）
  • 正态过程例外：宽平稳 ⇔ 严平稳（正态分布完全由一、二阶矩决定）

自相关函数的基本性质

自相关函数 R_X(τ) = E[X(t)X(t+τ)] 是宽平稳过程最重要的数字特征， 它有一系列深刻的性质：

① R_X(0) = 平均功率

R_X(0) = E[X(t)X(t)] = E[X²(t)]

这是信号的平均功率——信号幅度平方的时间平均期望。

② 偶函数性质

R_X(-τ) = R_X(τ)

证明：R_X(-τ) = E[X(t)X(t-τ)] = E[X(t-τ)X(t)] = R_X(t-τ, t) = R_X(τ)（宽平稳性保证只依赖时间差）。 所以自相关函数关于 τ=0 对称。

③ 柯西-施瓦茨不等式

|R_X(τ)| ≤ R_X(0)

自相关函数在 τ=0 处取得最大值（绝对值意义上）。时间间隔越大，相关性越弱。

④ 非负定性

对任意实数 t₁, t₂, ..., tₙ 和任意函数 g(t)，有：

Σᵢ Σⱼ R_X(tᵢ - tⱼ) · g(tᵢ) · g(tⱼ) ≥ 0

这意味着以 R_X(tᵢ - tⱼ) 为元素的矩阵是半正定的。这是平稳过程能通过谱表示的理论基础。

各态历经性（遍历性）

平稳性告诉我们"所有时刻的统计规律相同"，但这还不够。实际中我们只有一条样本曲线 （一段观测数据）。能否用这一条曲线来推断整个过程的统计性质？

这就是各态历经性（Ergodicity）要回答的核心问题。

时间平均 vs 统计平均

对任意一条样本曲线 x(t)，我们可以计算它的时间平均：

⟨X⟩ = lim_{T→∞} 1/T ∫₀ᵀ x(t) dt

而过程的统计平均（期望）是：

E[X(t)] = μ_X

定义

如果宽平稳过程的时间平均以概率 1 等于统计平均，则称过程具有各态历经性：

  • 均值各态历经：lim_{T→∞} 1/T ∫₀ᵀ X(t) dt = μ_X（w.p.1）
  • 自相关各态历经：lim_{T→∞} 1/T ∫₀ᵀ X(t)X(t+τ) dt = R_X(τ)（w.p.1）
为什么"各态历经" 直观含义：随着时间推移，一条样本曲线会"经历"过程的所有可能状态， 因此它的时间平均就能代表整个过程的统计平均。 如果过程是非各态历经的，那不同样本曲线可能给出完全不同的统计结果。

随机相位正弦波的例子

考虑过程 X(t) = cos(ω₀t + Φ)，其中 Φ ~ U(0, 2π)。这是一个经典的平稳过程， 让我们来验证它的各态历经性。

统计平均：E[X(t)] = ∫₀^{2π} cos(ω₀t + φ) · 1/(2π) dφ = 0

对任意一条样本曲线（固定一个相位 φ₀），它的时间平均：

时间平均：lim_{T→∞} 1/T ∫₀ᵀ cos(ω₀t + φ₀) dt = 0

两者相等！所以这个过程是均值各态历经的。下面的 SVG 展示了两条不同相位的样本曲线：

均值各态历经的充要条件

对于宽平稳过程，均值各态历经有一个优雅的充要条件：

lim_{T→∞} 1/T ∫_{-T}^{T} (1 − |τ|/T) · [R_X(τ) − μ_X²] dτ = 0

这个条件的直觉含义是：当 τ 增大时，自协方差 C_X(τ) = R_X(τ) − μ_X² 必须衰减， 而且要衰减得足够快。

一个实用的充分条件

如果自相关函数在 τ → ∞ 时收敛到均值的平方：

lim_{τ→∞} R_X(τ) = μ_X²

那么过程一定是均值各态历经的。这是考试中最常用的判断方法。

怎么理解这个充分条件 R_X(τ) → μ_X² 意味着：当时间间隔足够大时，X(t) 和 X(t+τ) 几乎不相关了。 这正是"过程逐渐忘记过去"的信号——如果过了很长时间后就独立了，那么一条长样本曲线就会经历所有可能的状态。

时间均值估计式

各态历经性的最大实用价值在于：我们可以用一条样本曲线来估计过程的统计量。

均值估计

μ̂_X = 1/T ∫₀ᵀ x(t) dt

自相关函数估计

R̂_X(τ) = 1/(T − τ) ∫₀^{T−τ} x(t)x(t+τ) dt

其中 T 是观测时间长度。当 T 足够大时，这些估计量会以概率 1 收敛到真实值。
