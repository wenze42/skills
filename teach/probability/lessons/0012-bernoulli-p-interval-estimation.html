Lesson 0012 — （0-1）分布参数 p 的区间估计与单侧置信区间

概率论 · 考研核心考点 · 20 分钟 · 对应教材第 7 章 §6

前置知识 你需要已经会：矩估计/极大似然估计的基本思想、中心极限定理、双侧置信区间的一般求解方法。 这一课聚焦（0-1）分布这个最常考的特例。

为什么（0-1）分布值得单独讲

（0-1）分布 X ~ Bernoulli(p) 只取两个值：X = 1（事件发生，概率 p）或 X = 0（不发生，概率 1-p）。 但现实中大量问题都可以归结为这个模型：

  • 产品合格率（随机抽一个，合格=1，不合格=0）
  • 命中率、故障率、犯罪率、感染率……
  • 任何"二选一"的问题

我们的目标是：做了 n 次观测（n 很大），观测到 k 次 1（即 X̄ = k/n）， 那么 p 的置信区间是什么？

前置：（0-1）分布的数字特征

这是所有推导的基础，请确认你会：

量公式
E(X)（总体均值）p
D(X)（总体方差）p(1 − p)
样本均值 X̄1nΣXᵢ = k/n
E(X̄)（无偏）p
D(X̄)（标准误的平方）p(1 − p)n
p 的点估计（矩估计=极大似然）p̂ = X̄ = k/n

双侧置信区间（大样本精确解法）

第一步：中心极限定理近似

n 很大时（一般 n ≥ 30），由 CLT：

X̄ − p√(p(1 − p)/n)  ≈  N(0, 1)

所以置信水平 1 − α 的双侧置信区间满足：

P( −uα/2 ≤ X̄ − p√(p(1 − p)/n) ≤ uα/2 )  ≈  1 − α

第二步：整理为二次方程

关键一步：两边都乘分母、移项、平方，就得到关于 p 的一元二次不等式：

(n + uα/2²) · p²  −  (2nX̄ + uα/2²) · p  +  nX̄²  ≤  0

对应方程：

A·p² − B·p + C = 0
系数表达式
An + uα/2²
B2nX̄ + uα/2²
CnX̄²

第三步：解二次方程

判别式 Δ = B² − 4AC，两个根：

p₁,₂  =  B ± √Δ2A

因为二次项系数 A > 0，所以不等式 A·p² − B·p + C ≤ 0 的解在两根之间：

p 的 (1 − α) 双侧置信区间：(p₁, p₂)

这里 p₁ = (B − √Δ)/(2A) 是下限，p₂ = (B + √Δ)/(2A) 是上限。

为什么不直接用 X̄ ± u·σ？ 近似法是 X̄ ± uα/2√(X̄(1 − X̄)/n)，把 p 换成了 X̄。这个在 p 靠近 0.5 时还行， 但 p 靠近 0 或 1 时误差大，而且可能出界（小于 0 或大于 1）。精确解法永远在 [0,1] 内， 考研应该考精确法。

双侧完整数值例子

从一批产品中随机抽检 n = 100 件，其中 k = 80 件合格， 即 X̄ = 0.8。求 p 的 95% 双侧置信区间。

查表：α = 0.05 时 uα/2 = u0.025 = 1.96

单侧置信区间

什么时候用单侧

双侧置信区间回答的问题是"p 在某个区间内吗？"。 但很多实际问题只关心一个方向：

  • "产品合格率 p 至少是多少？" → 单侧下限
  • "次品率 p 不超过多少？" → 单侧上限
  • "感染率 会不会高于某个警戒线？" → 单侧上限

单侧下限的推导（P(p ≥ p̂L) = 1 − α）

关键区别：现在要的是单边概率，不是双边：

P( X̄ − p√(p(1 − p)/n) ≤ uα )  ≈  1 − α

注意：这里用 uα 而不是 uα/2——因为 α 全部堆在右边了。 整理过程跟双侧完全一样，平方后还是那个关于 p 的二次方程，只是系数里 uα/2 换成了 uα：

系数双侧用单侧用
An + uα/2²n + uα²
B2nX̄ + uα/2²2nX̄ + uα²
CnX̄²nX̄²（不变）

代入 uα 算出来两个根，取较小那个就是下限 p̂L：

单侧下限：p̂L = (B − √Δ')/(2A)，其中 α 用 uα

单侧上限的推导（P(p ≤ p̂U) = 1 − α）

同理，只要把式子反过来：

P( X̄ − p√(p(1 − p)/n) ≥ −uα )  ≈  1 − α

还是同一个二次方程，解的较大根就是上限 p̂U：

单侧上限：p̂U = (B + √Δ')/(2A)，其中 α 用 uα
α = 1.645 1−α α 单侧上限：α 全堆在左边 −uα = −1.645 1−α α

完整解题模板（直接套）

考试时按这个模板一步步写：

  1. 确定统计模型：Xᵢ ~ Bernoulli(p) 独立同分布
  2. 点估计：p̂ = X̄ = k/n
  3. 用 CLT 近似：(X̄ − p)/√(p(1−p)/n) ≈ N(0,1)
  4. 选分位点：
    · 双侧 → uα/2
    · 单侧下限 → uα
    · 单侧上限 → uα（取较大根）
  5. 写二次方程：(n+u²)p² − (2nX̄+u²)p + nX̄² = 0
  6. 求根公式解：p₁,₂ = (B ± √(B²−4AC))/(2A)
  7. 结论：区间 (p₁, p₂)，或单侧下限 p₁ / 上限 p₂
