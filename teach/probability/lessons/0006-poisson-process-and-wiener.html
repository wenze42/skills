Lesson 0006 — 泊松过程与维纳过程

概率论 · 两个最重要的独立增量过程 · 约 40 分钟

两个极端但互补的独立增量过程 泊松过程只能跳跃取整数值（计数来了多少次）； 维纳过程只能连续变化（布朗运动粒子位置）。 它们是独立增量 + 时齐这两条公理下最基础、最常用的两个特例——也是考研考频最高的两个过程。

一、计数过程

设 N(t) 表示在 [0, t] 内某种"事件"发生的次数（如电话总机来话数、放射性衰变粒子数、 医院急诊接诊数）。则 {N(t), t ≥ 0} 称为计数过程，它满足：

  • N(0) = 0（初始时刻事件数为零）
  • N(t) 是取值在 {0, 1, 2, …} 上的整数变量（离散状态）
  • N(t) 关于 t 单调不减（次数只增不减）
  • s < t ⟹ N(t) − N(s) = (s, t] 内事件发生的次数

二、泊松过程——计数世界的"黄金标准"

如果一个计数过程满足以下三条公理，它就是强度为 λ 的泊松过程（λ > 0，常数）：

公理 ① 独立增量：对任意 t₁ < t₂ ≤ t₃ < t₄， N(t₂) − N(t₁) 与 N(t₄) − N(t₃) 相互独立。
公理 ② 增量分布：对任意 s < t， N(t) − N(s) ~ P(λ(t − s))（参数为 λ(t − s) 的泊松分布）。
公理 ③ 初始条件 N(0) = 0。

三条公理合起来，意味着：事件以平均速率 λ 均匀地、独立地、随机地到来。 λ 越大，单位时间内平均到来的事件越多——它是整个过程的"节拍"。

2.1 泊松过程的数字特征

由公理 ②，N(t) ~ P(λt)（即 N(t) = N(t) − N(0)），直接得到：

均值函数：E[N(t)] = λ t
方差函数：D[N(t)] = λ t ← 均值 = 方差，这是泊松分布的"散弹噪声"特征

下面推导协方差和自相关。对 s ≤ t：

  • N(t) = N(s) + (N(t) − N(s))
  • 由独立增量，N(s) 与 N(t) − N(s) 独立
  • Cov(N(s), N(t)) = Cov(N(s), N(s)) + Cov(N(s), N(t)−N(s)) = D[N(s)] + 0 = λs
协方差函数：CN(s, t) = λ · min(s, t)
自相关函数：RN(s, t) = λ² s t + λ · min(s, t)

当 s = t 时，D[N(t)] = CN(t, t) = λt，与之前结果一致 ✅

2.2 等待时间——Γ 分布登场

记 Wn 为第 n 个事件出现的绝对时刻（即等待了多久第 n 个事件才来）， 则有：

Wn = min{ t > 0 : N(t) ≥ n }
Wn ~ Γ(n, λ) ← 参数为 (n, λ) 的伽马分布

特别地，当 n = 1 时：

W₁ ~ Exp(λ) ← 首次等待时间服从指数分布

2.3 点间间距——无记忆性的源泉

记 Ti = Wi − Wi−1（令 W₀ = 0）为第 i−1 个到第 i 个事件之间的时间间隔， 则：

T₁, T₂, T₃, … 独立同分布 Exp(λ)

这个结论反过来也成立：若点间间距独立同 Exp(λ)，则计数过程一定是泊松过程。 这是泊松过程的一个等价定义，在许多实际建模中更直观（"顾客到来的间隔时间是独立同指数"）。

指数分布的无记忆性——为什么重要 指数分布 P(T > s + t | T > s) = P(T > t)，即"已经等了 s 时间还没发生事件， 那剩下还要等多久的分布和从来没等过一样"。 这完美解释了泊松过程的独立增量性——事件到来与过去发生过什么完全无关。

三、维纳过程（布朗运动）

1827 年布朗观察到：花粉粒在水中的运动是连续的、不规则的、永远不停的—— 这就是布朗运动。1905 年爱因斯坦用分子碰撞给出物理解释， 1923 年维纳用严格的概率语言定义了它：

过程 {W(t), t ≥ 0} 是 σ² 维纳过程，若满足：
① 独立增量：不重叠区间增量相互独立
② 增量正态：对任意 s ≤ t，W(t) − W(s) ~ N(0, σ²(t − s))
③ W(0) = 0，且 W(t) 的样本函数几乎处处连续

3.1 维纳过程的数字特征

由 W(t) = W(t) − W(0) ~ N(0, σ²t)，直接得：

均值函数：E[W(t)] = 0 ← 永远零均值，这叫"鞅性质"
方差函数：D[W(t)] = σ² t
协方差函数：CW(s, t) = σ² · min(s, t)

协方差推导与泊松过程完全相同——利用 W(t) = W(s) + (W(t)−W(s)) 和独立增量。

3.2 维纳过程是正态过程

任意有限时刻 t₁ < t₂ < … < tₙ，(W(t₁), W(t₂), …, W(tₙ)) 是多维正态。 为什么？因为：

  • 每个 W(tₖ) 是增量的和：W(tₖ) = [W(t₁)] + [W(t₂)−W(t₁)] + … + [W(tₖ)−W(tₖ₋₁)]
  • 每个增量 W(tᵢ)−W(tᵢ₋₁) 独立且正态
  • 独立正态变量的线性组合仍是正态 ⇒ 联合正态
正态过程的"极简定理"再次生效 维纳过程 = 零均值 + CW(s,t) = σ² min(s,t)。 抓住这两个函数，就抓住了它所有的有限维分布、所有的统计性质。

四、两者对比

性质泊松过程 N(t)维纳过程 W(t)
状态空间 离散 {0, 1, 2, …} 连续 ℝ
样本函数 阶梯状，只向上跳 连续但处处不可微
增量分布 泊松 P(λΔt) 正态 N(0, σ²Δt)
均值函数 λ t 0
方差函数 λ t (= 均值) σ² t
协方差 C(s,t) λ · min(s,t) σ² · min(s,t)
独立增量 ✅ ✅
时齐 ✅ ✅
正态过程 ❌ ✅

注意它们的协方差函数形式完全一样，只是系数（λ vs σ²）不同。 这不是巧合——独立增量 + 时齐 + 连续参数过程的协方差必然长成 σ² min(s,t) 的样子， 差别只在增量的分布类型。

五、考研高频结论速记

泊松过程必背

  • E[N(t)] = D[N(t)] = λ t
  • N(t) ~ P(λ t)
  • 首次等待 W₁ ~ Exp(λ)，第 n 次等待 Wₙ ~ Γ(n, λ)
  • 点间间距 Ti ~ Exp(λ)，独立同分布
  • 条件 N(t) = n 下，n 个事件的发生时刻 W₁, …, Wₙ 的分布等价于 n 个独立 U(0,t) 顺序统计量

维纳过程必背

  • W(t) ~ N(0, σ² t)
  • Cov(W(s), W(t)) = σ² min(s, t)
  • 样本函数连续，但处处不可微
  • 正态过程，完全由均值=0 和协方差函数决定
N(t) = n 下事件发生时刻的条件分布 在已知 [0, t] 内发生了 n 个事件的条件下，这 n 个事件的发生时刻在 [0, t] 上独立均匀。 这是泊松过程一个非常有用的性质，考研中偶尔考填空题。
