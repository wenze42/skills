Lesson 0004 — 一元线性回归

概率论 · 数理统计 · 约 22 分钟

为什么用回归

方差分析回答的是"X 的不同水平下 Y 是否不同"。但很多时候我们想知道更精细的关系—— "X 增加 1 单位，Y 平均增加多少？"回归分析就是干这个的。

本课讨论最简单的一元线性回归：只有一个自变量 x，一个因变量 y， 假设它们的关系可以用一条直线近似。

线性回归模型

yᵢ = a + b xᵢ + εᵢ，  εᵢ ~ N(0, σ²)  独立同分布

其中 a 是截距（x=0 时的 y 值），b 是斜率（x 每增加 1，y 平均变化 b）。 εᵢ 是随机误差，代表模型没捕捉到的部分。我们要从数据估计出 â 和 b̂。

区分样本与总体 a, b 是未知的总体参数；â, b̂ 是从样本算出来的估计值。 εᵢ 是不可观测的随机误差，而残差 êᵢ = yᵢ − (â + b̂xᵢ) 是可观测的、对 εᵢ 的估计。

最小二乘法推导

最小二乘法（Ordinary Least Squares, OLS）的准则是：让所有点到回归线的垂直偏差平方和最小。 写成数学式就是最小化：

Q(a, b) = Σᵢ [yᵢ − (a + b xᵢ)]²

对 a 和 b 分别求偏导令其为 0，解正规方程可得闭式解（闭式解 = 有公式直接算）：

b̂ = ½½ (xᵢ − x̄)(yᵢ − ȳ)  /  ½½ (xᵢ − x̄)²
â = ȳ − b̂ · x̄

引入两个缩写，写起来更方便：

SS_xx = Σ(xᵢ − x̄)²,   SS_xy = Σ(xᵢ − x̄)(yᵢ − ȳ)

则 b̂ = SS_xy / SS_xx。这是考研最常考的公式之一，建议记住。

平方和分解与 R²

回到方差分解。记 ŷᵢ = â + b̂xᵢ 为第 i 个点的预测值，则：

yᵢ − ȳ = (ŷᵢ − ȳ) + (yᵢ − ŷᵢ)

两边平方求和，可以证明交叉项消失（关键！），得到：

SST = SSR + SSE
记号名称公式含义
SST 总平方和 Σ(yᵢ − ȳ)² y 的全部波动
SSR 回归平方和 Σ(ŷᵢ − ȳ)² x 通过回归解释掉的部分
SSE 残差平方和 Σ(yᵢ − ŷᵢ)² 回归解释不掉的纯噪声

由此定义决定系数 R²：

R² = SSR / SST = 1 − SSE / SST

R² 衡量自变量 x 能够解释因变量 y 波动的比例，取值 [0, 1]。 R² 越接近 1，拟合越好。对于一元线性回归，R² = r²（r 是 x 和 y 的相关系数）—— 这也给了 R² 一个直观的统计意义：就是相关系数的平方。

显著性检验

回归做出来了，还要检验"b 是否真的不为 0"（零假设 H₀: b = 0）。有两种等价的检验：

F 检验

MSR = SSR/1（回归只有一个自变量，自由度 1），MSE = SSE/(n−2)：

F = MSR / MSE  ~  F(1, n−2)

t 检验

t = b̂ / SE(b̂)  ~  t(n−2)，  SE(b̂) = √(MSE / SS_xx)
关键结论：t² = F 在一元线性回归中，F(1, n−2) 和 t²(n−2) 的分布完全相同。
t 检验针对的是斜率 b，F 检验针对的是整体回归——这里二者等价。

置信区间 vs 预测区间

给定一个新的 x₀，有两个容易混淆的区间：

区间类型估计什么中心标准差
置信区间 x₀ 处的均值 E(y|x₀) ŷ₀ = â + b̂x₀ √(MSE[1/n + (x₀−x̄)²/SS_xx])
预测区间 x₀ 处的单个 y 值 ŷ₀ = â + b̂x₀ √(MSE[1 + 1/n + (x₀−x̄)²/SS_xx])
直觉 预测区间多了一个 "1" 项——因为预测单个 y 时，不仅有 a、b 估计的不确定性，还有随机误差 ε₀ 本身。 所以预测区间总是比置信区间更宽。

完整数值例子

某工厂记录了 10 批产品的投入 x（千元）和产出 y（单位）：

批次12345678910合计
x1234567891055
y243546576850

先算基础统计量：n=10，

x̄ = 55/10 = 5.5，   ȳ = 50/10 = 5.0

第一步：算 SS_xx 和 SS_xy

所以 SS_xy = 45，SS_xx = 82.5，SST = Σ(yᵢ−ȳ)² = 30。

第二步：算斜率和截距

b̂ = SS_xy / SS_xx = 45 / 82.5 = 6/11 ≈ 0.5455
â = ȳ − b̂ · x̄ = 5.0 − (6/11) × 5.5 = 5.0 − 3.0 = 2.0

回归方程：ŷ = 2 + 0.5455 x。

第三步：算 SSR、SSE、R²

SSR = b̂² · SS_xx = (45/82.5)² × 82.5 = 45²/82.5 = 2025/82.5 ≈ 24.5455

SSE = SST − SSR = 30 − 24.5455 ≈ 5.4545
R² = SSR / SST = 24.5455 / 30 ≈ 0.8182

相关系数 r = √R² ≈ 0.9045，确认正相关很强。

第四步：F 检验和 t 检验

自由度：回归 1，残差 n−2 = 8。

MSR = SSR/1 = 24.5455
MSE = SSE/8 = 5.4545/8 ≈ 0.6818
F = MSR/MSE = 24.5455 / 0.6818 ≈ 36.00

F₀.₀₅(1, 8) ≈ 5.32，计算 F ≈ 36 ≫ 临界值 → 拒绝 H₀，b 显著不为 0。

t 检验：

SE(b̂) = √(MSE / SS_xx) = √(0.6818 / 82.5) ≈ √0.00826 ≈ 0.0909
t = b̂ / SE(b̂) = 0.5455 / 0.0909 ≈ 6.00

t² = 36 = F ✓，和 F 检验完全一致。t₀.₀₂₅(8) = 2.31，6 > 2.31 → 同样显著。
