Lesson 0004 — 三极管：结构与电流放大原理

模拟电子电路 · Lesson 0004 / 0020 · 约 35 分钟

前置知识 必须掌握 Lesson 0002（PN 结） 的正向/反向偏置，以及 Lesson 0003（二极管及其电路） 的恒压降模型。 三极管就是"两个 PN 结共用一层极薄的基区"拼起来的器件——你在 0002 学的两个结，在这里第一次被装进同一块硅片。

一、三极管长什么样：结构与符号

双极型晶体管（Bipolar Junction Transistor，简称 BJT），中文习惯叫三极管。 做法是：在一块半导体上做两个背靠背的 PN 结，中间那一层做得极薄，再从三个区域各引出一个电极。

  • 发射极 E（Emitter）：负责向基区"发射"载流子，是电流的源头；
  • 基极 B（Base）：夹在中间，负责"控制"通过多少载流子；
  • 集电极 C（Collector）：负责"收集"穿过基区而来的载流子。

按三块半导体的排列顺序分两类：NPN（两块 N 夹一块 P）和 PNP（两块 P 夹一块 N）。 两个 PN 结各有名字：发射区与基区之间的叫发射结，基区与集电区之间的叫集电结。 这两个结的偏置状态，就是后面判断"工作在哪个区"的唯一依据。

符号的记忆法：箭头永远画在发射极上，方向就是发射结正向电流的方向。 NPN 的箭头由基极指向发射极外侧（朝外），PNP 的箭头朝内。英文口诀 "NPN — Not Pointing iN"。 符号里那根又短又粗的竖线代表基区，画得短粗就是在提醒你：基区必须很薄。

PNP 管的一切电流方向、电压极性与 NPN 相反：发射极电位最高，电流从 E 流入、从 B 和 C 流出。 考研卷面上 NPN 占九成，遇到 PNP 只要把"正负、电流方向"全部取反即可。

二、凭什么能放大：三个"故意"的设计

同样是一个 PN 结，二极管只能单向导电，三极管却能放大。差别不在原理，而在 掺杂浓度和几何尺寸——这是简答题与"为什么"型选择题的高频出处。

  1. 发射区重掺杂（约 1018~1019 cm−3）： 发射区的多数载流子数量压倒性占优，正向偏置时几乎只有"发射区向基区注入"这一种电流， 反方向的注入可以忽略。这个比例叫发射效率，重掺杂就是为了让它接近 1。
  2. 基区极薄且轻掺杂（厚度 1 μm 量级，掺杂约 1016 cm−3）： 载流子穿过基区的时间远小于它的寿命，来不及复合就到达了集电结边缘。 复合掉的只是极小一部分，这一小部分才形成基极电流 IB。基区越薄，IB 越小，β 越大。
  3. 集电区面积大、轻掺杂：结面积大便于"接住"载流子，散热好、耐压高； 轻掺杂使集电结的耗尽层主要向集电区扩展，不易击穿。

除了内部结构，还需要外部偏置条件：发射结正向偏置、集电结反向偏置。 这一条是第 0005 课判断"放大区/饱和区/截止区"的核心，这里先记住结论。

一句话本质 三极管是电流控制电流的器件：用很小的 IB 去控制很大的 IC。 但 IC 的能量来自电源 VCC，不是从 IB 里"变"出来的。 它像一个阀门，不是变压器——阀门只负责开度，水流(能量)来自水库。

三、载流子怎么走：I_E = I_B + I_C

以 NPN 管为例，把"放大"这个动作拆成四步，每一步都对应一个电极的电流：

  1. 注入：发射结正偏，发射区的电子大量越过发射结进入基区 （同时基区空穴也向发射区注入，这部分是"无用电流"，靠重掺杂压到很小）。
  2. 扩散：进入基区的电子在浓度差作用下继续向集电结方向扩散， 由于基区很薄，绝大多数电子在复合之前就走到了集电结边缘。
  3. 复合：扩散途中极少数电子与基区空穴复合而消失。复合掉的电子由基极电源补充， 于是形成很小的基极电流 IB（μA 级）。
  4. 收集：集电结反偏，结内电场把到达边缘的电子全部"扫"进集电区， 形成集电极电流 IC（mA 级）。

把三步的电流记成一张"账"：发射极送出的载流子总数 = 集电极收走的 + 基区复合掉的，于是

I_E = I_C + I_B　（节点电流定律 KCL）

数量级感受：IB 约几十 μA，IC 约几 mA，IE 只比 IC 大一点点。 所以工程上常写 IC ≈ IE，而 IC 是 IB 的几十到几百倍。

易错点 不要把 IE = IB + IC 记成 IC = IE + IB； 也不要以为 IB 越大管子"越有劲"。IB 只是控制量， 真正搬运电荷、提供能量的是集电极回路的电源 VCC。

四、β、α 与三种组态

4.1 两个电流放大系数

同一个管子，从不同电极看进去，就得到两个不同的电流放大系数：

β = I_C / I_B　（共射直流电流放大系数，典型 20 ~ 200）
α = I_C / I_E　（共基直流电流放大系数，典型 0.95 ~ 0.99）

两者不是独立的。把 IE = IC + IB 代进 α 的定义： α = IC / (IC + IB)，分子分母同除 IB，得 α = β / (1 + β)。反解就得到 β。

α = β / (1 + β)　　　β = α / (1 − α)

数值感受：β = 100 → α = 100/101 = 0.990；β = 50 → α = 0.980。 α 永远小于 1，所以共基组态没有电流放大，它的本事是电压放大和高频特性好。

4.2 例题 1：由电流求 β、α（基础题，必须秒算）

测得某三极管 IB = 40 μA，IC = 4 mA。求 β、α、IE。若温度升高后 IC 变为 4.4 mA 而 IB 不变，求新的 β。

  1. β = IC/IB = 4 mA / 40 μA = 4000 μA / 40 μA = 100
  2. IE = IC + IB = 4 mA + 0.04 mA = 4.04 mA
  3. α = IC/IE = 4 / 4.04 = 0.990，与 β/(1+β) = 100/101 一致 ✅
  4. 升温后 β′ = 4.4 mA / 40 μA = 110，增大了 10%。

第 4 问是这道题真正的考点：β 不是常数。同一只管子的 β 会随温度、IC、UCE 变化， 这正是第 0008 课要解决"Q 点稳定"问题的根源。

4.3 例题 2：由三个电位反推管型、材料、电极

这是选择题的经典套路：测得三个电极对地电位为 ①3 V、②3.7 V、③9 V，判断管型、材料，并指出 E/B/C。

  1. 找"差 0.7 V 的一对"：② − ① = 0.7 V，正好是硅管发射结的正向压降 → 材料是硅， 这两个电极是 B 和 E，剩下的 ③ 必是 C。
  2. 分 B 和 E：放大状态下 NPN 满足 UB > UE，所以 ② 是基极 B、① 是发射极 E。 （若反过来 UB < UE，就是 PNP。）
  3. 定管型：UC = 9 V 最高，满足 UC > UB > UE → NPN。
  4. 结论：NPN 硅管，①E、②B、③C；且集电结反偏（UC > UB），工作在放大区。
判别口诀 先找 0.7 V（硅）或 0.3 V（锗）的一对定 B、E 与材料；再看 C 的电位排最高还是最低定 NPN / PNP。 三个电位里，离得最远的那个是 C，夹在中间、与另一个差 0.7 V 的是 B。

4.4 三种组态：后面几课的地图

放大电路总有一个电极作为输入与输出的公共端，按公共端命名组态。 这一节只要求"知道有三种、各叫什么、大致什么特点"，具体分析在第 0007、0009 课。

组态公共端输入输出电压增益电流增益相位
共射 CE发射极基极集电极 大（几十~几百）大（β）反相 180°
共集 CC集电极基极发射极 ≈ 1（略小于 1）大（1+β）同相
共基 CB基极发射极集电极 大小于 1（α）同相

一张表记住用途：共射是主放大级（电压电流都放大，最常用）； 共集是缓冲/输出级（电压不放大但带负载能力强，又叫射极跟随器）； 共基用于高频与宽带场合。
