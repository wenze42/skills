Lesson 0007 — 共射放大电路：微变等效电路法

模拟电子电路 · Lesson 0007 / 0020 · 约 45 分钟

前置知识 必须掌握 Lesson 0006（直流通路与 Q 点）： I_BQ、I_CQ、U_CEQ 要能三分钟算完。还要熟悉 Lesson 0005 的输出特性与放大区条件。 这一课的核心是：把非线性的三极管在 Q 点附近"线性化"，然后用纯电阻电路的方法算增益。

上一课只有 Q 点，现在加入交流信号 u_i，要回答三件事： 放大多少倍（A_u）？向信号源要多少电流（R_i）？带得动多重负载（R_o）？

三极管是非线性器件，直接列方程没法解。工程上在 Q 点附近做切线：用电阻 + 受控源等效三极管， 得到微变等效电路。信号足够小时误差可接受，这就是"小信号"的含义。

一、共射电路与交流通路

信号从基极进、集电极出，发射极是公共端，故称"共射"。C₁、C₂ 是耦合电容： 隔直通交，既不把直流送到信号源和负载，也不让负载影响 Q 点。

交流通路怎么画

三条规则（与直流通路正好相反）
  1. 耦合电容、旁路电容一律短路。中频时容量足够大，X_C ≈ 0。
  2. 直流电源 V_CC 置零 → 交流接地。理想电压源内阻为零，对交流来说 +V_CC 端与地等电位。
  3. 电感保留（对交流呈现感抗）。

改造后：C₁、C₂ 变成导线，V_CC 那条横线变成地。 于是 R_b、R_c、R_L 都有一端接地—— R_c 与 R_L 并联，这是本课最重要的结构认识。

注意：直流时 R_c 与 R_L 并不并联，中间隔着 C₂，负载不消耗直流； 只有交流通路里 C₂ 短路，两者才并联。所以 I_CQ 与 R_L 无关，A_u 却与它密切相关。

二、三极管的微变等效模型

思路一句话：在 Q 点附近用切线代替曲线。输入特性在 Q 点的斜率记为 1/r_be， 基极-发射极之间等效为一个电阻；输出特性在放大区近似水平，i_C = βi_b 与 u_CE 无关， 集电极-发射极之间等效为一个受控电流源 βi_b。

r_be = r_bb′ + (1 + β) · 26 mV / I_EQ　（常温，r_bb′ ≈ 200 Ω）
  • r_bb′：基区体电阻，低频小功率管取 200 Ω（题目不给就取 200，按题目为准）。
  • 26 mV：常温热电压，考研固定用 26 mV。
  • I_EQ：I_EQ = (1+β)I_BQ ≈ I_CQ，单位必须用 mA 才得到 Ω。
  • 有的教材写 r_be = 300 + (1+β)26/I_CQ(mA)，以题目给定为准。
关键区别 r_be 是动态电阻（u_be/i_b），不是直流电阻 U_BEQ/I_BQ。 前者几百到几千欧，后者几百千欧。用错这个，整道题全废。

这个模型里没有 V_CC、没有电容，只有三个电阻和一个受控源——它就是一张普通的线性电路图。 接下来的工作全是电路分析：串并联、分压、欧姆定律。

适用条件（三个"必须是"） 必须是中频（忽略结电容，见 Lesson 0014）、小信号（不超出 Q 点附近线性区）、 且工作在放大区。缺一条，模型就不成立。

三、三条公式：A_u、R_i、R_o

输出端 R_c 与 R_L 并联，受控源电流全部流过它们：u_o = −βi_b·(R_c∥R_L)； 输入端 u_i = i_b·r_be。相除即得：

A_u = u_o / u_i = − β · R_L′ / r_be　，　R_L′ = R_c ∥ R_L

这就是共射放大电路最核心的一条公式。负号表示输出与输入反相 180°： u_i 升高 → i_b 增大 → i_c 增大 → R_c 上压降增大 → u_CE 下降。 所以输入正峰时输出为负峰，同刻反号。

另外两个参数描述"这个放大器好不好接"：

R_i = R_b ∥ r_be　，　R_o ≈ R_c
  • 输入电阻 R_i：从输入端看进去，R_b 与 r_be 并联。 因 R_b 有几百 kΩ，故 R_i ≈ r_be（1 kΩ 量级）——这就是共射"输入电阻低"的由来。
  • 输出电阻 R_o：输入源置零后受控源开路，从输出端往回看只剩 R_c。 注意不含 R_L，它是外接负载，不属于放大器本身。
负号到底要不要写 求电压放大倍数时必须写负号（携带相位）；求幅值放大倍数时写 |A_u|。 题目没说明幅值，标准答案通常保留负号并注明"反相"。

四、完整数值例题

题目：共射电路 V_CC = 12 V，R_b = 300 kΩ，R_c = 4 kΩ，R_L = 4 kΩ，β = 50， 硅管 U_BEQ = 0.7 V，r_bb′ = 200 Ω。求 Q 点、r_be、A_u、R_i、R_o。

第 1 步：直流工作点（Lesson 0006）

I_BQ = (12 − 0.7) / 300k ≈ 37.7 μA
I_CQ = 50 × 37.7 μA ≈ 1.88 mA
U_CEQ = 12 − 1.88 mA × 4 kΩ ≈ 4.5 V　（> 0.3 V，放大区 ✅）
I_EQ = (1 + β) I_BQ = 51 × 37.7 μA ≈ 1.92 mA

第 2 步：动态电阻

r_be = 200 + 51 × 26 mV / 1.92 mA = 200 + 690 ≈ 890 Ω

第 3 步：交流负载

R_L′ = R_c ∥ R_L = 4k ∥ 4k = 2 kΩ

第 4 步：三条结果

A_u = − 50 × 2k / 890 ≈ − 112
R_i = R_b ∥ r_be = 300k ∥ 890 ≈ 887 Ω　（≈ r_be）
R_o ≈ R_c = 4 kΩ
量数值说明
I_CQ1.88 mA由 R_b、β 决定
U_CEQ4.5 V约 V_CC/2，位置合适
r_be≈ 890 Ω用 I_EQ（≈ I_CQ）计算
A_u≈ −112负号 = 反相
R_i≈ 887 Ω≈ r_be
R_o≈ 4 kΩ就是 R_c，不含 R_L
如果题目还给了信号源内阻 R_s 常问源电压放大倍数：A_us = A_u · R_i/(R_i + R_s)。 如 R_s = 1 kΩ，则 A_us = −112 × 0.887/1.887 ≈ −53—— 信号在输入端被分掉一半，这正是"输入电阻要尽量大"的原因。

五、常见错误与速查表

五个扣分点

  1. 忘掉 R_L：必须用 R_L′ = R_c ∥ R_L。 本课例题若漏掉 R_L，会得 −225，整整大一倍。
  2. 丢掉负号：只写 112 会被判概念错误。
  3. r_be 公式用错：必须 r_bb′ + (1+β)·26mV/I_EQ， 漏掉 (1+β) 或误用 I_BQ，结果差几十倍。
  4. 单位踩坑：26 mV / I_EQ(mA) 得 Ω；若 I_EQ 用 μA 代入，结果大 1000 倍。
  5. R_o 带上 R_L：测量时负载断开，所以只有 R_c。

速查表

步骤公式要点
① 静态工作点 I_BQ=(V_CC−U_BEQ)/R_b；I_CQ=βI_BQ；U_CEQ=V_CC−I_CQ R_c 先直流，且与 R_L 无关
② 动态电阻 r_be = r_bb′ + (1+β)·26mV/I_EQ r_bb′ ≈ 200 Ω，I_EQ ≈ I_CQ
③ 交流负载 R_L′ = R_c ∥ R_L 交流通路中两者并联
④ 电压增益 A_u = −β R_L′ / r_be 负号 = 反相 180°
⑤ 输入电阻 R_i = R_b ∥ r_be ≈ r_be 共射输入电阻低
⑥ 输出电阻 R_o ≈ R_c 不含 R_L
⑦ 源电压增益 A_us = A_u · R_i/(R_i + R_s) R_s 为信号源内阻

六、Quiz — 考研风格题

三道题分别考增益计算、相位关系和 r_be，都是考场原题难度。

这一课学到了什么

  1. 交流通路：电容短路、V_CC 交流接地，于是 R_c 与 R_L 并联。
  2. 微变等效：r_be 串在基极，βi_b 受控源接在 C、E 之间，非线性变线性。
  3. 三条公式：A_u = −βR_L′/r_be、R_i = R_b∥r_be、R_o ≈ R_c。
  4. 顺序不能乱：Q 点 → r_be → R_L′ → A_u。

这个电路有个致命弱点：I_CQ = βI_BQ，β 随温度和批次变化，Q 点跟着漂。 下一课（Lesson 0008）用分压偏置 + 发射极电阻把 Q 点稳住， 代价是增益下降——"降多少"仍要用本课的微变等效电路算。
