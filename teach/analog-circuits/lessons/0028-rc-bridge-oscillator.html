Lesson 0028 — RC 桥式正弦波振荡电路

模拟电子电路 · Lesson 0028 / 0029 · 约 55 分钟

前置知识 需要 Lesson 0015（反馈的基本概念）、 Lesson 0016（负反馈的作用）、 Lesson 0017（深度负反馈与稳定性） 以及 Lesson 0020（运放应用） 中的同相比例电路。 核心工具只有一个：闭环增益 A_f = A/(1 + AF)，以及"环路增益 AF"这个概念。

前面所有的放大电路都在回答同一个问题：给定一个输入，输出是多少。 振荡器反过来：没有输入，输出自己动起来。它不是"放大信号"，而是把电路内部的噪声 放大成稳定的正弦波。

这件事听起来像永动机，其实不是——振荡器需要直流电源供电，只是把直流能量转换成交流能量。 判断它能不能振荡、振荡在什么频率、幅度多大，全靠环路增益这一把尺子。 这一课讲最经典的 RC 桥式（文氏桥）振荡器；下一课讲 LC 与石英晶体。

一、振荡的两个条件

把放大器接成闭环，输入接地，仍然有输出，这叫自激。 从反馈公式看，闭环增益的分母为零时增益无穷大：

A_f = A/(1 + AF)　⟹　自激条件：1 + AF = 0　⟹　AF = −1

写成幅值与相位两个条件，就是本课的总纲：

相位平衡：φ_A + φ_F = 2nπ　（n = 0, 1, 2, …）
幅度平衡：|A| · |F| = 1

相位条件决定"能不能振"：反馈信号必须与输入同相， 才能自己维持自己。差 180° 就成了负反馈，只会把信号压死。 幅度条件决定"振多大"：环路增益恰好为 1，每次循环补上的能量等于损耗的能量，幅度稳定。

起振用 >，平衡用 = 电路刚上电时，输出为零（或只有微小的热噪声）。要让幅度从零长起来，必须 |AF| > 1，让每次循环的净增益大于 1，幅度像滚雪球一样变大。
幅度变大后，管子的非线性或稳幅元件把增益压下来，最终停在 |AF| = 1。
所以：起振条件 |AF| > 1，平衡条件 |AF| = 1。这两个不能混。

1.1 与"负反馈放大器自激"的区别

第 17 课讲过，负反馈放大器如果环路相移达到 180°、环路增益又大于 1，也会自激—— 那是事故，要设法消除。振荡器是故意让环路满足同样条件， 把自激变成功能。数学条件完全相同，设计意图相反：

负反馈放大器自激正弦波振荡器
目的必须避免必须发生
相位附加相移 180°（通常在高频段）人为设计成 0° 或 360°
幅度|AF| > 1 即自激起振 |AF| > 1，靠稳幅回到 1
波形往往不是纯正弦（可能方波、寄生振荡）靠选频网络保证单一频率

要让振荡器输出纯正弦而不是方波，环路里必须有一个选频网络： 只让某一个频率满足相位条件，其余频率的相移不满足，自然被排除。 RC 桥式用的就是RC 串并联网络。

二、RC 串并联选频网络

这个网络由两部分组成：串联臂 R 与 C 串联， 并联臂 R 与 C 并联。信号从串联臂进、从并联臂取出， 反馈系数就是并联臂阻抗除以总阻抗。

2.1 传递函数推导

用阻抗分压，反馈系数 F = U_o/U_i：

Z_1 = R + 1/(jωC)　，　Z_2 = R ∥ 1/(jωC) = R/(1 + jωRC)
F = Z_2/(Z_1 + Z_2)

把 Z_1、Z_2 代入，分子分母同乘 (1 + jωRC)，整理得：

F = 1 / [ 3 + j(ωRC − 1/(ωRC)) ]

这是一个非常漂亮的结果：实部恒为 3，虚部只随频率变化。 分三种情况：

  • ωRC = 1 时虚部为零，F = 1/3，相移 φ_F = 0；
  • ωRC < 1（低频）时虚部为负，φ_F > 0（超前）；
  • ωRC > 1（高频）时虚部为正，φ_F < 0（滞后）。

令虚部为零，得到谐振角频率与频率：

ω_0 = 1/(RC)　⟹　f_0 = 1/(2πRC)

2.2 为什么选 RC 而不是 LC

低频（几赫兹到几百千赫兹）如果用电感做选频，L = 1/(4π²f²C)。 取 f_0 = 1 kHz、C = 0.1 μF，需要 L ≈ 253 mH——体积大、Q 值低、还有磁芯非线性。 RC 网络用两只电阻两只电容就能实现，成本低、便于集成，这是音频与低频振荡器几乎都用 RC 的原因。

代价是 RC 网络的选频能力弱（Q 只有 1/3），所以对放大器的增益精度要求高， 而且频率稳定性不如 LC 和晶体。这是后话。

三、文氏桥（Wien Bridge）振荡电路

有了"相移为零、幅值 1/3"的选频网络，接下来只需要一个同相放大器： 放大器的相移是 0°（同相），网络在 f_0 处相移也是 0°， 总相移满足 2nπ；只要放大器增益补上网络的 1/3 衰减，就能起振。

同相比例电路的增益是 A_u = 1 + R_f/R_1。幅度条件要求：

A_u · F = (1 + R_f/R_1) · (1/3) ≥ 1　⟹　R_f/R_1 ≥ 2

这就是文氏桥最著名的结论：同相放大器增益至少为 3， 等价于 R_f ≥ 2R_1。实际取略大于 3（如 3.1～3.3），保证可靠起振。

3.1 为什么叫"桥"

把电路画成电桥形式会更清楚：左边一臂是 RC 串并联网络（正反馈臂）， 右边一臂是 R_f、R_1（负反馈臂），两个臂的中点分别接运放的同相端与反相端， 输出端与地是两个"桥"的顶点。四个臂构成一个桥，故名文氏桥。

这种"正反馈选频 + 负反馈定增益"的双臂结构有个巨大好处： 选频与增益解耦。调 f_0 只需同步改变选频网络的 R、C， 不会影响增益；调增益只需改 R_f，不影响频率。

3.2 相位条件的逐项核对

环节在 f₀ 处的相移说明
同相放大器 A0°输入在同相端，输出与输入同相
RC 串并联网络 F0°虚部 ωRC − 1/(ωRC) = 0
环路总相移0° = 2nπ（n=0）满足相位平衡 ✅
幅度|A|·|F| = 3 × 1/3 = 1平衡；起振时略大于 1
两个反馈别接反 RC 网络必须接同相端（正反馈），R_f、R_1 必须接反相端（负反馈）。 接反了会变成两级负反馈，相位差 180°，永远不振。这是实验课最常见的故障。

四、起振、稳幅与波形

上电瞬间，电路里只有电阻热噪声和运放失调，幅度大约微伏级。 只要 |AF| > 1，每一轮循环幅度乘以 |AF|，呈指数增长：

U_m(t) = U_m(0) · e^σt　，　σ ≈ (|AF| − 1)/(RC)　（近似）

增长不会无限持续。当幅度接近电源电压时，运放进入非线性（输出限幅、压摆率受限）， 等效增益下降；如果用了热敏电阻，增益还会随温度主动下降。最终 |AF| 被拉回 1，幅度稳定，形成等幅正弦波。

注意波形形状：起振段幅度小、周期相同；增长段每个周期幅度更大；稳幅段幅度恒定。 频率始终由选频网络决定，与幅度无关——这正是线性选频网络的好处。

4.1 五种稳幅措施

措施原理优点缺点
R_f 用 NTC 热敏电阻 幅度↑ → 电流↑ → 温度↑ → R_f↓ → A↓ 连续、波形好 热惯性大，稳定慢；需足够功耗
R_1 用 PTC 热敏电阻（或钨丝灯泡） 幅度↑ → 温度↑ → R_1↑ → A↓ 灯泡同时起指示作用，经典方案 灯泡体积大、寿命有限
二极管双向限幅 幅度超过导通阈值后等效电阻下降 简单、快 削波引入谐波失真
场效应管压控电阻 整流滤波得到与幅度相关的栅压，改变沟道电阻 失真小、可调 电路复杂
AGC 自动增益控制 峰值检波 → 误差放大 → 控制增益 精度高，适合仪器 环路稳定性要设计
稳幅的方向不能反 记住一句话：幅度越大，增益必须越小。 若热敏电阻接错（用 PTC 放在 R_f 位置），幅度增大时增益反而增大， 结果是"要么不振，要么幅值冲到电源轨变成方波"。

4.2 起振裕量与波形失真的折中

|AF| 取得太接近 1，起振慢、易受温度影响停振；取得太大，稳幅时非线性深， 波形失真大、谐波多。工程经验：

  • 用热敏电阻稳幅：A 取 3.05～3.2（裕量 2%～7%）；
  • 用二极管限幅：A 可取 3.5 以上，但失真明显；
  • 要求低失真（< 0.1%）：必须用 AGC 或 PTC 灯泡，且 A 只比 3 大一点点。

五、频率调节与实用设计

5.1 同轴双联电位器

f_0 = 1/(2πRC)，要连续调频，必须同时改变两个 R （串联臂与并联臂的 R），且保持两者相等。做法是用同轴双联电位器： 一个旋钮带动两个阻值相同的电位器。

如果只改一个 R，网络不再是"对称"的，F 在谐振处不再等于 1/3， 相位条件也被破坏，输出频率会偏离公式、幅度也会跳变。

5.2 用波段开关切换电容

电位器的调节范围有限（一般 10 倍以内），宽频段覆盖要靠切换 C：

频段CR（f₀ 中心）覆盖范围（R 变 10 倍）
低频1 μF15.9 kΩ100 Hz～1 kHz
中频0.1 μF15.9 kΩ1 kHz～10 kHz
高频0.01 μF15.9 kΩ10 kHz～100 kHz

5.3 运放带来的频率上限

振荡频率不能超过运放的能力，两个硬约束：

增益带宽积：f_0 · A_u < GBW　⟹　f_0 < GBW/3
压摆率：2πf_0 U_om < SR

例如 GBW = 1 MHz 的通用运放，文氏桥增益为 3，理论最高 f_0 ≈ 333 kHz； 若输出幅度 5 V，SR = 0.5 V/μs 时， f_0 < SR/(2πU_om) = 0.5×10⁶/(2π×5) ≈ 15.9 kHz。 压摆率往往先成为瓶颈——这是高频文氏桥必须选高速运放的原因。

六、四道完整例题

例题 1：设计 f₀ = 1 kHz 的选频网络

题：要求文氏桥振荡频率 f_0 = 1 kHz，电容取 C = 10 nF， 求 R；若手头只有 E24 系列电阻，实际频率是多少？

解：由 f_0 = 1/(2πRC) 反解

R = 1/(2π f_0 C) = 1/(2π × 1000 × 10 × 10⁻⁹) = 1/(6.283 × 10⁻⁵) ≈ 15.9 kΩ

E24 系列没有 15.9 kΩ，最接近的是 16 kΩ。实际频率：

f_0' = 1/(2π × 16k × 10n) = 1/(1.0053 × 10⁻³) ≈ 994.7 Hz

相对误差 (994.7 − 1000)/1000 = −0.53%，对音频振荡器完全够用。 若要精确 1 kHz，用 E96 系列的 15.8 kΩ 或 15.9 kΩ，误差可降到 0.1% 以内。

R、C 怎么选 同样的 f_0，R 和 C 可以互换。取舍原则：
· R 太小（几百欧）→ 运放输出电流大，增益误差变大；
· R 太大（几兆欧）→ 漏电流、噪声、分布电容影响显著；
· C 用薄膜电容（涤纶、聚丙烯），温度系数小、损耗低；不要用陶瓷 Y5V 或电解电容，容量随温度漂移会让 f_0 跑掉。
工程常用 R = 1 kΩ～100 kΩ、C = 1 nF～1 μF。

例题 2：起振所需的 R_f

题：文氏桥中 R_1 = 10 kΩ。 ① 求起振的临界 R_f；② 若取 R_f = 22 kΩ，环路增益是多少？ ③ 该电路能否可靠起振？

解①：临界条件是 A = 3，即

1 + R_f/R_1 = 3　⟹　R_f = 2R_1 = 20 kΩ

解②：取 22 kΩ 时

A = 1 + 22/10 = 3.2　，　|AF| = 3.2 × 1/3 = 1.067

解③：|AF| = 1.067 > 1，满足起振条件。 裕量 6.7%，属于工程常用范围（3%～10%）。起振后幅度增大， 稳幅元件把 R_f 从 22 kΩ 压到 20 kΩ，A 回到 3， |AF| = 1，进入等幅振荡。

验算：若电源为 ±12 V，运放输出饱和电压约 ±10.5 V。 稳幅后输出幅度必须低于这个值，否则波形削顶。设计时应让稳幅点对应的幅度 比电源轨低 2～3 V，给运放留出线性区。

例题 3：热敏电阻稳幅的定量选型

题：文氏桥取 R = 1.6 kΩ、C = 0.1 μF，R_1 = 1 kΩ。 R_f 用 NTC 热敏电阻，25 °C 时 2.2 kΩ，温度系数 −4%/K， 热阻 R_th = 1 K/mW。① 求 f_0；② 求稳幅时 R_f 应从 2.2 kΩ 降到多少； ③ 需要温升多少？④ 需要多大功耗与输出幅度？

解①：

f_0 = 1/(2π × 1.6k × 0.1μ) = 1/(1.005 × 10⁻³) ≈ 995 Hz

解②：稳幅时 A = 3，即 R_f = 2R_1 = 2.0 kΩ。相对变化

ΔR/R = (2.0 − 2.2)/2.2 = −9.1%

解③：温度系数 −4%/K，所需温升

ΔT = 9.1%/4% = 2.3 K

解④：热阻 1 K/mW，所需功耗

P = ΔT/R_th = 2.3 mW

该电流同时流过 R_f 与 R_1，但只有 R_f 是热敏元件； 它上面的功耗为 P = I²R_f，正是用来加热自身的功率：

I = √(P/R_f) = √(2.3 mW / 2.2 kΩ) ≈ 1.02 mA
U_o(rms) = I × (R_f + R_1) = 1.02 mA × 3.2 kΩ ≈ 3.27 V

峰值 3.27 × 1.414 ≈ 4.6 V，±12 V 供电有充足余量，方案可行。

反面验算：如果沿用例题 2 的 R_f = 22 kΩ、R_1 = 10 kΩ， 稳幅电流只有 3.27 V/32 kΩ ≈ 0.1 mA，P ≈ 0.2 mW， 温升仅 0.23 K，R_f 只降约 0.9%，远到不了 9.1% 的平衡点。 结果就是幅度一路涨到运放限幅，输出变成方波。 热敏电阻稳幅必须核算功耗，不能只看阻值。

例题 4：判断三个电路能否振荡

题：下列三个电路都用了 RC 串并联网络，判断能否产生正弦振荡。

(a) 反相放大器 A = −3，RC 网络接在反馈回路中。

判断：f_0 处网络相移 0°，反相放大器相移 180°， 环路总相移 180°。相位条件是 2nπ，180° 不满足。 网络相移范围只有 +90°～−90°，无论频率怎么变，总相移都到不了 0° 或 360°， 所以不能振荡。

(b) 同相放大器 R_f = 15 kΩ、R_1 = 10 kΩ，网络接同相端。

判断：A = 1 + 15/10 = 2.5，|AF| = 2.5/3 = 0.833 < 1。 相位条件满足，但幅度条件不满足，任何扰动都会逐周期衰减， 不能维持振荡（只能看到逐渐消失的衰减正弦）。

(c) 同相放大器 R_f = 22 kΩ、R_1 = 10 kΩ，RC 网络误接到反相端。

判断：放大器本身是同相（0°），但网络接到反相端后构成负反馈， 环路等效相移 180°，不满足相位条件，不能振荡。

判断三步法 ① 找环路：从放大器输入端出发，经放大器、反馈网络回到输入端；
② 算相位：φ_A + φ_F 是否为 2nπ；
③ 算幅度：|A|·|F| 是否 > 1（起振）或 = 1（平衡）。
相位不过关直接判死；相位过了再看幅度。两步都过才是振荡器。

七、易错点与速查表

七个高频错误

  1. 把起振条件写成 |AF| = 1。等于 1 只能维持，不能从零起振； 起振必须严格大于 1。
  2. 忘记 F = 1/3，直接用 A = 3。 正确逻辑是 A·F ≥ 1 → A ≥ 3；若网络参数不对称，F 不再是 1/3， 增益要求也要跟着变。
  3. 把 RC 网络接反相端。接反相端变成负反馈，相位差 180°，不振。
  4. 用 f_0 = 1/(2πRC) 时 R、C 取错对象。 式中的 R、C 是串联臂与并联臂各自的 R、C， 两臂必须相等；不是两臂电阻之和。
  5. 只调一个 R 变频。必须同步调两个 R（双联电位器），否则 F ≠ 1/3、 相位失衡。
  6. 稳幅方向接反。NTC 应放在 R_f 位置（幅度↑ → R_f↓ → A↓）； 放在 R_1 位置会越振越猛。
  7. 忽略运放压摆率。高频、大幅度时正弦波变三角波，甚至停振； 先算 2πf_0U_om < SR。

这一课学到了什么

  1. 振荡的本质是自激：环路增益 AF = −1， 拆成相位平衡 φ_A+φ_F = 2nπ 与幅度平衡 |AF| = 1。
  2. 起振与平衡不是一回事：起振要 |AF| > 1， 稳幅后回到 = 1；中间靠非线性或热敏元件完成过渡。
  3. RC 串并联网络的三个数：F = 1/[3+j(ωRC−1/ωRC)]、 谐振时 F = 1/3、φ = 0、f_0 = 1/(2πRC)。
  4. 文氏桥的增益门槛：同相放大 A = 1+R_f/R_1 ≥ 3， 即 R_f ≥ 2R_1；RC 网络必须接同相端构成正反馈。
  5. 稳幅的方向：幅度增大时增益必须减小。NTC 放 R_f、 PTC/灯泡放 R_1，并且要核算热敏元件的功耗。
  6. 调频要同步：两个 R 用同轴双联电位器一起变， 宽频段靠切换 C；高频受 GBW 与压摆率双重限制。

下一课（Lesson 0029）把选频网络从 RC 换成 LC 与石英晶体： 频率更高、Q 值更大、稳定度从 10⁻³ 提升到 10⁻⁶ 甚至 10⁻⁹。 你会发现，"相位平衡 + 幅度平衡"这套判据原封不动，只是网络换了一副面孔。
