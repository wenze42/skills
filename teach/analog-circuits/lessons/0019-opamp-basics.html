Lesson 0019 — 集成运放基础

模拟电子电路 · Lesson 0019 / 0020 · 约 35 分钟

前置知识 需要 Lesson 0013（差分放大电路）、 Lesson 0016（1+AF）、 Lesson 0017（深度负反馈）、 Lesson 0018（互补输出级）。 运放内部就是把前三课的内容焊在一起的产物。

一、运放内部：一颗芯片里的四级电路

集成运算放大器（Operational Amplifier，简称运放）不是新原理，而是把前面十几课 学过的单元电路集成到一颗芯片里。打开它的内部框图，只有四块：

组成部分典型电路主要贡献的指标
输入级 差分放大电路（BJT 或 MOS），双端输入、单端输出 决定 R_id（输入电阻）、K_CMR（共模抑制比）、U_IO（失调）、噪声
中间级 共射（或共源）放大，常带相位补偿电容 提供绝大部分电压增益 A_od（可达 10⁵ 以上）
输出级 互补对称射极跟随器（甲乙类），带过流保护 决定 R_o（输出电阻小）、最大输出摆幅、带载能力
偏置电路 电流源（镜像电流源、微电流源等） 为各级提供稳定的静态电流，提高电源抑制能力
一条因果链 差分输入 → 共模抑制强、能直接放大直流；共射中间级 → 增益极高； 互补输出 → 输出电阻低、能带负载。这正好对应运放的三条理想假设， 所以"理想运放"不是虚构，而是集成工艺把这些指标推到了极端。

二、符号与引脚

  • 两个输入端：标 "+" 的是同相输入端（u_+）， 标 "−" 的是反相输入端（u_−）。输出与同相端同相，与反相端反相。
  • 一个输出端：u_o。
  • 两个电源端：+V_CC 与 −V_CC（或双电源 ±V）， 电路图中常省略，但它是输出摆幅的物理上限——输出永远不可能超过电源轨。
  • 常见封装：8 脚双运放（如 LM358）、14 脚四运放，另有调零、补偿引脚。
u_o = A_od · (u_+ − u_−)　（开环时）
u_id = u_+ − u_− 称为差模输入电压

三、主要参数

参数符号典型值含义与影响
开环差模电压增益A_od10⁵（约 100 dB） 开环时差模增益，越大越接近"虚短"
差模输入电阻R_id1 MΩ~10¹² Ω 越大越接近"虚断"，对信号源负载越轻
输出电阻R_o几十~几百 Ω 越小带负载能力越强
共模抑制比K_CMR80~120 dB 抑制共模干扰（温漂、50 Hz 干扰）的能力，越大越好
输入失调电压U_IO1~10 mV 输入为零时输出不为零所需的补偿电压，是直流精度的主要限制

四、理想运放三条假设 → 虚短与虚断

把实际参数推向极端，得到理想运放。只有三条：

① A_od → ∞　② R_id → ∞　③ R_o → 0

虚短的推导（一条极限，不是玄学）

运放工作在线性区时，输出电压 u_o 是有限值（受电源限制）。 由 u_o = A_od·(u_+ − u_−) 反解：

u_+ − u_− = u_o / A_od →（A_od → ∞）→ 0
故 u_+ = u_−，两端电位相等但并未短接 → "虚短"

虚断的推导

I_+ = u_+ / R_id → 0，　I_− = u_− / R_id → 0
故 I_+ = I_− = 0，输入端开路但仍有电位 → "虚断"
最重要的一条前提（必考） 虚短只在运放工作在线性区时成立，即电路必须引入负反馈， 且输出没有饱和。若运放工作在非线性区（比较器、开环、正反馈）， 输出被推到 ±U_omax，此时 u_+ 与 u_− 不再相等，虚短失效， 但虚断仍然成立（R_id 极大与工作区无关）。 0020 讲比较器时全靠这一条区分。

六、考研例题（带步骤）

例题 1：虚短到底有多"短"

某运放 A_od = 10⁵，接成闭环后输出电压 u_o = 10 V。求差模输入电压 u_id， 并说明"虚短"近似的误差量级。

解

  1. 由 u_o = A_od·u_id 得 u_id = 10 / 10⁵ = 10⁻⁴ V = 0.1 mV。
  2. 0.1 mV 相对于 10 V 的输出是 10⁻⁵ 量级，相对于常见的伏级输入信号是万分之一以下。
  3. 结论：只要 A_od 足够大且工作在线性区，把 u_id 当作 0（虚短）带来的误差 在工程精度内可忽略。若 A_od 只有 10³，u_id 就是 10 mV，近似开始不可靠。

例题 2：转换速率 SR 限制了最高频率

某运放 SR = 0.5 V/μs，要求输出幅值 U_om = 10 V 的正弦波。求最高不失真频率 f_max。

解

  1. 正弦波的最大变化率出现在过零点，其值为 du/dt|max = 2πf·U_om。
  2. 不失真条件：2πf·U_om ≤ SR，故 f_max = SR/(2πU_om)。
  3. 代入：SR = 0.5 V/μs = 0.5 × 10⁶ V/s， f_max = 0.5×10⁶ / (2π × 10) ≈ 7.96 kHz。
  4. 解读：超过这个频率，输出跟不上输入的变化，正弦波会被"削"成三角波。 注意这是大信号限制，与小信号带宽（GBW）是两回事，考试常放在一起对比。

例题 3：GBW 与闭环带宽

运放 GBW = 1 MHz，接成闭环增益 A_f = 100 的放大电路，求闭环带宽。

解

  1. 由增益带宽积守恒：A_f · BW_f = GBW。
  2. BW_f = GBW / A_f = 10⁶ / 100 = 10 kHz。
  3. 这与 0016 的 BW_f = (1+AF)·BW 是同一件事的两种写法： 闭环增益越低，带宽越宽；增益为 1（跟随器）时带宽就等于 GBW。

八、Quiz — 考研风格题

这一课学到了什么

  1. 运放是前面所有单元电路的集成：差分输入、共射增益、互补输出、电流源偏置。
  2. 三条理想假设导出两条黄金法则：虚短（u_+ = u_−）、虚断（I_+ = I_− = 0）。
  3. 虚短有前提：必须线性区 + 负反馈；非线性区虚短失效、虚断仍成立。
  4. 两个频率限制要分清：小信号看 GBW，大信号看 SR。

最后一课（Lesson 0020）把运放用起来：线性区的比例、加减、积分、微分， 非线性区的比较器与方波发生器，最后用运放搭出能自己产生正弦波的 RC 桥式振荡器——正好把 0017 的"自激"从敌人变成工具。
