Lesson 0006 — 直流通路与静态工作点 Q

模拟电子电路 · Lesson 0006 / 0020 · 约 40 分钟

前置知识 必须掌握 Lesson 0004（BJT 结构与原理） 和 Lesson 0005（输出特性与三种工作状态）。 尤其是：放大区要求发射结正偏、集电结反偏；I_C = βI_B； I_E = I_B + I_C = (1+β)I_B。这一课回答一个最实际的问题—— 没有输入信号时，管子到底停在哪一点？

放大电路里，三极管同时干两件事：建立直流工作点，以及放大交流小信号。 这两件事必须分开算——这就是模电最核心的方法论：先直流、后交流，先静态、后动态。

所谓静态，指输入信号 u_i = 0 时电路的状态。此时各处的电压、电流都是直流量， 记作 I_BQ、I_CQ、U_CEQ，它们在输出特性曲线上确定一个点，叫静态工作点 Q （Quiescent point）。Q 点定不下来，后面的 r_be、A_u、R_i、R_o 全都无从谈起。

路线：直流 → 图解 → 计算 → 失真。

一、直流通路怎么画

直流通路是只考虑直流分量时的等效电路。画法只有三条规则，但每年都有人栽在第三条上：

三条规则（背下来）
  1. 耦合电容、旁路电容一律开路。电容的容抗 X_C = 1/(2πfC)，直流时 f = 0，容抗无穷大 → 相当于断开。
  2. 电感一律短路。直流通路里电感没有感抗，只剩导线电阻，一般忽略 → 用导线代替。
  3. 信号源置零。电压源短路（u_i = 0 即两端等电位），电流源开路。直流电源 +V_CC 要保留——它正是 Q 点的能量来源。

检验标准很简单：每条支路都要能通直流。上图基极回路 V_CC → R_b → 发射结 → 地、 集电极回路 V_CC → R_c → 集电极 → 发射极 → 地 都通，Q 点才有定义。

为什么要先算直流 r_be 与 I_EQ 成反比，Q 点一错，微变等效参数全错。 考研大题第一步永远是"求静态工作点"。

二、图解法：直流负载线与输出特性

图解法把电路分成"外部"和"管子"两半，各自画一条线，交点就是解。 对集电极回路列 KVL：

U_CE = V_CC − I_C · R_c　　⟹　　I_C = (V_CC − U_CE) / R_c

这是一条直线，叫直流负载线。它在两个坐标轴上的截距特别有用：

  • 令 U_CE = 0 → I_C = V_CC / R_c（纵轴截距，管子饱和时的假想电流）
  • 令 I_C = 0 → U_CE = V_CC（横轴截距，管子截止时的管压降）
  • 斜率 = −1/R_c：R_c 越小，负载线越陡

另一条线是三极管的输出特性曲线族——给定一个 I_B，就有一条 I_C–U_CE 曲线。 负载线与某条曲线的交点，就是在这组 I_B 下的工作点。基极回路提供的 I_BQ 决定了落在哪条曲线上。

上图取 V_CC = 12 V、R_c = 4 kΩ，负载线从 (0, 3 mA) 连到 (12 V, 0)。 当 I_BQ = 40 μA、β = 40 时 I_CQ = 1.6 mA，对应 U_CEQ = 12 − 1.6 × 4 = 5.6 V， 交点落在放大区中部——这是一个"舒服"的 Q 点。

图解法的考研问法 常见三问：①画负载线；②标 Q 点并读出 I_CQ、U_CEQ； ③R_b 增大时 Q 怎么动？I_BQ 减小 → 沿负载线右下移，趋向截止。

三、计算法：四条公式定 Q

考试中绝大多数情况用计算法，因为快且准。以最基本的固定偏置共射电路为例， 基极回路由 V_CC、R_b 和发射结组成：

I_BQ = (V_CC − U_BEQ) / R_b
I_CQ = β · I_BQ
U_CEQ = V_CC − I_CQ · R_c

三极管在放大区时 U_BEQ ≈ 0.7 V（硅管），这是唯一需要记的常数。 集电极电流还可以写成 I_CQ = β(V_CC − U_BEQ)/R_b，与 R_c 无关—— 这说明 R_c 只影响 U_CEQ，不影响 I_CQ，这是固定偏置电路的重要特征。

算完之后必须做两件事：

  1. 验算放大区：U_CEQ > U_CES ≈ 0.3 V 且 I_BQ > 0。否则管子不在放大区，公式全部失效。
  2. 求 I_EQ：I_EQ = (1+β)I_BQ ≈ I_CQ。下一课的 r_be 要用它。
什么时候不能用计算法 发射极串了 R_e 或用分压偏置时，基极回路不再是"一个电阻 + 一个结"， 要先做戴维南等效，见 Lesson 0008。

Q 点选取原则

  • 居中：U_CEQ ≈ V_CC / 2。这样向饱和、向截止两个方向的余量接近相等，U_om 最大。
  • 看信号大小：小信号放大可以取低一些（省电、噪声小）；大信号（如功放前级）必须居中，否则先削波。
  • 看温度与 β 分散性：固定偏置的 I_CQ = βI_BQ 直接随 β 变化，R_b 一固定，换一只管子 Q 点就漂。要稳定就得换分压偏置（Lesson 0008）。
  • 可量化：调 Q 点不是"看着顺眼"，而是让 U_CEQ − U_CES 与 I_CQ R_L′ 尽量相等。

四、Q 点偏移：饱和失真与截止失真

Q 点还要求"位置对"：大致落在负载线中点，正负半周才有对称的摆动空间。 Q 点偏了，大信号波形就会被"削平"，这叫非线性失真。

为什么是"这一侧"被削

记住一条因果链：u_i ↑ → i_B ↑ → i_C ↑ → u_CE = V_CC − i_C R_c ↓。 所以输出与输入反相：输入正半周，输出走低。

  • Q 点偏高（I_CQ 大、U_CEQ 小）：输入正半周使 i_C 继续增大， 很快撞上饱和边界 U_CES，u_CE 降不下去，波形的谷底被削平。 同时 i_C 的正半周顶部被削平。
  • Q 点偏低（I_CQ 小、U_CEQ 接近 V_CC）：输入负半周使 i_C 减小， 很快进入截止（i_C = 0），u_CE 升不上去，波形的峰顶被削平。
示波器上怎么认（高频选择题） 看输出波形：
· 底部平（负峰削平）→ Q 点偏高 → 饱和失真 → 应增大 R_b（减小 I_BQ）或减小 R_c；
· 顶部平（正峰削平）→ Q 点偏低 → 截止失真 → 应减小 R_b（增大 I_BQ）。
再补一条：若输入是 u_i、输出 u_o 反相，别把输入波形拿来判失真方向。

最大不失真输出电压幅度

Q 点给定后，输出能"摆"多大，取决于它离两个边界哪个更近：

U_om = min( U_CEQ − U_CES , I_CQ · R_L′ )　，　R_L′ = R_c ∥ R_L
  • U_CEQ − U_CES：向下摆到饱和还剩多少余量；
  • I_CQ · R_L′：向上摆到截止还剩多少余量（交流负载线的纵轴截距）。

取两者中较小的那个，因为只要有一侧先撞墙，波形就开始削。 这也是"Q 点选中点"的量化依据。

五、典型考研例题

题目：固定偏置共射电路，V_CC = 12 V，R_b = 470 kΩ，R_c = 3 kΩ，β = 60， 硅管 U_BEQ = 0.7 V，负载开路。求静态工作点，并判断最大不失真输出电压幅度。

第一步：基极回路

I_BQ = (12 − 0.7) / 470k = 11.3 V / 470 kΩ ≈ 24 μA

第二步：集电极电流

I_CQ = β · I_BQ = 60 × 24 μA ≈ 1.44 mA

第三步：管压降

U_CEQ = 12 − 1.44 mA × 3 kΩ = 12 − 4.32 ≈ 7.7 V

第四步：验算。U_CEQ = 7.7 V > U_CES ≈ 0.3 V，且 I_BQ > 0， 管子工作在放大区，前面用的 I_C = βI_B 成立 ✅

第五步：最大不失真幅度（负载开路，R_L′ = R_c = 3 kΩ）

U_om = min(7.7 − 0.3, 1.44 mA × 3 kΩ) = min(7.4 V, 4.3 V) = 4.3 V

结论：输入信号逐渐加大时，先出现截止失真——因为向上摆的余量（4.3 V）小于向下摆的余量（7.4 V）。 要扩大动态范围，应把 Q 点下移（增大 R_b），让两个余量接近相等。

第二问常见变体 若 R_b 改为 300 kΩ：I_BQ = 37.7 μA，I_CQ = 2.26 mA，U_CEQ = 5.2 V， Q 点上移、余量变小，更易饱和失真。这类"改一个电阻，Q 怎么动"是选择题常客。

六、易错点与速查表

五个高频错误

  1. 直流通路里留着耦合电容。C₁、C₂ 必须开路，否则基极回路变成"断路 + 电容"，I_BQ 根本算不出来。
  2. 把 V_CC 也"置零"。置零的只有信号源，直流电源是 Q 点的来源，必须保留。
  3. 用 U_BEQ = 0 硬算。硅管一律 0.7 V，用 0 会让 I_BQ 偏差 6% 以上。
  4. 算完不验算放大区。若算出 U_CEQ < 0.3 V 或为负，说明假设错误，管子已在饱和区，I_C = βI_B 不成立。
  5. 把负载线截距记反。纵轴截距是 V_CC/R_c，横轴截距是 V_CC；斜率是 −1/R_c。

速查表

项目公式 / 结论要点
直流通路 电容开路、电感短路、信号源置零、V_CC 保留 先画通路，再列方程
基极电流 I_BQ = (V_CC − U_BEQ) / R_b 硅管 U_BEQ = 0.7 V
集电极电流 I_CQ = β I_BQ 仅放大区成立
管压降 U_CEQ = V_CC − I_CQ R_c 必须 > U_CES ≈ 0.3 V
直流负载线 U_CE = V_CC − I_C R_c 截距 V_CC/R_c 与 V_CC，斜率 −1/R_c
Q 点偏高 饱和失真，输出谷底削平 增大 R_b 或减小 R_c
Q 点偏低 截止失真，输出峰顶削平 减小 R_b
最大不失真幅度 U_om = min(U_CEQ − U_CES, I_CQ R_L′) 取小者，两侧余量相等时最大

七、Quiz — 考研风格题

下面 3 道题覆盖本课全部考点，选完立刻能看到解析。

这一课学到了什么

  1. 直流通路三条规则：电容开路、电感短路、信号源置零，但 V_CC 保留。
  2. 两种定 Q 的方法：图解法是"负载线 ∩ 输出特性"，计算法是四条公式，考试以计算法为主。
  3. Q 点决定失真类型：偏高饱和（削谷底）、偏低截止（削峰顶），调节 R_b 是最直接的手段。
  4. 动态范围：U_om 由较近的那个边界决定，Q 点居中时最大。
