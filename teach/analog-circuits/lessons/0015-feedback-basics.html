Lesson 0015 — 反馈的基本概念与四种组态

模拟电子电路 · Lesson 0015 / 0020 · 约 35 分钟

前置知识 需要 Lesson 0007（共射放大电路）、 Lesson 0012（多级放大） 和 Lesson 0014（频率响应）。 你至少要能一眼看出共射、共集、共基三种组态的相位关系——瞬时极性法全靠它。

前十四课我们一直在“开环”地看放大电路。这一课开始在输出与输入之间拉一根线， 把输出的一部分送回去。增益、带宽、失真随之全变，甚至可能自己振荡—— 反馈是模电后半程的总开关。

一、反馈的定义与框图

反馈：把放大电路输出量（电压或电流）的一部分或全部， 通过反馈网络送回输入回路，与输入量进行比较， 用比较的结果去控制净输入量。带反馈的放大电路称为闭环放大电路， 原来的放大电路称为基本放大电路（开环）。

X_id = X_i − X_f　　X_o = A · X_id　　X_f = F · X_o
A_f = X_o / X_i = A / (1 + AF)
量名称含义
A开环增益基本放大电路本身的增益，不含反馈
F反馈系数反馈网络把输出量送回输入端的比例，F = X_f / X_o
AF环路增益信号绕“放大 → 反馈”一整圈获得的总增益
1 + AF反馈深度闭环后净输入被削弱的倍数，也是性能改善的倍数
A_f闭环增益加反馈后整个电路的增益，A_f = X_o / X_i

分母 1 + AF 是整个负反馈理论的“心脏”。它大于 1，说明反馈削弱了净输入， 是负反馈；它在 0 与 1 之间，说明反馈增强了净输入，是正反馈； 它等于 0，闭环增益趋于无穷大，电路不需要输入就能输出——这就是自激， 我们会在 Lesson 0017 专门处理。

二、有无反馈的判断

判断有没有反馈，只需要问一个问题：输出回路有没有一条通路把信号送回输入回路？ 具体做法是在电路图上找“跨接”在输出与输入之间的元件（电阻、电容、导线）， 看它是否把输出节点连到了输入节点。

  • 无反馈：固定偏置共射只有 R_b、R_c，输出只连 V_CC 和地，没有元件回到输入。
  • 有反馈：分压偏置共射在发射极串 R_e，其电压又影响 U_BE，等于把输出信息送回输入。
  • 局部反馈：反馈只出现在某一级内部；考研题问“有没有反馈”通常指级间反馈。
易错点 不能因为“有电阻连到输入端”就判有反馈：V_CC 在交流通路里是地，接 V_CC 的电阻不构成反馈通路。 晶体管内部的 C_bc 除非题目特别说明，一律忽略。

三、正反馈与负反馈：瞬时极性法

反馈送回来的信号可能削弱净输入，也可能增强净输入。削弱的是负反馈 （改善性能），增强的是正反馈（振荡器故意使用，普通放大电路里是灾害）。 判断方法是瞬时极性法：

瞬时极性法四步
  1. 假设输入信号对地的瞬时极性为 ⊕（只假设一个瞬间，不看直流）。
  2. 沿信号传输路径逐级标极性：共射反相（⊕ 进 ⊖ 出）、共集同相、共基同相； 运放反相输入端反相、同相输入端同相。
  3. 沿反馈路径把极性送回输入回路，得到反馈信号的瞬时极性。
  4. 比较：反馈信号使净输入减小 → 负反馈；使净输入增大 → 正反馈。

以共射电路为例：发射极电阻 R_e 未并联旁路电容。设基极瞬时极性为 ⊕， 集电极反相为 ⊖，发射极跟随基极变化为 ⊕。发射极电压 u_f 升高后， U_BE = u_i − u_f 反而减小，净输入被削弱，所以是负反馈； 反馈与输入分别加在基极和发射极（不同节点），所以是串联； 反馈取自发射极电流在 R_e 上的压降，所以是电流反馈。 合起来是电流串联负反馈。

并联反馈怎么比 串联比电压：u_id = u_i − u_f；并联比电流：i_id = i_i − i_f。 反馈电流抵消输入电流、使净输入减小，就是负反馈。

四、交流反馈与直流反馈

同一个反馈元件，在直流通路和交流通路里可能作用完全不同。 判断方法是画直流通路（电容开路、电感短路）和交流通路 （电容短路、直流电源置地），分别看反馈通路是否还存在：

反馈通路存在于名称主要作用
直流通路直流反馈稳定静态工作点 Q，抑制温漂
交流通路交流反馈改善动态性能：增益、带宽、失真、输入输出电阻
两者都有交直流反馈同时稳定 Q 点和动态性能

典型例子是发射极电阻：R_e 无旁路时，直流和交流都经过它，是交直流反馈； 并联 C_e 后，直流仍走 R_e（稳定 Q 点），交流被短路（无交流反馈，增益不被压低）。 这就是共射电路既能稳定工作点、又能保持高增益的原因。

约定 本课及 Lesson 0016、0017 说“负反馈”时，默认指交流负反馈。

五、四种组态与判别口诀

组态由输出端怎么取样和输入端怎么比较共同决定，两两组合正好四种。

5.1 输出端：电压反馈还是电流反馈

用输出端短路法：令输出电压 u_o = 0（把输出端对地短路）， 看反馈信号是否消失。

  • 反馈消失 → 反馈取自输出电压 → 电压反馈。
  • 反馈仍存在 → 反馈取自输出电流 → 电流反馈。

电压反馈稳压（R_o 减小），电流反馈稳流（R_o 增大）。

5.2 输入端：串联反馈还是并联反馈

看反馈信号与输入信号在输入端的连接方式：

  • 接在不同节点（一个在基极、一个在发射极；或一个在同相端、一个在反相端） → 两者以电压形式相加减 → 串联反馈，输入电阻增大。
  • 接在同一节点 → 两者以电流形式相加减 → 并联反馈，输入电阻减小。

5.3 电压串联负反馈

反馈电压 u_f 由 u_o 经 R_f、R_1 分压得到，与 u_i 分别接在两个输入端，以电压形式串联相减。 这就是电压串联负反馈：稳定输出电压、提高输入电阻、减小输出电阻。

5.4 电流并联负反馈

i_o 同时流过 R_L 与取样电阻 R，在 R 上产生正比于 i_o 的电压，再经 R_f 变成反馈电流 i_f， 送回反相输入端与 i_i 在同一节点相减。输出短路后 i_o 仍流过 R，反馈不消失，故为电流反馈； 输入同一节点，故为并联。它稳定输出电流、降低输入电阻、提高输出电阻。

5.5 四种组态对照

组态输出取样输入端稳定量R_ifR_of
电压串联u_o不同节点，电压相减输出电压增大减小
电压并联u_o同一节点，电流相减输出电压减小减小
电流串联i_o不同节点，电压相减输出电流增大增大

组态判别口诀 输出短路看法：短路后反馈没了是电压，还在是电流。
输入端看法：反馈与输入接同一点是并联，接不同点是串联。
稳什么：电压负反馈稳压，电流负反馈稳流；串联提高输入电阻，并联降低输入电阻。

5.6 考研例题：两级放大器的组态判断

题：两级共射电路，R_f 从第二级输出接回第一级发射极，输入加在第一级基极。

解：输出短路后反馈消失 → 电压反馈；输入在基极、反馈在发射极 → 串联反馈。 设 T1 基极 ⊕，经两级共射后输出 ⊕，反馈回发射极也是 ⊕，使 U_BE1 减小 → 负反馈。 结论：电压串联负反馈，稳定输出电压、提高输入电阻、减小输出电阻。

六、深度负反馈与 1+AF ≫ 1

当 1 + AF ≫ 1（工程上要求大于 10，实际常大于 100）时，分母里的 1 可忽略： 闭环增益几乎只由反馈网络决定，净输入几乎为零——这正是运放“虚短、虚断”的源头。 代价是增益只剩 1/F，所以深度负反馈一定伴随增益的大幅下降。

1 + AF ≈ AF　　A_f ≈ A / (AF) = 1 / F　　X_id = X_i − X_f ≈ 0

例题：A = 10⁵，F = 0.01，求环路增益、反馈深度和闭环增益；若 A 降到 5×10⁴，A_f 变为多少？

  1. AF = 10⁵ × 0.01 = 1000，1 + AF = 1001 ≫ 1，属于深度负反馈。
  2. A_f = 10⁵ / 1001 ≈ 99.9，与 1/F = 100 只差 0.1%。
  3. A 降一半后：A_f = 5×10⁴ / 501 ≈ 99.8，几乎不动。
F 的量纲 电压串联 F = u_f/u_o（无量纲）；电压并联 F = i_f/u_o（S）； 电流串联 F = u_f/i_o（Ω）；电流并联 F = i_f/i_o（无量纲）。 所以 A_f ≈ 1/F 得到的可能是电压增益、互阻增益、互导增益或电流增益。

这一课学到了什么

  1. 反馈是减法结构：X_id = X_i − X_f，A_f = A/(1+AF)。
  2. 有无反馈看通路，正负看净输入：瞬时极性法四步，串联比电压、并联比电流。
