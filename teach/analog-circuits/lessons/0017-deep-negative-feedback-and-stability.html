Lesson 0017 — 深度负反馈与稳定性

模拟电子电路 · Lesson 0017 / 0020 · 约 40 分钟

前置知识 需要 Lesson 0015（四种组态） 和 Lesson 0016（1+AF 的作用）， 以及 Lesson 0014（频率响应） 里 "每级最多贡献 −90° 附加相移"这条结论——本课的稳定性分析完全建立在它上面。

一、深度负反馈：当 1+AF 大到可以忽略 1

A_f = A/(1+AF) 里，如果 AF 是 1000，那么分母 1001 里的那个 1 几乎没意义。 工程上只要 AF ≥ 10，就可以放心近似：

条件：|1 + AF| ≫ 1（工程上取 AF ≥ 10）
结论：A_f = A/(1+AF) ≈ A/(AF) = 1/F

这一步替换的意义极大，值得单独强调：

  • 闭环增益只由反馈网络决定，与晶体管参数、A 的大小、温度统统无关；
  • F 通常由两三个无源电阻分压实现，精度可以做到千分之几；
  • 于是"用一堆离散性极大的管子，做出一个极精确的增益"——这正是运放能成为通用器件的根本原因。
组态闭环增益的物理含义量纲深度负反馈下的表达式
电压串联A_uf = U_o / U_iV/V≈ 1/F（F = U_f/U_o）
电压并联A_rf = U_o / I_i（跨阻）V/A = Ω≈ 1/F（F = I_f/U_o，S）
电流串联A_gf = I_o / U_i（跨导）A/V = S≈ 1/F（F = U_f/I_o，Ω）
电流并联A_if = I_o / I_iA/A≈ 1/F（F = I_f/I_o）

二、用"虚短 / 虚断"口算深度负反馈电路

深度负反馈下，净输入量被压到几乎为零。把这句物理事实翻译成数学，就得到两条口算规则：

串联负反馈：U_id = U_i − U_f ≈ 0　→　U_i ≈ U_f（输入端"虚短"）
并联负反馈：I_id = I_i − I_f ≈ 0　→　I_i ≈ I_f（输入端"虚断"）
别和运放的虚短混为一谈 这里的"虚短"是指整个放大电路的输入端口上，净输入电压近似为零， 原因是反馈把差值补掉了；不是运放内部两个输入端之间的性质。 0019 讲的运放虚短，是 A_od → ∞ 的直接后果。两者形式相同，来源不同，考试时按题目语境区分。

四步口算法

标准流程
  1. 判组态：输入端是串联还是并联 → 决定用 U_i ≈ U_f 还是 I_i ≈ I_f。
  2. 写 F：沿反馈网络，把反馈量表示成输出量的函数，得到 F。
  3. 代近似：把第 1 步的关系代入第 2 步，消掉中间变量。
  4. 得 A_f：整理出 输出/输入，与 1/F 对照验证。

例题：电压串联负反馈

某放大电路引入电压串联负反馈，反馈网络由 R₁ = 1 kΩ 与 R₂ = 9 kΩ 串联分压构成，反馈电压取自 R₁ 两端。开环增益 A = 10⁵。 求闭环电压增益 A_uf，并说明近似误差。

解

  1. 判组态：反馈电压与输入电压串联相减 → 串联负反馈 → 用 U_i ≈ U_f。
  2. 写 F：U_f 是 U_o 在 R₁ 上的分压， U_f = R₁/(R₁+R₂) · U_o = 1/10 · U_o，故 F = 0.1。
  3. 验深度：AF = 10⁵ × 0.1 = 10⁴，1+AF = 10001，远比 1 大 → 深度负反馈成立。
  4. 得结果： A_uf ≈ 1/F = 10。 用虚短验证：U_i = U_f = 0.1 U_o → U_o/U_i = 10 ✅
  5. 误差：精确值 A_uf = 10⁵/10001 = 9.999，与 10 的相对误差约 0.01%， 完全可以忽略。注意增益被砍了一万倍，换取的是"增益只由两个电阻决定"。

三、环路增益 AF 到底是什么

把反馈环在任意一点断开，注入一个测试信号，让它绕一圈回来，得到的比值就是 AF。 它是一个复数，同时携带幅度信息和相位信息：

A F = |AF| · e^(jφ)，　φ = φ_A + φ_F
  • 中频段：φ_A = −180°（反相放大），φ_F = 0°（纯电阻反馈网络）， 合计 φ = −180°，即 ±(2n+1)π → 负反馈成立；
  • 高频段：A 里的晶体管极间电容、负载电容引入附加相移， φ_A 从 −180° 继续往 −270°、−360° 走；
  • 一旦 φ 走到 −360°（= 0°，等效于 0 或 2nπ），反馈的性质就翻转为正反馈。

四、自激振荡：负反馈的"翻脸"

如果翻成正反馈的同时幅度条件也满足，电路就自己振荡起来——输入端什么都不接， 输出端却有持续的正弦波。这就是自激振荡。

自激条件（起振）：|AF| > 1　且　φ_A + φ_F = ±(2n+1)π
自激条件（维持）：|AF| = 1　且　φ_A + φ_F = ±(2n+1)π
为什么是 ±(2n+1)π 而不是 2nπ 因为中频时 A 本身已经反相（贡献 −180°），负反馈靠的就是这 180° 的反相。 要把它抵消成同相（360° 等效 0°），附加相移必须再补 180°，即总相移 360° 的奇数倍。 记法：负反馈要自激，附加相移得凑够 180°。

读图方法就一句话：先看相频曲线在哪降到 −180°，再看那一刻幅频曲线是否还在 0 dB 以上。 在 0 dB 以上 → 自激；在 0 dB 以下 → 稳定。

自激的物理原因

  • 晶体管极间电容 C_bc（密勒电容）、C_be，以及负载电容，构成多个极点；
  • 每过一个极点，附加相移再累加最多 −90°；三级以上就足以累加到 −180°；
  • 反馈深度越大（AF 越大），幅频曲线整体上抬，越容易在相移 180° 处仍高于 0 dB；
  • 所以反馈越深，越容易自激——这是一条重要的工程取舍。

五、稳定裕度：留多少余量才安全

相位裕度 γ = 180° − |φ(f_c)|，其中 f_c 是 |AF| = 1 的频率
增益裕度 G_m = −20lg|AF(f_180°)|，其中 f_180° 是 φ = −180° 的频率
裕度在哪一点测量稳定条件工程要求
相位裕度 γ |AF| = 1 的穿越频率 f_c γ > 0°（即 |φ| < 180°） γ ≥ 45°，通常取 45°~60°
增益裕度 G_m φ = −180° 的频率 f_180° G_m > 0 dB（即 |AF| < 1） G_m ≥ 10 dB
应试要点 题目给出"|AF| = 1 时附加相移为 −135°"，答案就是 γ = 180° − 135° = 45°， 结论"稳定，但裕度偏低"。给出的若是 −180° 或更大，则 γ ≤ 0，电路自激。

六、相位补偿：把不稳定的电路救回来

思路只有一条：让 |AF| 在相移爬到 −180° 之前就降到 1。 最简单的做法是人为压低第一个极点，使幅频曲线更早开始以 −20 dB/dec 下降。

两种常见补偿方式

方式做法效果与代价
简单电容补偿
（主极点补偿）		 在产生最高极点的那一级（通常是中间级）并接一个小电容 C 主极点频率降到 1/(2πRC)，幅频提前以 −20 dB/dec 下降； 带宽损失最大，但最简单、最可靠
RC 补偿
（滞后补偿）		 电容串一个电阻 R 后接入，或做成滞后-超前网络 避免主极点压得过低，带宽损失较小；设计稍复杂
一句话总结 稳定性是用带宽换来的。这和 0016 的"增益带宽积守恒"是同一件事的两面： 你想让闭环增益大、反馈深，就得接受带宽变窄；不肯让带宽，就得接受自激风险。

八、Quiz — 考研风格题

这一课学到了什么

  1. 深度负反馈让增益"脱胎换骨"：A_f ≈ 1/F，增益只由电阻网络决定。
  2. 虚短虚断是深度负反馈的口算工具：串联用 U_i ≈ U_f，并联用 I_i ≈ I_f。
  3. 负反馈可能自激：高频附加相移把 −180° 补成 −360°，负反馈变正反馈； 判据是"φ = −180° 时 |AF| 是否还大于 1"。
  4. 稳定性可以量化：相位裕度、增益裕度；不够就做相位补偿，代价是带宽。
