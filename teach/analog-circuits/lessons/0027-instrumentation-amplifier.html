Lesson 0027 — 仪表放大器与信号预处理

模拟电子电路 · Lesson 0027 / 0029 · 约 55 分钟

前置知识 本课直接建立在 Lesson 0013（差分放大电路）、 Lesson 0019（运放基础） 与 Lesson 0020（运放应用） 之上。 需要随时能写出：差分电路的差模增益、共模增益、共模抑制比 CMRR； 运放的虚短 u_+ = u_− 与虚断 i_+ = i_− = 0。

前面学过的差分放大电路，是用分立三极管搭出来的。它能抑制共模，但有个绕不过去的毛病： 输入电阻不够高、增益靠改电阻、共模抑制受电阻精度限制。现实中的传感器—— 应变片电桥、热电偶、压电薄膜、心电电极——输出阻抗动辄几千欧到几兆欧， 信号只有毫伏甚至微伏，而共模干扰（50 Hz 工频、人体电位）却有伏级。

把这种信号直接送进普通差分电路，等于用一把晃动的尺子去量头发丝。 仪表放大器（Instrumentation Amplifier，INA）就是为这个场景发明的： 三只运放、一只电阻 R_G 决定全部增益，输入电阻接近无穷大， 共模抑制比轻松做到 100 dB 以上。这一课从"为什么不够"讲到"怎么设计一条心电信号链"。

一、普通差分电路的三宗罪

先复习最基本的单运放差分电路（也叫减法电路）：四个电阻 R_1、R_2、R_3、R_f， 当 R_1 = R_2、R_3 = R_f 时输出为

u_o = (R_f / R_1) · (u_i2 − u_i1)

它看起来完美，但用在传感器前端会暴露三个致命问题。

1.1 输入电阻低

反相端那条支路的输入电阻就是 R_1，典型值 10 kΩ 量级； 同相端虽然高一些，但为了匹配也必须取同样的 R_1 + R_f。 而应变片电桥的输出电阻是 350 Ω～1 kΩ，看着不大，可一旦传感器输出阻抗随温度、 随导线长度变化，R_1 的分压比就跟着变——增益变成不可重复的。

更糟的是，信号源内阻 R_s 会直接串进 R_1： 实际增益变成 R_f/(R_1 + R_s)。传感器内阻一漂，标定就作废。

1.2 增益调节不便

要改增益，必须同时改 R_1 和 R_2（或同时改 R_3 和 R_f）， 否则共模抑制立刻崩掉。四只电阻要同步、同比例、同温度系数地变——这在量产里几乎不可能。 工程师真正想要的是：一只电位器拧下去，增益连续可调，CMRR 不受影响。

1.3 共模抑制受电阻匹配限制

单运放差分电路的 CMRR 完全由四只电阻的匹配精度决定。设电阻有相对误差 δ = ΔR/R， 可以证明（本课第四节推导）：

CMRR ≈ (1 + A_d) / (4δ)　，　A_d = R_f / R_1

取 A_d = 5、δ = 1%：CMRR ≈ 6/0.04 = 150，即 43.5 dB。 而心电前端要求 100 dB 以上——差 56 dB，也就是共模干扰会被多放大 600 倍。 靠 0.01% 的电阻？那是激光修调薄膜电阻的领域，成本和交期都不是课堂电路能承受的。

一句话总结 单运放差分电路的三个毛病同源：信号要经过电阻网络才进入运放。 想让输入电阻高、增益只由一只电阻决定、共模抑制不依赖四只电阻匹配， 就必须让信号先碰到运放的同相输入端——这就是三运放结构的出发点。

二、三运放仪表放大器

三运放仪表放大器分两级：第一级由 A1、A2 组成同相输入的差分放大器， 负责"高输入电阻 + 全部增益"；第二级由 A3 组成普通差分放大器，负责"把双端转单端"。 增益被拆成两段的乘积，只有第一级的一只 R_G 参与调节。

2.1 第一级：同相输入，为什么共模增益是零

看 A1、A2。信号从同相端进入，所以输入电阻就是运放同相端的输入电阻—— 理想为无穷大，实际可达 10⁹～10¹² Ω，而且与增益无关。这是第一级最重要的性质。

A1 的反相端经 R 接到自己的输出 u_o1；A2 同理接到 u_o2； 两只运放的反相端之间跨接 R_G。由虚短：

u_A1− = u_i1　，　u_A2− = u_i2

这两个反相端正好是 R_G 的两端。于是 R_G 上的电压就是两输入之差， 流过的电流为：

i_G = (u_i1 − u_i2) / R_G

这个电流由 A1 输出流出、经 R 与 R_G 流回 A2 输出。 在 R 上产生压降 i_G·R，方向使 u_o1 高于 u_i1、u_o2 低于 u_i2：

u_o1 = u_i1 + i_G R　，　u_o2 = u_i2 − i_G R
u_o1 − u_o2 = (u_i1 − u_i2) + 2 i_G R = (u_i1 − u_i2) · (1 + 2R/R_G)

第一级的差模增益就是 A_u1 = 1 + 2R/R_G。注意它只由一只电阻 R_G 决定， 改增益不用碰任何匹配电阻。

共模为什么是零（本课最核心的一句话） 令 u_i1 = u_i2 = u_cm。此时 R_G 两端电位相同， 没有电流流过 R_G（i_G = 0）；R 上也没有压降， 于是 u_o1 = u_o2 = u_cm。
第一级对共模的增益等于 1，而差模增益是 1 + 2R/R_G， 所以第一级的共模抑制比就是 A_u1 本身——增益越大，共模抑制越好。 这不是靠电阻匹配换来的，是拓扑结构白送的。

2.2 第二级：把双端变单端

A3 是一个标准差分放大器，输入是 u_o1、u_o2。当 R_3 = R_4 = R_1、 反馈电阻为 R_f 时：

u_o = (R_f / R_1) · (u_o2 − u_o1)

注意符号：A3 的反相端接 u_o1、同相端接 u_o2，所以输出正比于 u_o2 − u_o1。把第一级的结果代入：

u_o = (R_f/R_1) · (1 + 2R/R_G) · (u_i2 − u_i1)

这就是仪表放大器的总增益。工程上常把第二级做成单位增益（R_f = R_1）， 于是简化为最常用的形式：

A_u = 1 + 2R / R_G

第二级存在的意义不是增益，而是减法：它把已经放大的双端信号转成对地单端信号， 同时再贡献一级共模抑制。但它也带来一个副作用——第二级的四只电阻如果失配， 会把第一级残留的共模重新"漏"到输出。这是整机 CMRR 的瓶颈，第四节专门算。

2.3 增益的两种写法与设计取舍

形式表达式适用场景注意
完整式 A_u = (1 + 2R/R_G)·(R_f/R_1) 两级都参与增益 第二级增益不宜过大，否则第一级共模被放大后更容易泄漏
简化式 A_u = 1 + 2R/R_G 第二级单位增益（R_f = R_1） 增益全部由 R_G 决定，CMRR 最优
单电阻调节 R_G = 2R/(A_u − 1) 需要连续可调增益 R_G 用精密电位器或波段开关切换
为什么 R_G 常做成外接 R_G 是唯一决定增益的元件，把它引出到芯片外部，用户就能用一只电阻设定增益。 经典 INA128 的 datasheet 给出 R_G = 50 kΩ/(A_u − 1)，对应内部 2R = 50 kΩ。 这也解释了为什么仪表放大器的增益不能做到无穷大——R_G → 0 时增益受运放输出电流和开环增益限制。

三、共模与差模在 R_G 上的电流

理解仪表放大器的关键，是把任意两个输入拆成共模分量与差模分量：

u_cm = (u_i1 + u_i2)/2　，　u_d = u_i1 − u_i2
u_i1 = u_cm + u_d/2　，　u_i2 = u_cm − u_d/2

第一级只看 R_G 上的电压，也就是 u_i1 − u_i2 = u_d。 共模分量 u_cm 同时出现在 R_G 两端，互相抵消，不产生电流。 下图把两种情况并排画出来：左边共模，右边差模。

3.1 定量验证：共模增益确实为 1

再走一遍推导，这次用叠加。设 u_i1 = u_i2 = u_cm：

  1. 虚短给出 A1 反相端 = u_cm，A2 反相端 = u_cm；
  2. R_G 两端电压为 u_cm − u_cm = 0，所以 i_G = 0；
  3. R 上无压降，u_o1 = u_cm、u_o2 = u_cm；
  4. A3 的输入差为 0，输出共模分量为 0（理想）。

所以第一级共模增益 = 1，而总电路对共模的增益 = 0（第二级把它减掉了）。 第一级的"共模增益 1"并不丢人——它把共模原样搬到输出，第二级差分再减一次， 真正决定整机 CMRR 的是第二级电阻的匹配精度与第一级运放的 CMRR。

共模抑制的两个来源 ① 第一级：R_G 把共模"短路"掉，共模增益只有 1，差模增益 1+2R/R_G， 所以第一级内部就贡献了 1+2R/R_G 倍的 CMRR；
② 第二级：差分减法再抑制一次，但受四只电阻匹配限制。
设计时要把增益尽量放在第一级，让第二级保持单位增益——这是提高整机 CMRR 最有效的手段。

四、CMRR 与电阻匹配误差

理想运放、理想电阻下，仪表放大器的 CMRR 是无穷大。现实中 CMRR 被两件事拉低： 运放本身的共模抑制有限、电阻存在容差。后者是主要矛盾，而且可以定量算。

4.1 单运放差分电路的失配

设差分电路中 R_1 有相对误差 δ（R_1' = R_1(1+δ)），其余电阻理想。 对共模输入 u_cm 求输出，可以得到共模增益：

A_c ≈ A_d · δ / (1 + A_d)　，　A_d = R_f/R_1

于是

CMRR = A_d / A_c ≈ (1 + A_d) / δ

咦，和第一节写的 (1+A_d)/(4δ) 差一个 4？差别在于失配的电阻个数与位置。 若四只电阻各自独立、误差同分布，最坏情况会叠加，工程估算统一取：

CMRR ≈ (1 + A_d) / (4δ)　（δ 为单只电阻的相对容差）

这个 4 不是精确系数，而是"四只电阻、最坏组合"的经验因子。 考研答题写 CMRR ≈ (1+A_d)/(4δ) 即可；若题目明确只有一只电阻失配，则用 (1+A_d)/δ。

4.2 仪表放大器的失配

三运放结构中，第一级的 CMRR 主要由 R_G 与两只 R 的匹配决定， 但因为它把共模原样传到输出（增益 1），真正的瓶颈在第二级 A3：

CMRR_total ≈ (1 + R_f/R_1) / (4δ)

注意这个式子里没有第一级增益。这意味着：即使你把第一级增益做到 1000， 只要第二级电阻有 0.1% 失配，整机 CMRR 就被钉死在 (1+1)/(4×0.001) = 500，即 54 dB。这就是为什么高端仪表放大器要把 第二级四只电阻激光修调到 0.01% 以内，或者干脆做成"双运放"结构省掉第二级。

结论很反直觉：提高第二级增益反而能改善 CMRR（分子 1+A_d 变大）， 但代价是第二级会把第一级残留的共模也放大。工程折中是第二级取 2～10 倍， 再靠精密电阻把 δ 压到 0.01%。

dB 换算只需记三个数 20 lg 10 = 20 dB、20 lg 100 = 40 dB、20 lg 1000 = 60 dB。 所以 CMRR = 10⁵ 就是 100 dB，10⁶ 就是 120 dB。反算：100 dB → 10⁵，120 dB → 10⁶。

五、电桥传感器与仪表放大器

仪表放大器最常见的搭档是惠斯通电桥。应变片、称重传感器、压力传感器、 PT100 测温，本质都是"电阻变化 → 电桥失衡 → 差分电压"。

5.1 电桥输出公式

四个桥臂 R_1、R_2、R_3、R_4，激励电压 U_S。 两个中点对地的电位分别是两个分压：

U_L = U_S · R_3/(R_1 + R_3)　，　U_R = U_S · R_4/(R_2 + R_4)
ΔU = U_L − U_R

初始平衡时四臂相等，ΔU = 0。设只有 R_1 变化 R_1 = R + ΔR， 其余为 R，则

ΔU = U_S · [ R/(2R + ΔR) − 1/2 ] = − U_S · ΔR / (4R + 2ΔR) ≈ − U_S · ΔR/(4R)

取绝对值，得到最该背下来的电桥公式：

|ΔU| = U_S · ΔR / (4R)　（单臂工作）

5.2 三种桥接方式

接法变化的桥臂输出相对灵敏度
单臂（1/4 桥）1 只U_S·ΔR/(4R)1
半桥2 只，一增一减U_S·ΔR/(2R)2
全桥4 只，两增两减U_S·ΔR/R4

全桥不只是灵敏度高 4 倍，它还有两个隐藏好处：非线性误差被抵消 （分母里的 2ΔR 项在对称变化时相互抵消）、温度漂移相互抵消 （四只应变片同处一个温度场，电阻同向漂移，电桥仍平衡）。 所以称重传感器几乎清一色用全桥。

电桥输出为什么必须用仪表放大器 典型应变片：R = 350 Ω、U_S = 5 V、ΔR/R = 0.1%，单臂输出只有 5 × 0.001/4 = 1.25 mV。电桥输出电阻约 350 Ω，若用 R_1 = 10 kΩ 的普通差分电路，信号先被 350/(10k+350) 衰减 3.4%，而且这个衰减随温度变。 仪表放大器的输入电阻是 GΩ 级，350 Ω 源内阻的影响可以忽略。

5.3 电桥的共模问题

注意电桥两个中点对地的电位都大约是 U_S/2。也就是说， 差模信号只有毫伏，共模电平却有 2.5 V，两者相差 2000 倍。 这正是仪表放大器存在的理由：它必须在这 2.5 V 共模之上，分辨出 1 mV 的差模变化。 若 CMRR 只有 60 dB（1000 倍），2.5 V 共模会产生 2.5 mV 的等效输出误差—— 比信号本身还大，测量直接报废。

六、工程实践：屏蔽驱动、右腿驱动与隔离

真实信号链里，仪表放大器只是第一环。导线、人体、工频电场会引入大量共模干扰， 必须配合三种手段：屏蔽驱动、右腿驱动、隔离。

6.1 屏蔽驱动（Driven Shield）

传感器到放大器之间的电缆有分布电容 C_c（每米几十到几百 pF）。 芯线屏蔽层接地时，共模电压 u_cm 会通过 C_c 注入电流：

i_leak = C_c · du_cm/dt

这个电流流过信号源内阻 R_s，产生误差电压 i_leak·R_s； 更麻烦的是两条芯线的 C_c 不可能完全相等，于是共模被"转换成"差模。

解决办法：不要把屏蔽层接地，而是接到一个缓冲器的输出， 让屏蔽层电位跟随共模电压 u_cm。屏蔽层与芯线之间没有电位差， 就没有容性电流，等效把电缆电容"消除"了。这个缓冲器通常直接取仪表放大器第一级的共模节点。

6.2 右腿驱动（Right Leg Drive, RLD）

心电测量中，人体通过工频电场耦合会抬到几十伏的共模电位（安全电流限制下）。 仅靠仪表放大器的 CMRR 不够，因为电极阻抗不匹配会把共模转成差模。 右腿驱动把共模"反向打回去"：

  1. 从仪表放大器第一级取出共模电压 u_cm；
  2. 经反相放大器变成 −A_r·u_cm；
  3. 通过右腿电极（串限流电阻 R_LR，典型 100 kΩ～1 MΩ 保证安全）注入人体。

这是一个负反馈环路，把人体共模电压压低到 u_cm/(1+A_r)。 效果相当于把等效 CMRR 提高了 1+A_r 倍，轻松再加 40 dB。 限流电阻是安全底线：即使电路故障，流过人体的电流也被限制在微安级。

6.3 隔离放大

医疗设备（心电、脑电）必须承受除颤器高压，患者与市电之间要有电气隔离。 隔离放大器用变压器或光耦传递信号，隔离电压可达 2.5 kV～5 kV， 同时隔离电源也要独立（隔离 DC-DC）。代价是带宽、精度和成本， 所以通常放在信号链末端、ADC 之前。

七、四道完整例题

例题 1：电桥输出与所需增益

题：某称重传感器为全桥接法，R = 350 Ω，额定载荷下每片应变片 ΔR = 1.4 Ω，激励 U_S = 5 V。① 求单臂、全桥两种情况下的电桥输出； ② 若 ADC 满量程 2.0 V，求仪表放大器所需增益。

解①：先算相对变化量

ΔR/R = 1.4/350 = 0.004 = 0.4%

单臂：

|ΔU| = U_S·ΔR/(4R) = 5 × 0.004/4 = 0.005 V = 5 mV

全桥（四臂两增两减，灵敏度 ×4）：

|ΔU| = U_S·ΔR/R = 5 × 0.004 = 0.020 V = 20 mV

解②：满量程 20 mV 对应输出 2.0 V，

A_u = 2.0 V / 20 mV = 100

验算：采用 R = 20 kΩ、R_f/R_1 = 5，则第一级需 1+2R/R_G = 20， 即 R_G = 40 kΩ/19 ≈ 2.11 kΩ。取 E24 系列 2.1 kΩ， 实际第一级 1 + 40/2.1 = 20.05，总增益 100.2，误差 0.2%， 优于大多数应变片的综合精度（1%～2%）。

量程核算意识 算出增益后一定要回头检查：最大信号 × 增益 ≤ ADC 满量程， 并留 20%～30% 余量给过载。本例 20 mV × 100 = 2.0 V 正好打满， 工程上应把增益降到 80 左右，留出超载空间。

例题 2：给定增益反求 R_G

题：仪表放大器取 R = 25 kΩ，第二级 R_f = 100 kΩ、R_1 = 20 kΩ。 要求总增益 A_u = 200，求 R_G。

解：先算第二级增益

A_u2 = R_f/R_1 = 100k/20k = 5

第一级需要承担

A_u1 = A_u/A_u2 = 200/5 = 40

由 A_u1 = 1 + 2R/R_G：

2R/R_G = 39　⟹　R_G = 2R/39 = 50 kΩ/39 ≈ 1.282 kΩ

取标准值 1.3 kΩ 时 A_u1 = 1 + 50/1.3 = 39.46， 总增益 197.3，相对误差 −1.3%。若精度要求高，用 1.28 kΩ（E96 系列） 可得 A_u1 = 40.06，总增益 200.3。

验算：1 + 2×25k/1.282k = 1 + 39.0 = 40.0， 40 × 5 = 200 ✅。注意 R_G 与增益是反比关系： 增益越大，R_G 越小，对 R_G 的绝对误差越敏感。 高增益时（如 1000 倍），R_G 只有几十欧，必须用精密电阻或集成方案。

例题 3：由电阻失配估算 CMRR

题：上题电路若第二级四只电阻的容差为 δ = 0.1%， ① 估算整机 CMRR；② 要达到 100 dB，电阻容差需做到多少？

解①：第二级增益 A_d = 5，代入

CMRR ≈ (1 + A_d)/(4δ) = 6/(4 × 0.001) = 1500
20 lg 1500 = 20 × 3.176 = 63.5 dB

解②：要求 CMRR = 10⁵，反解 δ：

δ = (1 + A_d)/(4 × CMRR) = 6/(4 × 10⁵) = 1.5 × 10⁻⁵ = 0.0015%

结论：0.1% 的薄膜电阻只能给到 63.5 dB，离 100 dB 差 36.5 dB（约 67 倍）。 这正是"分立电阻搭仪表放大器"的天花板。集成仪表放大器（如 INA128）在片内用激光修调 把 δ 做到 0.001% 量级，才能标称 100 dB 以上；再往上就要靠右腿驱动、屏蔽驱动这类 系统级手段，而不是继续堆电阻精度。

答题模板 ① 写出 A_d = R_f/R_1；② 代 CMRR ≈ (1+A_d)/(4δ)； ③ 用 20 lg 转 dB；④ 反解时把 dB 先转回倍数。 四步写全，过程分基本不会丢。

例题 4：心电信号链的增益与 CMRR 分配

题：心电前端指标：差模信号 u_d = 1 mV，工频共模干扰 u_cm = 1 V，ADC 输入满量程 1 V，要求共模在输出端产生的误差 小于 5 mV。① 求总增益；② 求所需 CMRR；③ 若右腿驱动提供 40 dB， 仪表放大器本身需多少 dB？④ 给出增益分配方案。

解①：

A_u = 1 V / 1 mV = 1000

解②：共模在输出端的误差为 u_cm · A_u / CMRR，要求

1 V × 1000 / CMRR < 5 mV　⟹　CMRR > 1000/0.005 = 2 × 10⁵
20 lg(2 × 10⁵) = 20 × 5.301 = 106 dB

解③：右腿驱动把人体共模先压低 1+A_r 倍， 相当于系统 CMRR 增加 20 lg(1+A_r)。提供 40 dB 后：

CMRR_INA ≥ 106 − 40 = 66 dB（约 2000 倍）

解④：增益分三段，避免单级过大导致带宽和噪声恶化：

环节增益理由
仪表放大器第一级×100增益放前面可压低后级噪声贡献；CMRR 也随之提高
仪表放大器第二级×1单位增益，CMRR 最优，避免共模被二次放大
PGA×10靠近 ADC，便于切换量程
合计×10001 mV → 1 V

验算：第一级 1+2R/R_G = 100，取 R = 25 kΩ 得 R_G = 50k/99 ≈ 505 Ω。第二级 δ = 0.02% 时 CMRR ≈ 2/(4×0.0002) = 2500 = 68 dB，加上右腿驱动 40 dB， 系统约 108 dB，满足 106 dB 要求，余量 2 dB。

为什么不能把 1000 倍全放在第一级 第一级增益由 1+2R/R_G 决定，1000 倍要求 R_G ≈ 50 Ω。 这时 R_G 的引线电阻、接触电阻（几十毫欧到几欧）都变成百分之几的增益误差； 同时第一级运放带宽被压缩 1000 倍。工程上单级增益很少超过 100～200。

八、易错点与速查表

七个高频错误

  1. 把 R_G 当成反馈电阻。R_G 跨接在两只运放的反相输入端之间， 不接地、不接输出。接错位置增益公式全错。
  2. 认为共模时第一级输出为零。第一级共模增益是 1， u_o1 = u_o2 = u_cm；是第二级把它们相减才得到零。
  3. 用 A_u = R_f/R_G。正确是 1 + 2R/R_G， 系数 2 来自两只 R；漏掉 1 会在低增益时误差巨大。
  4. 忘记第二级增益。完整式是两级相乘，只有 R_f = R_1 时才能用简化式。
  5. 电桥公式少除 4。单臂是 U_S·ΔR/(4R)，半桥除 2，全桥不除。
  6. CMRR 用电压比直接当 dB。CMRR(dB) = 20 lg(CMRR)，不是 10 lg。
  7. 忽略输入偏置电流。仪表放大器输入偏置电流虽小（nA 级）， 流过电桥内阻仍会产生失调；高阻传感器要选 I_B 更小的型号。

九、Quiz — 考研风格题

4 道题覆盖增益、共模、电桥与 CMRR 估算。先动笔，再点选项。

这一课学到了什么

  1. 普通差分电路的三宗罪：输入电阻低、增益调节要动四只电阻、CMRR 受电阻匹配限制。
  2. 三运放结构的两级分工：A1/A2 同相输入负责高输入电阻与全部增益， A3 差分负责双端转单端；A_u = (1+2R/R_G)·(R_f/R_1)。
  3. 共模增益为零的机理：共模时 R_G 两端同电位、无电流， 第一级只是把共模原样搬运（增益 1），第二级再相减。
  4. CMRR 由电阻匹配决定：CMRR ≈ (1+A_d)/(4δ)， 0.1% 电阻只有 54～64 dB，100 dB 需要 0.001% 量级的修调电阻。
  5. 电桥前端：单臂 U_S·ΔR/(4R)，全桥灵敏 4 倍； 电桥的共模是 U_S/2，比差模大上千倍，非仪表放大器不可。
  6. 系统级手段：屏蔽驱动消除电缆电容电流，右腿驱动把共模压低 1+A_r 倍， 隔离放大保证患者安全。
