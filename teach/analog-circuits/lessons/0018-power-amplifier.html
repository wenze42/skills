Lesson 0018 — 功率放大电路

模拟电子电路 · Lesson 0018 / 0020 · 约 40 分钟

前置知识 需要 Lesson 0003（二极管与恒压降模型）、 Lesson 0005（BJT 输出特性与截止/饱和）、 Lesson 0013（互补对称的思想）。 这一课是整门课里唯一处理大信号的地方。

一、功放的任务：从"放大电压"到"输出功率"

前面十六课，我们一直在做小信号放大：输入 10 mV，输出 1 V，电流只有毫安级， 讨论的是增益、频响、失真系数。但扬声器要的是瓦特，不是伏特。

功率放大电路（Power Amplifier）的任务是：在负载上输出足够大的功率， 即同时给出足够大的电压摆幅和电流摆幅。8 Ω 扬声器要 10 W，意味着 U_o ≈ 9 V、I_o ≈ 1.1 A，这已经和前面"微安级基极电流"完全不是一个量级了。

对比项小信号放大电路功率放大电路
信号幅度微小，可用小信号模型线性化大，接近电源电压，必须用图解法
分析方法微变等效电路、h 参数大信号图解、负载线
核心指标增益、带宽、输入输出电阻输出功率、效率、管耗
主要矛盾失真与带宽效率与散热（管子会不会烧）
工作状态甲类（始终导通）乙类、甲乙类为主
效率的定义 η = P_o / P_V，其中 P_o 是负载上得到的有功功率（交流功率）， P_V 是直流电源提供的功率。两者的差额全部变成管子和电阻上的热量。 效率低的直接后果是：管子烫、散热器大、电池撑不住。

二、四种工作状态：导通角决定一切

"工作状态"说的是一个信号周期内管子导通多长时间， 用导通角表示（一个完整周期 = 360°）。静态工作点 Q 的位置直接决定导通角。

工作状态Q 点位置导通角最高理论效率特点
甲类放大区中部360°50%无交越失真，但静态也费电，效率极低
乙类刚好在截止点180°78.5%效率高，但存在交越失真
甲乙类截止点略上方180°~360°介于两者，约 60%~70%兼顾效率与失真，实际电路主流
丙类远低于截止点小于 180°可达 80% 以上失真极大，只能配谐振负载用于射频

三、乙类 OCL 互补对称电路

乙类效率高，但单个管子只能放大半个周期。解决办法是互补： 一个 NPN 管负责正半周，一个 PNP 管负责负半周，两者交替导通，拼出完整正弦波。 OCL（Output Capacitor Less）指双电源供电、输出端不需要隔直电容。

工作过程

  1. 正半周（u_i 为正）：T1（NPN）正偏导通，T2 截止。 电流路径 +V_CC → T1 → R_L → GND，输出正半周。
  2. 负半周（u_i 为负）：T2（PNP）正偏导通，T1 截止。 电流路径 GND → R_L → T2 → −V_CC，输出负半周。
  3. 两管各导通 180°，在负载上合成完整正弦波。 因为是两管轮流供电，电源电流是"半波整流"形状，不是恒定直流。

交越失真：乙类的原罪

BJT 有约 0.7 V 的导通门槛。当输入信号在零附近（|u_i| 小于约 0.5~0.7 V）时， 两个管子都截止，输出为零——波形在过零点被"掐"出了一个台阶。

甲乙类偏置：消除交越失真

只要让两个管子静态时就有微小电流（微导通），过零点就不会有死区， 导通角略微超过 180°，这就成了甲乙类。实现方法是在两管基极之间加一个 恒压偏置，产生约 1.2~1.4 V 的电压（两个 U_BE 之和）：

  • 二极管偏置：两个二极管串联（或一个二极管 + 电阻）接在两基极之间， 利用二极管的正向压降提供约 1.4 V 的固定偏压；
  • 恒压源偏置：用 U_BE 扩大电路（三极管 + 两只电阻）产生可调的恒压， 工程上更常用，因为可以精确调节偏置量。
注意 加了偏置后工作状态严格来说是"甲乙类"，不是"乙类"。 考研题里说"乙类互补对称电路"时，一般都按乙类（无偏置）计算效率和功率； 题目一旦提到"消除交越失真"，就是在考甲乙类的偏置方法。

四、输出功率、效率与管耗

设输出电压幅值为 U_om、负载为 R_L，忽略管子饱和压降和偏置损耗。 先记四个式子，再理解它们从哪来。

输出功率：P_o = U_om² / (2R_L)　（有效值 U_om/√2 的平方除以 R_L）
最大输出：U_om = V_CC → P_om = V_CC² / (2R_L)
电源功率：P_V = 2V_CC · U_om / (π R_L)
效率：η = P_o / P_V = (π/4) · (U_om / V_CC)

电源功率为什么带 π？因为每个管子只导通半个周期，电源电流是半波整流的形状， 其平均值是峰值除以 π。两个电源各供半个周期，合计 2V_CC · I_o(av)，其中 I_o(av) = U_om/(πR_L)。

当 U_om = V_CC（输出摆满）时效率取最大值：

η_max = π/4 = 78.5%（乙类理论极限）

单管管耗：为什么是 0.2 P_om

总管耗 = 电源功率 − 输出功率，两只管子平分，所以单管管耗：

P_T = (P_V − P_o)/2 = V_CC·U_om/(πR_L) − U_om²/(4R_L)

对 U_om 求导并令其为零，得到最大管耗出现在 U_om = 2V_CC/π ≈ 0.636 V_CC，此时：

P_Tmax = V_CC² / (π² R_L) ≈ 0.2 P_om
这里有个反直觉的点 最大管耗不出现在满输出时，而是出现在输出约为最大值的 64% 时。 因为满输出时效率最高，大部分功率都给了负载； 输出小时电源功率却仍有相当一部分消耗在管子上。 所以选管时不能只按"满输出减负载功率"来算，必须用 0.2P_om。

六、OTL 单电源电路

OCL 要双电源，电池供电的设备（收音机、小音箱）做不到。改用单电源时， 在输出端串一个大电容 C：

  • C 隔断直流，静态时输出端电位被充到 V_CC/2；
  • 负半周时 C 相当于一个"临时负电源"，向 PNP 管供电；
  • 因此最大输出电压幅值只有 V_CC/2，不是 V_CC。
OTL 最大输出：U_om = V_CC/2　→　P_om = (V_CC/2)²/(2R_L) = V_CC²/(8R_L)

效率公式不变（最大值仍是 78.5%），因为 η 只取决于 U_om 与供电电压之比。 但同样的电源电压下，OTL 的输出功率只有 OCL 的四分之一， 这是单电源方案必须付出的代价。

输出电容要多大 C 与 R_L 构成高通，必须让最低工作频率（如 50 Hz）也能顺利通过： C ≥ 1/(2π f_L R_L)。8 Ω、50 Hz 时 C 约需 400 μF，实际取 1000 μF 以上。

七、考研例题（带完整步骤）

乙类 OCL 互补对称功放，V_CC = ±15 V，R_L = 8 Ω， 忽略管子饱和压降。求： (1) 最大输出功率 P_om；(2) 此时效率与单管最大管耗；(3) 选管要求； (4) 若实际输出幅值 U_om = 10 V，求 P_o、P_V、η 与单管管耗。

解

  1. 最大输出功率：U_om = V_CC = 15 V
    P_om = V_CC²/(2R_L) = 225/(2×8) = 14.1 W
  2. 效率：满输出时 η = η_max = 78.5%
    单管最大管耗：P_Tmax ≈ 0.2 P_om = 0.2 × 14.1 = 2.82 W
  3. 选管：
    P_CM ≥ 2.82 W；|U_(BR)CEO| ≥ 2V_CC = 30 V；I_CM ≥ V_CC/R_L = 15/8 = 1.88 A
  4. U_om = 10 V 时：
    P_o = 10²/(2×8) = 6.25 W
    P_V = 2×15×10/(π×8) = 300/25.13 = 11.9 W
    η = 6.25/11.9 = 52.4%
    P_T = (11.9 − 6.25)/2 = 2.83 W （恰好接近 0.2P_om，因为 10 V ≈ 0.64×15 V，正是管耗峰值附近 ✅）

九、Quiz — 考研风格题

这一课学到了什么

  1. 功放的核心矛盾是效率：η = P_o/P_V，甲类最高 50%，乙类 78.5%。
  2. 乙类靠互补对称拼出完整波形：正半周 NPN，负半周 PNP，各导通 180°。
  3. 交越失真来自 0.7 V 门槛，用甲乙类恒压偏置（二极管/恒压源）消除。
  4. 三个数要背死：P_om = V_CC²/(2R_L)、η_max = 78.5%、P_Tmax ≈ 0.2P_om。
  5. 选管三看：P_CM ≥ 0.2P_om、|U_(BR)CEO| ≥ 2V_CC、I_CM ≥ V_CC/R_L。
