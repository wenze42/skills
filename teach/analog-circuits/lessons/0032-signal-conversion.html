Lesson 0032 — 信号的转换

模拟电子电路 · Lesson 0032 / 0035 · 约 55 分钟

前置知识 需要 Lesson 0020（运放应用） 的 虚短、虚断与反相/同相比例电路，Lesson 0021（电流源电路） 的"恒流"概念，以及 Lesson 0003（二极管电路） 的导通压降模型。这一课把这三样东西串起来。

真实系统里，传感器给出的量往往不是"电压"：光电二极管给电流， 热电偶给微伏，压敏电阻给电阻变化，而 ADC 只认电压， 显示器只认频率。中间这一层"翻译"，就是本课的四类转换：

转换输入输出典型用途
U-I电压电流驱动 LED、电磁阀、传感器激励
I-U电流电压光电二极管前置放大
交流-直流微弱交流单向脉动精密整流、表头、有效值检测
U-f电压频率VCO、模数转换、隔离传输

四类电路的共同点：运放 + 负反馈，虚短虚断全程有效。 与 0030、0031 的非线性应用不同，这里运放始终待在线性区——它只负责"搬运"， 不负责"判断"。

一、电压-电流转换（U-I）

先说清楚一件事：为什么不能直接用一个电阻把电压变成电流？ 因为 I = u/R 里的 R 若包含负载，电流就随负载变化； 若 R 与负载串联，负载上的压降又会改变电流。真正的恒流源要求 输出电流与负载无关——这只有靠反馈才能做到。

1.1 负载浮地型：最简单的恒流源

把负载 R_L 放到运放的反馈支路里，它就变成了"被控制的电阻"。 负载不接地（两端都悬空），所以叫浮地。

反相端是虚地（u_− = 0），虚断使 R 里的电流只能全部流进 R_L：

I_L = (u_i − 0)/R = u_i/R
  • 电流只由 u_i 和 R 决定，与 R_L 无关；
  • 换负载（只要运放不饱和），电流不变——这才是恒流源；
  • 输出电压 u_o = −I_L·R_L = −(R_L/R)·u_i，随 R_L 线性变化；
  • 代价：负载不能接地。这在传感器激励、电化学测量里常常无法接受。
饱和边界（必考） |u_o| = (R_L/R)|u_i| ≤ U_om，所以负载电阻上限为 R_L ≤ U_om·R/|u_i|。超过这个值，运放进饱和，I_L 就不再等于 u_i/R，恒流特性失效。答题时一定要写这句"在运放未饱和的范围内"。

1.2 负载接地型：Howland 电流源

负载必须接地时，就要用正、负反馈相互抵消的办法： 负反馈稳定增益，正反馈把输出电阻"顶"到无穷大。这就是 Howland 电流源。

R_1 与 R_2 构成负反馈（回到反相端），R_3 与 R_4 构成正反馈（回到同相端）。当两组电阻的比例相等时，正反馈恰好"抵消"掉负载电压对电流的影响：

R_2/R_1 = R_4/R_3　（平衡条件）
I_L = u_i / R_1　（与 R_L 无关）
  • 正反馈的作用：负载电压升高时，正反馈把同相端抬高，让运放输出电压跟着"追"上去， 从而维持 R_1 上的电流不变——等效于把输出电阻提高到接近无穷大。
  • 必须精确匹配：比例误差 1% 会让输出电阻掉到只有几十 kΩ， 负载一变电流就跟着变。工程上四个电阻要用同一批精密电阻（0.1%）。
  • 正反馈过强会自激：若 R_4/R_3 略大于 R_2/R_1， 电路变成振荡器；所以调试时要"从负反馈略占优"开始。
  • 负载范围仍受限：u_o = I_L·R_L ≤ U_om，即 R_L ≤ U_om·R_1/u_i。
两种结构怎么选 负载能浮地 → 用浮地型，简单、精度高、只需一个电阻；
负载必须接地 → 用 Howland，代价是四个电阻要匹配、调试更麻烦。
题目里出现"负载一端接地"四个字，几乎就是在考 Howland。

【例 1】两种 U-I 电路的电流与饱和边界

题：图 32-1 中 u_i = 2 V，R = 1 kΩ，运放 ±15 V 供电 （U_om ≈ ±13 V）。① 求 R_L = 500 Ω 时的 I_L 与 u_o； ② 求允许的最大负载电阻。

第一步：电流

I_L = u_i/R = 2 V / 1 kΩ = 2 mA

第二步：输出电压

u_o = −I_L·R_L = −2 mA × 500 Ω = −1 V

第三步：最大负载。令 |u_o| = U_om：

R_L(max) = U_om·R/u_i = 13 × 1 kΩ / 2 = 6.5 kΩ

讨论：若 R_L 换成 10 kΩ，理论上 u_o 要到 −20 V，超出电源，运放饱和在 −13 V。此时实际电流只有 13 V / 10 kΩ = 1.3 mA，不再是 2 mA——恒流特性失效。 这就是"恒流源也有电压上限"的含义。

二、电流-电压转换（I-U）

光电二极管受光照时产生光电流 I_S，它与光强成正比，但内阻极高、 信号极弱（nA~μA 级）。直接用一个电阻取样，会受运放输入电阻、电缆电容的影响。 标准做法是把光电二极管接在运放的虚地上，用反馈电阻 R_f 承接电流：

反相端是虚地，光电二极管的电流无处可去，只能全部流过 R_f； 电流从反相端流向输出端，所以输出为负：

u_o = −I_S·R_f
  • 虚地的好处：二极管两端电压近似为 0，结电容不随电压变化，响应速度快、线性好；
  • 输出与光强成正比，比例系数就是 R_f，改量程只需换 R_f；
  • 输入电阻几乎为零，电缆电容被"自举"掉，抗干扰能力强；
  • R_f 上常并一个小电容（几 pF），用来抑制高频噪声、防止自激，代价是带宽下降。

【例 2】光电二极管前置放大求输出电压

题：某光电二极管在给定光强下产生 I_S = 20 μA， 前置放大电路取 R_f = 100 kΩ。求输出电压；若光强增大到 I_S = 50 μA，输出又是多少？

第一步

u_o = −20 μA × 100 kΩ = −2 V

第二步

u_o = −50 μA × 100 kΩ = −5 V

讨论：输出为负，是因为电流从虚地节点"抽走"。 若系统要求正输出，只需在后面加一级反相器（增益 −1），或者把二极管反接（阳极接虚地）。 另外要注意：I_S = 50 μA 时若想再提高灵敏度（增大 R_f）， 必须验算 I_S·R_f < U_om，否则运放饱和。

三、精密整流：绕开 0.7 V 的死区

普通二极管整流有个硬伤：输入必须先克服 0.7 V 的导通压降。 当信号只有几十毫伏（热电偶、光电、生物电）时，二极管根本不导通—— 输出恒为零，等于没有整流。

普通半波整流：u_o = u_i − 0.7 V（u_i > 0.7 V）　；　u_o = 0（u_i ≤ 0.7 V）

运放能解决这个问题：把二极管放进反馈回路里，二极管的压降被"包"进了环路， 运放会自动多输出 0.7 V 把它补回来，于是输入输出之间几乎没有死区。

3.1 精密半波整流

工作过程分两个半周，务必逐句对照电路图：

  1. u_i > 0：电流经 R_1 流入反相端，必须经 R_f 流出，于是输出被拉负，D_1 正向导通，反馈闭环成立。虚地使 I = u_i/R_1 = −u_o/R_f，得 u_o = −(R_f/R_1)u_i。
  2. u_i < 0：运放输出要变正，D_1 反偏截止，反馈断开； D_2 导通，把运放输出钳在 −0.7 V 附近（不再往负饱和跑）， 负载 R_L 上没有电流，u_o ≈ 0。
u_o = −(R_f/R_1)·u_i　(u_i > 0)　；　u_o = 0　(u_i < 0)

D_2 不是可有可无的：没有它，u_i < 0 时运放会一路冲到负饱和， 等输入再变正时需要从 −13 V 爬回来，恢复时间长达几十微秒，高频信号直接被"拖平"。

【例 3】0.1 V 小信号：精密整流 vs 普通整流

题：输入 u_i = 0.1 sin ωt (V)，R_f = R_1 = 10 kΩ， 二极管导通压降 0.7 V。求精密半波整流的输出，并与普通二极管半波整流对比。

第一步：精密整流。R_f/R_1 = 1，所以

u_o = −0.1 sin ωt　(正半周)　；　u_o = 0　(负半周)

输出是一个幅度 0.1 V 的负半波，形状与输入完全相同，只是被"翻了半周、切掉一半"。

第二步：普通整流。二极管的导通条件是 u_i > 0.7 V， 而输入峰值只有 0.1 V：

u_i(max) = 0.1 V < 0.7 V　⟹　二极管永不导通，u_o ≡ 0

结论：普通整流对 0.1 V 信号完全失效，输出是一条零线； 精密整流能完整保留波形。这就是"精密"二字的全部含义。

第三步：估算残余死区。运放开环增益 A_od = 10⁵ 时， 折算到输入端的等效死区约为

ΔU ≈ U_D/A_od = 0.7 V / 10⁵ = 7 μV

7 μV 相对于 0.1 V 只有 0.007%，可以忽略。这就是"用增益换精度"的典型例子。

为什么是"负"半波 输入接的是反相端，所以 u_i > 0 时输出为负。 想要正半波输出，把 D_1、D_2 都反接，或者在后面加一级反相器。 画波形题先问一句"输出该是什么极性"，能避免整题翻车。

3.2 全波精密整流

半波整流丢掉了一半能量。要得到 |u_i|，用两级：第一级做半波， 第二级把"原信号"和"半波信号"按 1 : 2 的比例相加。

设 R_f = R_1 = R，则 A_1 输出（记为 u_o1）为 −u_i（u_i > 0）或 0（u_i < 0）。 A_2 是反相加法器，两路输入的权重分别为 R/R = 1 与 R/(R/2) = 2：

u_o = −(u_i + 2u_o1)

分两种情况验证：

  • u_i > 0：u_o1 = −u_i，代入得 u_o = −(u_i − 2u_i) = +u_i；
  • u_i < 0：u_o1 = 0，代入得 u_o = −u_i > 0。
u_o = |u_i|　（全波精密整流的传输特性）

这就是"绝对值电路"。传输特性是一条关于纵轴对称的 V 形折线： 输入为正，输出沿 +45° 上升；输入为负，输出沿 −45° 上升， 两条支路在原点相接。它与 0030 的滞回特性不同——这里没有跳变，只有折点。

【例 4】全波整流的传输特性与输出

题：图 32-6 中 R_f = R_1 = R = 10 kΩ，输入 u_i = 2 sin ωt (V)。求输出电压的表达式与峰值，并说明传输特性的形状。

第一步：表达式。由 u_o = |u_i|：

u_o = |2 sin ωt| = 2|sin ωt| (V)

第二步：峰值与频率。输出峰值仍为 2 V， 但频率翻倍——原信号每个周期有两次过零，绝对值把负半周"翻"上来， 所以一个输入周期内输出出现两个峰：

f_o = 2f_i

第三步：传输特性。以 u_i 为横轴、u_o 为纵轴， 得到两条斜率 +1 与 −1 的射线在原点汇合，形如 "V"。 注意四个象限都只出现在上半平面（u_o ≥ 0）， 这是"整流"二字的几何含义。

追问：若 R/2 误焊成 R（权重变成 1）， 则 u_i > 0 时 u_o = −(u_i − u_i) = 0，输出只剩半个波—— 又退回半波整流。这个"权重 2"是本题唯一的要害。

四、峰值检波

峰值检波要记住输入信号的最大值，常用于测量、自动增益控制。 基本结构是"二极管 + 电容 + 高阻缓冲"：

  • u_i 上升时，运放输出跟着上升，D 导通，给 C 充电；
  • u_i 下降时，D 截止，C 上的电压无处泄放，被"记住"；
  • 反馈从电容端取回反相端，运放自动补偿 D 的 0.7 V 压降，精度远高于无运放的版本；
  • R 提供放电通路，时间常数 RC 必须远大于信号周期， 否则电容还没充满就开始掉，输出变成"锯齿状包络"。
保持条件：RC ≫ T_signal　；　纹波：Δu ≈ U_peak·T/(RC)

这与 0031 的方波发生器结构相似（都是 RC + 单向器件），但目的相反： 那边要让电容不停地充放，这边要让电容几乎不放电。 同一套元件，靠 RC 与信号周期的比值，走向两个极端。

五、电压-频率转换（U-f）

最后一种转换不需要精密电阻网络，而是"用电压控制振荡频率"。 0031 已经给出结论：把积分器的输入从固定的 ±U_Z 换成受控电压 u_I， 频率就跟着变：

f = (R_2·u_I) / (4·R_1·R_3·C·U_Z)　⟹　f ∝ u_I

工程上更常用电荷平衡式结构：积分器 + 比较器 + 复位开关。 积分器对 u_I 积分，到门限时比较器触发开关，把一份固定的电荷 注入积分电容（复位），周期因此与 u_I 成反比、频率与 u_I 成正比。 优点是线性度高（可达 0.01%），缺点是结构复杂。

  • U-f 的用途：把模拟量变成频率后，可以用光耦或变压器隔离传输， 频率不怕传输线上的压降和干扰；
  • 再配合计数器，就构成了一位"积分型 ADC"；
  • 与 0031 的 VCO 相比，U-f 强调的是线性度与稳定性，VCO 强调的是调频速度。

六、易错点与速查表

六个高频错误

  1. 忘记"负载浮地"这个前提。浮地型 U-I 电路的负载不能接地，接了就短路到地，电流全部跑掉。
  2. 把 Howland 的平衡条件写反。R_2/R_1 = R_4/R_3，是"两个分压比相等"，不是"四个电阻全相等"。
  3. 不验算饱和。恒流源的负载上限 R_L ≤ U_om·R/u_i，超过就失效，这是必写的收尾一句。
  4. 把 I-U 的输出符号写错。电流从虚地抽走，输出为负；符号取决于二极管接法，不是"一定为正"。
  5. 以为精密整流"没有死区"。死区只是被缩小到 U_D/A_od，不是零；且大信号时运放压摆率仍会限制速度。
  6. 全波整流的权重写错。第二级两路权重是 1 : 2，不是 1 : 1；写成 1:1 就退回半波。

七、Quiz — 考研风格题

4 道题覆盖 U-I、I-U、精密整流与全波权重。算完再点。

这一课学到了什么

  1. 恒流靠反馈：把负载放进反馈支路（浮地型）或让正负反馈相抵（Howland）， 电流才与负载无关；代价分别是"负载不能接地"与"电阻必须匹配"。
  2. 虚地是 I-U 的核心：光电二极管接虚地，输出 −I_S R_f， 线性、快速、抗干扰。
  3. 精密整流 = 把二极管包进反馈环：死区从 0.7 V 降到 U_D/A_od， 弱信号才能被整流。
  4. 全波靠 1:2 加权：u_o = |u_i|，输出频率翻倍。
  5. 转换的本质是"用反馈换精度"：运放不产生能量，它只是把不理想的器件 （二极管、负载、传感器）"藏"进环路里，让外部只看到理想的关系式。
