Lesson 0009 — 共集电极与共基极放大电路

模拟电子电路 · Lesson 0009 / 0035 · 约 35 分钟

前置知识 必须掌握 Lesson 0007（共射放大电路） 的微变等效电路与 A_u = −βR_L′/r_be，以及 Lesson 0008（分压式偏置） 的 Q 点算法。这一课不引入新器件、不引入新公式体系——只把输出端从集电极换到射极、或者把基极接地， 同一个晶体管就变出了三种完全不同的「性格」。

前面两课我们一直默认：输入进基极、输出从集电极取、发射极接地。这只是三种接法中的一种。 晶体管只有三个电极，任选一个作公共端（交流地），剩下两个一个作输入、一个作输出， 一共只有三种组合。这三种组合的增益、输入/输出电阻、频率特性差别巨大，是选择题和多级放大器级间搭配的高频考点。

一、三种组态是怎么分的

判断组态只看两件事：信号从哪个电极进、从哪个电极出。剩下的第三个电极就是公共端， 组态以它命名。

组态信号怎么走（输入 → 输出）结论
共射 CE
公共端：射极 e		 b 进 → c 出（e 交流接地） 反相，电压增益大（几十~几百），Ri 中、Ro 中
共集 CC
公共端：集电极 c		 b 进 → e 出（c 交流接地） 同相，电压增益 ≈1，Ri 大、Ro 小

判断口诀 「输入输出之外的那个电极，就是公共端」。共集电路的集电极接 VCC，交流等效为地， 所以叫共集；共基电路的基极通过旁路电容接地，所以叫共基。
易错点 「共射」的「射」说的是发射极是公共端（交流接地），不是「信号从发射极射出去」。 共射电路的输出始终取在集电极，发射极只是交流地。真正让信号从发射极输出的是共集电路 （射极跟随器）。别把「直流电流 iC 从 c 流到 e」当成「信号从 e 出去」——直流偏置决定工作点， 交流信号走哪条路要画交流通路才看得清。

二、共集电极电路：射极跟随器

把负载从集电极挪到发射极，就是共集电极电路。它的输出电压「跟着」输入电压走， 所以又叫射极跟随器（Emitter Follower）。

1. 直流：先算 Q 点

直流通路里 C1、C2 开路，基极回路的方程是：

I_B = (V_CC − U_BE) / [R_b + (1+β)R_e]　　I_E = (1+β)I_B　　U_CE = V_CC − I_E R_e

分母里的 (1+β)R_e 来自折算：射极电流是基极电流的 (1+β) 倍。 这条规则算输入电阻时还要再用一次。

2. 交流：电压增益略小于 1

画微变等效电路时，集电极接 VCC（交流地），所以集电极直接接地； 发射极通过 Re∥RL 接地。输入电压 ui 加在 b、e 之间， 输出电压 uo 取自 e 对地。列 KVL 可得：

A_u = (1+β)(R_e∥R_L) / [r_be + (1+β)(R_e∥R_L)] < 1，且为正（同相）

分母比分子多了一个 r_be，所以增益永远小于 1，但通常能达到 0.95~0.99。 电压不放大，但电流放大了 (1+β) 倍，功率仍有增益——这正是缓冲级的价值： 把高阻源的信号「搬」到低阻负载上。

3. 输入电阻大、输出电阻小

R_i = R_b ∥ [r_be + (1+β)(R_e∥R_L)]　　R_o = R_e ∥ [(r_be + R_b∥R_s) / (1+β)]
  • Ri 大：发射极电阻折算到基极被放大 (1+β) 倍，所以输入电阻可达几十 kΩ 甚至上百 kΩ，对前级几乎不取电流。
  • Ro 小：从输出端往回看，基极回路的电阻被缩小 (1+β) 倍，输出电阻只有几十 Ω，带负载能力强。
  • 两者是同一件事的两面：射极跟随器本质上是电压串联负反馈，负反馈「抬高 Ri、压低 Ro」。
典型用途 ① 多级放大器的输入级（提高整机 Ri）；② 输出级（降低 Ro、驱动低阻负载）； ③ 级间缓冲（避免后级低 Ri 拖垮前级增益）。

三、共基极电路

把基极通过旁路电容接地，信号从射极进、从集电极出，就是共基极电路。 它的输入电阻极小、频率特性最好，是高频宽带的「专用组态」。

1. 电压增益与相位

A_u = +β(R_c∥R_L) / r_be　（同相）

为什么是正号？设 ui 升高 → 发射极电位升高 → UBE 减小 → IE、IC 减小 → Rc 上的压降减小 → 集电极电位 uo 升高。输入升、输出也升，所以同相。 注意增益的大小与共射完全相同（都是 βRL′/rbe），只是相位相反。

2. 输入电阻极小、输出电阻大

R_i = r_be / (1+β) ≈ 几 Ω ~ 几十 Ω　　R_o ≈ R_c

从射极看进去，基极回路的 rbe 被缩小 (1+β) 倍，所以输入电阻只有十几欧。 这是共基电路最致命的缺点：如果信号源内阻较大，源电压会在内阻上被大幅分压， 实际有效增益远小于 βRL′/rbe。所以共基电路必须配低阻信号源， 工程上常把共集（低输出电阻）放在它前面，组成「共集—共基」级联。

3. 为什么高频特性好

共射的 Cb′c 跨接输入输出，被密勒效应放大 (1+|Au|) 倍，带宽被压低； 共基的基极交流接地，Cb′c 一端接地，无密勒倍增， 所以上限频率最高，常用于高频、宽带和 cascode（共射—共基）结构。

五、考研例题与易错点

例题 1：射极跟随器的四个参数

共集电路，VCC = 12 V，Rb = 200 kΩ，Re = 2 kΩ，RL = 2 kΩ， β = 100，rbe = 1 kΩ，信号源内阻 Rs = 1 kΩ。求 Au、Ri、Ro。

解

  1. 交流负载：RL′ = Re∥RL = 2∥2 = 1 kΩ。
  2. 折算：rbe + (1+β)RL′ = 1 + 101×1 = 102 kΩ。
  3. Au = 101×1 / 102 = 0.990（同相，略小于 1）。
  4. Ri = Rb ∥ 102 kΩ = 200∥102 = 67.5 kΩ。
  5. Rb∥Rs = 200∥1 ≈ 0.995 kΩ，则 Ro = Re ∥ [(1 + 0.995)/101] = 2 kΩ ∥ 19.8 Ω ≈ 19.6 Ω。

输出 20 Ω、输入 67.5 kΩ，即「阻抗变换」；把 Re 当 Ro 会差 100 倍。

例题 2：共基电路与共射的对照

同一只管子（β = 100，rbe = 1 kΩ），Rc = 5 kΩ，RL = 5 kΩ， 分别接成共射和共基，求 Au、Ri、Ro。

解：RL′ = 5∥5 = 2.5 kΩ。

参数共射共基
Au−100×2.5/1 = −250+100×2.5/1 = +250
Ri≈rbe = 1 kΩ1 kΩ/101 ≈ 9.9 Ω
Ro≈Rc = 5 kΩ≈Rc = 5 kΩ

增益大小完全一样，只差一个负号；输入电阻差 100 倍。若信号源内阻 Rs = 50 Ω， 共基电路的实际源电压利用率只有 9.9/(50+9.9) ≈ 16.5%，有效增益降到约 41。 这就是「共基必须配低阻源」的定量含义。

易错点

  1. 共集 Au 略小于 1。 带载更小，Au=1 只是近似。
  2. 共集 Ro 不是 Re。 要把基极回路电阻除以 (1+β) 再与 Re 并联，结果通常只有几十欧。
  3. 共基 Au 取正号。 它与共射大小相同、相位相反，是选择题的常设坑。
  4. 共基 Ri 极小。 不能直接拿 Au 乘源电压，必须先算源内阻分压。
  5. 「电压不放大」不等于「没有放大」。 共集的电流增益是 (1+β)，功率增益仍然可观。
  6. 共基没有密勒效应，但仍有结电容和输出端负载，频响好不等于「无上限」。
