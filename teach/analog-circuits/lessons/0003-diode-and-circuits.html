Lesson 0003 — 二极管及其电路

模拟电子电路 · Lesson 0003 / ∞ · 约 30 分钟

前置知识 必须掌握 Lesson 0002（PN 结）——尤其是正向/反向偏置、势垒、肖克利方程。 二极管就是一个单独的 PN 结，这一课是把 PN 结原理变成真正能用的电路。

这一课的定位

上一课你搞懂了 PN 结为什么有单向导电性。现在我们把 PN 结的两端各拉一根线， 就得到了一个二极管（Diode）。考研中二极管电路是高频考点—— 题型是"给定电路 + 输入波形，求输出波形/电压"。

这一课要搞定三件事：

  1. 二极管的三种模型（分析电路的"尺子"，根据精度需求选一把）
  2. 考研高频应用电路（限幅、钳位、整流、稳压管——每一个都考过）
  3. 电路分析套路（遇到含二极管的电路，按什么步骤下手）

一、二极管的符号与伏安特性

伏安特性曲线和 PN 结完全相同——就是把肖克利方程画出来：

区域电压条件电流特征二极管状态
正向 U > 导通阈值（硅 ≈ 0.5V 开始，0.7V 完全导通） I 指数增长 导通
反向截止 −B_v < U < 0 I ≈ −Iₛ ≈ 0（nA 级） 截止
反向击穿 U ≤ −B_v（击穿电压） I 急剧增大 击穿（稳压管利用此特性）

二、二极管的三种电路模型

二极管是非线性器件——直接用肖克利方程解电路会得到超越方程，手算极难。 工程上用分段线性近似，根据精度需求选模型：

模型 1：理想模型（最粗糙，分析大方向时用）

  • 适用场景：粗略分析电路工作原理、判断哪个二极管导通、定性波形分析
  • 特点：计算极简，但硅二极管会有 ~0.7V 误差

模型 2：恒压降模型（考研首选，精度够用）

  • 适用场景：考研 90% 的二极管电路分析都用这个模型
  • 记忆：硅管 0.7V，锗管 0.3V

模型 3：折线模型（最精确，分析细节时用）

  • 适用场景：精确计算导通电流、分析电阻分压器中的二极管
  • 考研中偶尔出现，但恒压降模型是绝对主力
考研选择题陷阱 当题目明确说"用理想模型分析"时，不能用 0.7V。 当题目没说——默认用恒压降模型（硅 0.7V）。 锗管一般会明确说"锗二极管"或"1N34A"之类的型号。

三、含二极管电路的分析步骤

遇到含多个二极管的电路，按以下 4 步走：

四步分析法
  1. 拆：把所有二极管从电路里拔掉，用开路代替，分别算出每个二极管两端的开路电压 U_D（= 阳极电压 − 阴极电压）。
  2. 判：U_D > 0.7 V → 正向偏置，记为「候选导通」；U_D < 0.7 V → 反向偏置，判为截止。
  3. 定优先级：多个候选导通时，U_D 最大的先导通；它导通后会改变其他二极管的 U_D，必须重新计算。
  4. 求解：导通的用 0.7 V 电压源代替，截止的用开路代替，再用 KVL / KCL 解线性电路。

举个考研典型例题：

解（恒压降模型，硅管 0.7 V）

  1. 拆：D1、D2 都用开路代替。D1 两端 U_D1 = 12 − 0 = 12 V（阳 12 V、阴 0 V）；D2 两端 U_D2 = 0 − 0 = 0 V。
  2. 判：U_D1 = 12 V > 0.7 V → D1 候选导通；U_D2 = 0 V → D2 截止。
  3. 定优先级：只有一个候选，D1 直接导通。
  4. 求解：D1 用 0.7 V 电压源代替 → U_O = 12 − 0.7 = 11.3 V。回代检验：D2 阴极 = 11.3 V、阳极 = 0 V，反向偏置，确认截止 ✅

四、考研高频应用电路

应用 1：限幅电路（最常考）

限幅电路的功能是：把信号幅度限制在某个范围内，超过就"削掉"。 有两种基本类型：

串联限幅

二极管串联在信号通路中。二极管导通时 = 短路，信号通过；截止时 = 开路，信号被切断。

  • 下限幅：D 正向串入（如上图）→ 保留正半周，削掉负半周
  • 上限幅：D 反接 → 保留负半周，削掉正半周
  • 双向限幅：两个二极管反向并联 → 正负峰同时被削

并联限幅

二极管并联在输出端。二极管截止时 = 开路，信号通过；导通时 = 短路到参考电平。

记法 串联限幅：D 串在通路里 → 截止时断路 → 信号过不去 并联限幅：D 并在输出端 → 导通时短路 → 输出被钳住 削掉哪个极性 → 看二极管的导通方向

应用 2：钳位电路（箱位电路）

钳位电路的功能是：把信号的峰值钳在某个直流电平上，但不改变波形形状。 与限幅电路的区别：限幅削幅度，钳位加直流。

  • 负钳位：二极管阴极接输出节点（如上图）→ 负峰钳到 0 V，正峰抬到 +2V_p
  • 正钳位：二极管反接 → 正峰钳到 0 V，负峰降到 −2V_p
  • 双向钳位：两个二极管 + 两个电容，分别钳正负峰

应用 3：整流电路（二极管最经典应用）

整流 = 把交流电变成直流电。二极管的单向导电性就是核心。

半波整流

桥式全波整流（最常用）

  • 图中的 R 就是负载，输出 v_o 取自 R 两端（上为正、下为负）
  • 正半周（左端为正）：电流 v_i+ → D1 → R → D4 → v_i−
  • 负半周（右端为正）：电流 v_i− → D2 → R → D3 → v_i+
  • 精髓：无论正负半周，流过 R 的电流方向始终不变 → 得到全波
  • 平均电压 ≈ 0.636 V_m（是半波的两倍）
电路平均输出电压 V_O二极管平均电流 I_D最大反向电压 U_RM
半波整流 0.318 V_m 0.45 V_m / R √2 · V_2 ≈ 1.414 V_2
全波（双二极管） 0.636 V_m 0.45 V_m / R（每个二极管） 2√2 · V_2 ≈ 2.828 V_2
桥式全波 0.636 V_m 0.45 V_m / R（每个二极管） √2 · V_2 ≈ 1.414 V_2
记忆口诀 半波平均 0.45 V_2，全波/桥式平均 0.9 V_2（V_2 是有效值）。 二极管最大反向电压：半波 = 桥式 = √2 V_2 ≈ 1.414 V_2， 全波（双管）= 2.828 V_2（这是全波的缺点——二极管耐压要求高）。

应用 4：稳压管（反向击穿区的应用）

稳压管（Zener Diode）就是特意工作在反向击穿区的二极管。 反向击穿后，即使电流变化很大，电压几乎不变——这就是稳压的来源。

  • 稳压管反向击穿后，U_O = U_Z（稳压值，基本恒定）
  • R 的作用：限制电流 + 分压，U_i = I·R + U_Z
  • 稳压条件：I_Zmin ≤ I_Z ≤ I_Zmax，I_Zmin ≈ 1~2 mA
  • I_Zmax = P_Z / U_Z（P_Z 为额定耗散功率，如 0.5 W、1 W）

五、Quiz — 考研风格题

这一课学到了什么

  1. 三种模型的选择：理想（粗糙）→ 恒压降（考研主力）→ 折线（精确）
