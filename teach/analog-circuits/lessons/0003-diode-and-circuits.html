Lesson 0003 — 二极管及其电路

模拟电子电路 · Lesson 0003 / ∞ · 约 30 分钟

前置知识 必须掌握 Lesson 0002（PN 结）——尤其是正向/反向偏置、势垒、肖克利方程。 二极管就是一个单独的 PN 结，这一课是把 PN 结原理变成真正能用的电路。

这一课的定位

上一课你搞懂了 PN 结为什么有单向导电性。现在我们把 PN 结的两端各拉一根线， 就得到了一个二极管（Diode）。考研中二极管电路是高频考点—— 题型是"给定电路 + 输入波形，求输出波形/电压"。

这一课要搞定三件事：

  1. 二极管的三种模型（分析电路的"尺子"，根据精度需求选一把）
  2. 考研高频应用电路（限幅、钳位、整流、稳压管——每一个都考过）
  3. 电路分析套路（遇到含二极管的电路，按什么步骤下手）

一、二极管的符号与伏安特性

  二极管电路符号：

  阳极(+) ──▶┤ ├── 阴极(−)

  PN 结对应：    P  ──▶┤ ├──  N
               阳极       阴极

  正向导通方向：从阳极流向阴极（箭头方向）
  反向截止方向：从阴极到阳极（反向偏置）

伏安特性曲线和 PN 结完全相同——就是把肖克利方程画出来：

区域电压条件电流特征二极管状态
正向 U > 导通阈值（硅 ≈ 0.5V 开始，0.7V 完全导通） I 指数增长 导通
反向截止 −B_v < U < 0 I ≈ −Iₛ ≈ 0（nA 级） 截止
反向击穿 U ≤ −B_v（击穿电压） I 急剧增大 击穿（稳压管利用此特性）

二、二极管的三种电路模型

二极管是非线性器件——直接用肖克利方程解电路会得到超越方程，手算极难。 工程上用分段线性近似，根据精度需求选模型：

模型 1：理想模型（最粗糙，分析大方向时用）

  理想二极管等效电路：

  正向导通 → 短路（U = 0，没有压降）
  反向截止 → 开路（I = 0，没有电流）

  ┌── 理想 ──┐        ┌── 实际（硅）──┐
  │0.7V│     │        │  ~0.7V 压降   │
  │    │     │        │               │
  └────┴─────┘        └───┴───────────┘
      U                   U
  • 适用场景：粗略分析电路工作原理、判断哪个二极管导通、定性波形分析
  • 特点：计算极简，但硅二极管会有 ~0.7V 误差

模型 2：恒压降模型（考研首选，精度够用）

  恒压降模型等效电路：

  正向导通 → 串联一个 0.7V 电压源（硅）/ 0.3V（锗）
  反向截止 → 开路

  ┌── 恒压降 ──┐
  │   0.7V │   │
  │        │   │
  └────────┴───┘
         U

  等效为： ──|>|── 0.7V 电压源（阳极接电压源+端）
  • 适用场景：考研 90% 的二极管电路分析都用这个模型
  • 记忆：硅管 0.7V，锗管 0.3V

模型 3：折线模型（最精确，分析细节时用）

  折线模型等效电路：

  正向导通 → 串联一个 0.5V 电压源 + 一个 20Ω 电阻（硅的典型值）
  反向截止 → 开路

  本质：把伏安特性曲线的导通段用一条直线近似
  → 不是理想短路，而是有约 20Ω 的动态电阻
  • 适用场景：精确计算导通电流、分析电阻分压器中的二极管
  • 考研中偶尔出现，但恒压降模型是绝对主力
考研选择题陷阱 当题目明确说"用理想模型分析"时，不能用 0.7V。 当题目没说——默认用恒压降模型（硅 0.7V）。 锗管一般会明确说"锗二极管"或"1N34A"之类的型号。

三、含二极管电路的分析步骤

遇到含多个二极管的电路，按以下 4 步走： 

  ★ 四步分析法 ★

  Step 1：把所有二极管都从电路里"拆出来"，分别计算每个二极管两端的电压
          （假设二极管不存在，用开路代替，算开路电压 U_D）

  Step 2：判断每个二极管的偏置状态
          U_D > 0.7V → 正向偏置 → 可能导通（记为"候选导通"）
          U_D < 0.7V → 反向偏置 → 截止（开路）

  Step 3：如果有多个候选导通的二极管
          → 优先"导通电压最低"的那个（即 U_D 最大的那个先导通）
          → 它导通后会影响其他二极管的 U_D → 重新计算

  Step 4：把导通的二极管用"0.7V 电压源"代替，截止的用"开路"代替
          → 用线性电路知识（KVL、KCL）求解

举个考研典型例题： 

  例题：电路如下，求 U_O（恒压降模型，硅管）

     +12V
      │
      ├── D1(阳极)  D1(阴极) ── GND
      │
      D2(阴极)      D2(阳极) ── GND
      │
     U_O

  Step 1：拆除 D1、D2，算开路电压
  D1: U_D1 = 12 - 0 = 12V（P端=12V，N端=0V）→ 正向偏置
  D2: U_D2 = 0 - 0 = 0V（P端=0V，N端=0V）→ 零偏

  Step 2：D1 候选导通，D2 可能截止
  Step 3：D1 优先导通

  Step 4：D1 用 0.7V 电压源代替
  U_O = 12 - 0.7 = 11.3V

  此时 D2 的阴极 = 11.3V，阳极 = 0V → 反向偏置，确认截止 ✅

四、考研高频应用电路

应用 1：限幅电路（最常考）

限幅电路的功能是：把信号幅度限制在某个范围内，超过就"削掉"。 有两种基本类型：

串联限幅

二极管串联在信号通路中。二极管导通时 = 短路，信号通过；截止时 = 开路，信号被切断。 

  串联上限幅：

  输入 v_i ──▶ R ──┬── D(阳极) ── D(阴极) ── 输出 v_o
                    │
                   V_ref

  当 v_i > V_ref + 0.7V 时 → D 导通 → v_o ≈ V_ref + 0.7V（被限制）
  当 v_i < V_ref + 0.7V 时 → D 截止 → v_o ≈ v_i（信号通过）

  ★ 上限幅：削掉正峰值
  ★ 下限幅：二极管反过来，削掉负峰值
  ★ 双向限幅：两个二极管相向并联，同时削正负峰

并联限幅

二极管并联在输出端。二极管截止时 = 开路，信号通过；导通时 = 短路到参考电平。 

  并联限幅：

  输入 v_i ──▶ R ──┬── 输出 v_o
                    │
                    ├── D(阳极) ── V_ref

  二极管与负载并联，导通时把输出钳在 V_ref + 0.7V
  （原理相同，只是接法不同——考研中两种都可能考）
记法 串联限幅：D 串在通路里 → 截止时断路 → 信号过不去 并联限幅：D 并在输出端 → 导通时短路 → 输出被钳住 削掉哪个极性 → 看二极管的导通方向

应用 2：钳位电路（箱位电路）

钳位电路的功能是：把信号的峰值钳在某个直流电平上，但不改变波形形状。 与限幅电路的区别：限幅削幅度，钳位加直流。 

  钳位电路（负峰值钳位到零）：

  输入 v_i ──▶ C ──┬── 输出 v_o
                   │
                   ├── D(阴极接节点，阳极接 GND)

  原理：电容充电到峰值，信号整体"抬高"或"降低"
  使钳位端正好落在参考电平上

  v_i 是 ±V_p 的正弦波 → 电容 C 充电到 V_p
  v_o = v_i + V_p → 负峰值被钳在 0V，正峰值变成 +2V_p

  ★ 正钳位：把正峰值钳到参考电平（二极管反接）
  ★ 负钳位：把负峰值钳到参考电平（如上图）
  ★ 双向钳位：两个二极管 + 两个电容，分别钳正负峰值

应用 3：整流电路（二极管最经典应用）

整流 = 把交流电变成直流电。二极管的单向导电性就是核心。

半波整流

  半波整流：

  交流输入 v_i ──▶ D ──▶ R ── GND

  v_i 正半周 → D 导通 → 电流通过 R → v_o = v_i - 0.7V
  v_i 负半周 → D 截止 → 无电流 → v_o = 0

  输出：只有正半周被保留，负半周被削掉
  脉动大，平均电压 ≈ 0.318 V_m（V_m 是峰值）

桥式全波整流（最常用）

  桥式整流（4 个二极管）：

        D1  D2
       ┌─▶┤  ├─▶┐
  v_i ─┤        ├─ R ─ GND
       └─◀┤  ├─◀┘
        D3  D4

  正半周：v_i+ → D1 → R → D4 → v_i−（电流从 v_i+ 经 R 到 v_i−）
  负半周：v_i− → D2 → R → D3 → v_i+（电流仍然从 R 的上端流向下端！）

  ★ 全波整流的精髓：无论正负半周，流过 R 的电流方向始终不变
  ★ 平均电压 ≈ 0.636 V_m（半波的两倍）
  ★ 考研常考：求输出平均电压、二极管平均电流、二极管承受的最大反向电压
电路平均输出电压 V_O二极管平均电流 I_D最大反向电压 U_RM
半波整流 0.318 V_m 0.45 V_m / R √2 · V_2 ≈ 1.414 V_2
全波（双二极管） 0.636 V_m 0.45 V_m / R（每个二极管） 2√2 · V_2 ≈ 2.828 V_2
桥式全波 0.636 V_m 0.45 V_m / R（每个二极管） √2 · V_2 ≈ 1.414 V_2
记忆口诀 半波平均 0.45 V_2，全波/桥式平均 0.9 V_2（V_2 是有效值）。 二极管最大反向电压：半波 = 桥式 = √2 V_2 ≈ 1.414 V_2， 全波（双管）= 2.828 V_2（这是全波的缺点——二极管耐压要求高）。

应用 4：稳压管（反向击穿区的应用）

稳压管（Zener Diode）就是特意工作在反向击穿区的二极管。 反向击穿后，即使电流变化很大，电压几乎不变——这就是稳压的来源。 

  稳压管电路：

  输入 U_i ──▶ R ──┬── 输出 U_O
                   │
                   ├── 稳压管(阴极接输入侧，阳极接 GND)
                   │
                  GND

  稳压管反向击穿后，U_O = U_Z（稳压值，基本恒定）
  R 的作用：限制电流 + 分压（U_i = I·R + U_Z）

  关键条件：稳压管电流必须在 I_Zmin ~ I_Zmax 之间
  I_Zmin ≈ 1~2 mA（太小不能稳定）
  I_Zmax = P_Z / U_Z（耗散功率不能超过 P_Z）
  P_Z 是稳压管的额定耗散功率（如 0.5W、1W）
