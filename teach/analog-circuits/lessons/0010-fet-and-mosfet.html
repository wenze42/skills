Lesson 0010 — 场效应管：JFET 与 MOSFET

模拟电子电路 · Lesson 0010 / 0020 · 约 35 分钟

前置知识 需要 Lesson 0004（BJT 结构与原理） 和 Lesson 0005（BJT 特性曲线与工作区） 的 「输入控制输出」思路。这一课把控制量从基极电流换成栅源电压， 其余的分析套路（特性曲线 → 工作区 → Q 点）完全平行。

到此为止，我们所有的放大器件都是 BJT：靠基极电流控制集电极电流。但还有另一大类器件—— 场效应管（Field Effect Transistor，FET）。它靠电场控制沟道里的多数载流子， 栅极几乎不取电流，输入电阻可以高到 109 Ω 以上。集成运放的输入级、手机里的射频开关、 电源里的功率开关，用的几乎都是它。

一、从 BJT 到 FET：电压控制

两类器件的本质区别只有一句话：

BJT（双极型）FET（单极型）
控制量基极电流 iB栅源电压 uGS
受控量集电极电流 iC漏极电流 iD
输入电阻低，rbe 约 kΩ 级极高，107~1015 Ω
载流子电子和空穴都参与只有一种多数载流子
关系iC = βiB（线性）iD = f(uGS)（平方律）

「电压控制」带来两个直接后果：第一，输入电阻极高，前级几乎不被负载； 第二，栅极不取稳态电流，所以偏置电阻可以取得很大，这在集成电路里极省面积。 代价是跨导 gm 通常比 BJT 的 β/rbe 小，同样条件下的电压增益往往低一些。

二、JFET 的结构与夹断

结型场效应管（Junction FET，JFET）是最基础的一种。以 N 沟道为例： 在一小块 N 型半导体两侧各扩散一个 P+ 区，两个 P+ 区在管内连在一起引出栅极 G； N 型半导体的两端分别引出漏极 D和源极 S。

工作时漏源之间加正电压 UDS，栅源之间加负电压 UGS， 使两个 P+N 结都反向偏置。反偏电压越负，耗尽层越宽，留给电流通过的 N 沟道越窄， 沟道电阻越大，ID 越小。这就是「用电压控制电流」的物理机制。

  • UGS = 0：耗尽层最窄，沟道最宽，ID 达到最大，记为 IDSS。
  • UGS 变负：沟道逐渐变窄，ID 减小。
  • UGS = UP：两侧耗尽层在沟道中间相遇，沟道被夹断，ID ≈ 0。 UP 叫夹断电压，也写作 UGS(off)，N 沟道时为负值（如 −4 V）。
极性不能错 N 沟道 JFET：UDS > 0，UGS ≤ 0；P 沟道全部反过来。 若 UGS 加正，栅极 PN 结正偏导通，栅极会吸入电流，失去「高输入电阻」的意义，甚至损坏管子。 所以 JFET 只有耗尽型，没有增强型——它不能靠正栅压「增强」出沟道。

三、转移特性：平方律

把 ID 随 UGS 的变化画出来，就是转移特性。 在恒流区内，它近似为一条抛物线：

I_D = I_DSS (1 − U_GS / U_P)²　　（U_P < U_GS ≤ 0，N 沟道）

曲线的三个关键点必须记住：

  • UGS = 0 → ID = IDSS（最大）；
  • UGS = UP → ID = 0（夹断）；
  • UGS = UP/2 → ID = IDSS/4（代入平方律即可验证）。

注意公式里的 UP 是带符号的负值。若题目给「夹断电压 4 V」而没说正负， N 沟道要自己补上负号，写成 UP = −4 V，否则整个计算都会反号。

四、MOSFET：增强型与耗尽型

MOS 场效应管（Metal-Oxide-Semiconductor FET）把 JFET 的 P+N 结栅极换成了 「金属（多晶硅）—SiO2 绝缘层 — 半导体」结构。栅极与沟道之间是绝缘的， 所以输入电阻比 JFET 还高几个数量级（可达 1012 Ω 以上）。

1. 增强型 NMOS

衬底是 P 型，漏、源是两个 N+ 区，但两者之间没有现成的沟道。 当 UGS 增大到超过开启电压 UGS(th)（也叫阈值电压 Uth，约 2~5 V）时， 栅极电场把衬底表面的电子吸引过来，形成反型层，把漏源连通，才出现 ID。

I_D = I_DO (U_GS / U_GS(th) − 1)²　（U_GS > U_GS(th)）

增强型的特点：UGS = 0 时截止，必须加正栅压才导通； 没有 IDSS，也没有夹断电压，只有开启电压。它是数字电路和功率开关的主力。

2. 耗尽型 NMOS

制造时在 SiO2 下预置了一条 N 型沟道，所以 UGS = 0 时就已经导通， 此时电流就是 IDSS。UGS 可正可负：加正压沟道变宽（增强），加负压沟道变窄（耗尽）， 负到 UGS(off) 时夹断。转移特性与 JFET 形状相同，也用平方律描述。

类型UGS = 0 时关键参数典型用途
JFET（N 沟道）导通（IDSS）夹断电压 UP < 0低噪声输入级、模拟开关
耗尽型 MOS导通（IDSS）UGS(off)恒流源、音频放大
增强型 MOS截止开启电压 UGS(th) > 0数字电路、功率开关、CMOS

3. 衬底怎么接、栅极怎么保护

MOS 管有四端：G、D、S 和衬底 B。衬底与漏、源之间各有一个 PN 结，必须保证不导通， 所以分立管通常把衬底与源极在内部短接；集成电路里所有 NMOS 共用一个 P 型衬底， 衬底接最低电位（PMOS 的 N 阱接最高电位）。

静电保护（必考常识） 栅极的 SiO2 只有几十纳米厚，输入电阻又极高，身上一点静电电荷就无处泄放， 几十伏就能把氧化层击穿，而且是永久损坏。所以：取用时分立管三脚短接、烙铁可靠接地、 电路里给栅极加对地电阻或保护稳压管；测试时绝不能把栅极悬空。

五、输出特性、跨导与对比

固定一个 UGS，画 ID 随 UDS 的变化，得到一条输出特性曲线； 换几个 UGS 就得到一族曲线。它们把平面分成三个区：

工作区条件（N 沟道）特征用途
可变电阻区 UDS < UGS − Uth（增强型）
或 UDS < UGS − UP（JFET）		 ID 随 UDS 近似线性，等效为一个受 UGS 控制的小电阻 RDS(on) 模拟开关、压控电阻
恒流区（放大区） UDS > 上式临界值，且 UGS 已使沟道导通 ID 几乎只由 UGS 决定，交流等效为受控电流源 放大、恒流源
截止区 UGS < Uth（增强型）或 UGS < UP（JFET） ID ≈ 0 开关断开
击穿区 UDS 超过漏源击穿电压 ID 急剧上升，可能损坏 应避免

1. 跨导 gm

FET 的放大能力用跨导衡量，定义是固定 UDS 时，漏极电流变化量与栅源电压变化量之比：

g_m = ΔI_D / ΔU_GS |_{U_DS 恒定}　（单位 mS，即 mA/V）

对 JFET 和耗尽型 MOS，把平方律求导可得三个等价写法：

g_m = (2 I_DSS / |U_P|)(1 − U_GS/U_P) = 2√(I_D · I_DSS) / |U_P| = 2I_D / |U_GS − U_P|

在 UGS = 0 处跨导最大，gm0 = 2IDSS/|UP|。 有些教材把分母 |UGS − UP| 近似成 |UP|，写成 g_m ≈ 2I_D/|U_P|；做题时若题目给了 UGS，用精确式更稳妥。 增强型 MOS 则用 g_m = 2I_D/(U_GS − U_GS(th))。

2. 考研例题

例 1：N 沟道 JFET，IDSS = 4 mA，UP = −4 V，UGS = −2 V。 求 ID 与 gm。

  1. ID = 4×(1 − (−2)/(−4))² = 4×(1 − 0.5)² = 1 mA。
  2. gm = 2√(1×4)/4 = 1 mS；用另一式验证：2×4/4×(1−0.5) = 1 mS ✅

例 2：增强型 NMOS，UGS(th) = 2 V，UGS = 3 V，ID = 1 mA。 求 gm：gm = 2×1/(3−2) = 2 mS。

3. 易错点

  1. UP 是负值。 公式里必须代 −4 V 而不是 4 V，否则平方项符号全错。
  2. IDSS 不是「最大漏极电流」。 它只是 UGS = 0 时的饱和电流；增强型 MOS 根本没有 IDSS。
  3. 恒流区不是理想电流源。 曲线仍有微小上翘，对应输出电阻 rds，只是通常远大于外接电阻，可以忽略。
  4. 栅极电流≈0 ≠ 栅极可以悬空。 MOS 栅极悬空会积累静电，几分钟就能击穿氧化层。
  5. gm 的单位是 mS。 gm(mS) × R(kΩ) 直接得无量纲增益，不要再多乘 10−3。
  6. JFET 没有增强型。 说「JFET 加正栅压增强沟道」是错的，正栅压只会让栅结正偏。
