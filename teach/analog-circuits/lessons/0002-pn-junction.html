Lesson 0002 — PN 结：单向导电性的秘密

模拟电子电路 · Lesson 0002 / ∞ · 约 25 分钟

前置知识 如果你还没读过 Lesson 0001，请先快速过一遍半导体、N 型、P 型的概念——这一课直接建立在那上面。

这一课为什么重要

上一课我们学了：N 型半导体多电子，P 型半导体多空穴。 现在——把这两种材料紧密地贴在一起，会发生什么？

这个问题的答案，就是整个电子工业的起点。二极管、三极管、MOS 管、 你手机里几十亿个晶体管——本质上都是 PN 结的不同组合。

接触前 vs 接触后：一场"电荷难民潮"

接触前：各安其位

一块 N 型半导体，旁边放一块 P 型半导体。两块都是电中性的—— 虽然 N 型里有很多自由电子，但也有等量的施主离子（带正电）； 虽然 P 型里有很多空穴，但也有等量的受主离子（带负电）。 

  接触前：

  N 型半导体（左）          P 型半导体（右）
  ┌──────────────┐          ┌──────────────┐
  │ ⊕ e⁻ ⊕ e⁻ ⊕ │          │ ⊕ ⊕ ○ ⊕ ○ ⊕ │
  │ e⁻ ⊕ e⁻ ⊕ e⁻│          │ ○ ⊕ ⊕ ○ ⊕ ○ │
  │ ⊕ e⁻ ⊕ e⁻ ⊕ │          │ ⊕ ○ ⊕ ⊕ ○ ⊕ │
  └──────────────┘          └──────────────┘
    电子多，整体中性          空穴多，整体中性

N 型里有高浓度自由电子（多数载流子浓度 ≈ 掺杂浓度 10¹⁵~10¹⁸ cm⁻³）， P 型里几乎没有自由电子（少数载流子，浓度 ≈ nᵢ²/p ≈ 10⁴~10⁷ cm⁻³）。 这种浓度差——就是一切的驱动力。

接触瞬间：扩散运动开始了

当两块半导体真正接触时——浓度差导致扩散，就像一滴墨水滴入清水：

  • N 型中的大量自由电子 → 向 P 型区域扩散
  • P 型中的大量空穴 → 向 N 型区域扩散

但电子和空穴都是带电粒子，它们一扩散，就会在接触区域产生一个意想不到的东西： 

  接触后，扩散刚开始：

  N 型半导体（左）    界面    P 型半导体（右）
  ┌──────────────────┬──────┬──────────────────┐
  │ ⊕ e⁻            │e⁻ →  │                  │
  │                  │← ○  │ ○                │
  │                  │     │                  │
  └──────────────────┴──────┴──────────────────┘

  注意：电子带负电，它"进入"P 型就相当于 P 型多了负电荷
  空穴带正电，它"进入"N 型就相当于 N 型多了正电荷

耗尽层与势垒：扩散被自己拦下了

空间电荷区（耗尽层）形成

扩散运动不是无限进行的——因为扩散的过程会产生一个反向电场，阻止扩散继续。 让我们看这个循环：

  1. N 型中的电子扩散到 P 型 → P 型界面附近积累负离子
  2. P 型中的空穴扩散到 N 型 → N 型界面附近积累正离子
  3. 这些离子不能移动（它们是掺杂原子，被共价键锁住了）
  4. 于是界面附近出现了一个正离子区 + 负离子区——形成内部电场

这个区域里，几乎没有可移动的载流子（都被扩散走了），所以叫耗尽层 或阻挡层。它的厚度通常在 1~10 μm 量级。 

  耗尽层形成后（静止状态）：

  N 型半导体        耗尽层（空间电荷区）         P 型半导体
  ┌──────────┬──────────────────────────┬──────────┐
  │ e⁻ ⊕ e⁻ │  ⊕ ⊕ ⊕ │     无载流子    │ ⊖ ⊖ ⊖ │ ○ ⊕ ○ │
  │          │  ⊕ ⊕ ⊕ │                  │ ⊖ ⊖ ⊖ │        │
  │ 电中性   │  正离子 │ ← 内部电场 E → │ 负离子 │ 电中性  │
  └──────────┴──────────────────────────┴──────────┘

  内部电场方向：从正离子区指向负离子区（→ 向右）

漂移运动 vs 扩散运动：动态平衡

内部电场对载流子有电场力作用，导致它们做漂移运动—— 和扩散运动方向相反：

  • 扩散：电子从 N → P，空穴从 P → N
  • 漂移（电场驱动）：电子从 P → N，空穴从 N → P

当耗尽层发展到某个厚度时，扩散电流 = 漂移电流，方向相反、大小相等， PN 结达到动态平衡。此时总电流为零，耗尽层厚度稳定。

势垒高度（接触电位差）

内部电场的存在意味着界面处有一个电位差——就像一个"小山丘"。 电子要从 N 型扩散到 P 型，必须爬过这个丘。这个电位差叫势垒高度 （也叫接触电位差或结电位）。

势垒高度 φ ≈ (0.6 ~ 0.7) V （硅，室温）
势垒高度 ≈ (0.2 ~ 0.3) V （锗，室温）
记忆点 硅的势垒 ≈ 0.7V，锗的势垒 ≈ 0.3V。这个数字后面会反复出现—— 二极管导通电压、BJT 发射结电压，本质上就是这个势垒。

偏置：给 PN 结通电

现在 PN 结在动态平衡状态，总电流为零。如果我们外接电压， 会发生什么？这就是单向导电性的来源。

正向偏置（Forward Bias）— 导通

P 接正，N 接负。外加电压与内部电场方向相反， 削弱内部电场，势垒降低，耗尽层变窄。 

  正向偏置：

  电池(+) ──── P 型 ──── 耗尽层 ──── N 型 ──── 电池(-)
  │                                              │
  │                                              │
  └──── 外加电场 与 内部电场 方向相反 ──────────┘

  效果：势垒从 0.7V 降到 ~0.2V，耗尽层变薄
  → 扩散电流 >> 漂移电流
  → 电子从 N 大量涌入 P，空穴从 P 大量涌入 N
  → PN 结 导通，形成大电流

当外加电压接近 0.7V（硅），势垒几乎消失，扩散运动畅通无阻——电流急剧增大。 这就是为什么硅二极管的导通电压 ≈ 0.7V。

反向偏置（Reverse Bias）— 截止

P 接负，N 接正。外加电压与内部电场方向相同， 增强内部电场，势垒升高，耗尽层变宽。 

  反向偏置：

  电池(-) ──── P 型 ──── 耗尽层 ──── N 型 ──── 电池(+)
  │                                              │
  │                                              │
  └──── 外加电场 与 内部电场 方向相同 ──────────┘

  效果：势垒升高，耗尽层变宽
  → 扩散运动几乎完全被阻止（载流子不够爬高势垒）
  → 只有 少数载流子 做漂移运动
  → PN 结 截止，电流极小（nA 级别）

少数载流子虽然少，但在反向电场下会被加速穿过耗尽层—— 这形成了微小的反向饱和电流 Iₛ，基本与反向电压大小无关 （因为少数载流子数量有限，用完就没了）。

反向击穿

反向偏置电压不是无限可以加的。当电压大到某个临界值时， 反向电流会突然急剧增大——这就是反向击穿。 有两种机制：

击穿类型 原理 发生条件 典型击穿电压
齐纳击穿 高电场使共价键电子被拉出（隧道效应） 高掺杂 PN 结，耗尽层薄 < 6V
雪崩击穿 少数载流子被加速撞断更多共价键（倍增效应） 低掺杂 PN 结，耗尽层宽 > 6V
稳压管 反向击穿并不一定是坏事。稳压管（齐纳二极管）就是利用 反向击穿区的恒压特性工作的——击穿后电压基本不随电流变化。 只要不过热烧毁，击穿是可逆的。

伏安特性：把上面的东西画成曲线

PN 结的电流-电压关系可以用肖克利方程描述：

I = Iₛ (e^(U / Uₜ) − 1) I：PN 结电流 Iₛ：反向饱和电流（常温下 ≈ 10⁻¹⁵ A 量级） U：外加电压 Uₜ：温度当量电压，Uₜ = kT/q ≈ 26 mV（室温 300K）

这个方程揭示了单向导电性的本质：

  • 正向（U ≫ Uₜ）：e^(U/Uₜ) 指数增长，电流急剧增大 → 导通
  • 反向（|U| ≫ Uₜ）：e^(U/Uₜ) ≈ 0，I ≈ −Iₛ → 截止
  • 击穿（反向足够大）：方程不再适用，电流急剧增大

一张图总结 PN 结

  ★ PN 结核心知识图谱 ★

  接触前          接触后（平衡）          正向偏置            反向偏置
  ───────────    ──────────────         ─────────          ─────────
  N: 多e⁻         耗尽层形成             势垒降低            势垒升高
  P: 多○          扩散 = 漂移            耗尽层变薄          耗尽层变宽
                  势垒 ≈ 0.7V           I 急剧增大          I ≈ Iₛ（极小）
                                         → 导通              → 截止

  关键公式：I = Iₛ (e^(U/Uₜ) − 1)
  关键数字：φ ≈ 0.7V（硅）, Uₜ ≈ 26mV（室温）
  击穿电压 < 6V → 齐纳击穿；> 6V → 雪崩击穿

Quiz — 确认理解

这一课学到了什么

  1. 扩散 vs 漂移：接触后浓度差驱动扩散，扩散产生电场，电场驱动反向漂移，最终动态平衡
  2. 耗尽层：界面附近无载流子的区域，内部电场就建立在这里
  3. 单向导电性：正向偏置削弱势垒→导通；反向偏置增强势垒→截止
  4. 反向击穿：齐纳击穿（低电压、高掺杂）和雪崩击穿（高电压、低掺杂）

理解了 PN 结，你就理解了所有半导体器件的心脏。下一课我们会看 二极管——它就是一个单独的 PN 结，是 PN 结原理的第一个实际应用。
