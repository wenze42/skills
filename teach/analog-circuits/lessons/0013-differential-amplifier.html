Lesson 0013 — 差分放大电路

模拟电子电路 · Lesson 0013 / 0020 · 约 40 分钟

前置知识 必须已掌握：Lesson 0007（共射放大电路的微变等效分析）、 Lesson 0008（Q 点稳定）、 Lesson 0012（直接耦合与零点漂移）。 本课的“半边电路法”就是把差分电路拆成两个熟悉的共射电路来算。

一、零点漂移：差分电路为什么存在

上一课留下一个问题：直接耦合放大电路能放大直流，但第一级的零点漂移会被后面各级放大， 在输出端可能完全淹没真正的信号。温度每升高 1 ℃，UBE 约下降 2~2.5 mV， 这个变化经过几级放大就是伏特级的错误。

抑制零漂的最有效思路不是“把管子做得更稳”，而是用对称性把漂移抵消掉： 把两个完全相同的单管放大电路并排放置，让它们处在同样的温度、同样的电源下。 温度变化时，两管的漂移一模一样；把两个输出相减，漂移就消失了。

Δu_o = (U_C1 + ΔU_漂移) − (U_C2 + ΔU_漂移) = U_C1 − U_C2

真正有用的信号则让两管反向变化，相减之后反而加倍。 这就是差分放大电路的全部思想：放大“差别”，抵消“共同”。

二、长尾式差分放大电路的结构

  • 完全对称：T1、T2 同型号，Rc1 = Rc2，Rb1 = Rb2，这是差分电路能抑制零漂的前提；
  • 长尾电阻 Re：两管发射极接在一起，共用一个 Re 到负电源 −VEE。 它给两管提供稳定的静态电流，也是抑制共模信号的关键元件；
  • 偏置电流：IE1 + IE2 ≈ (VEE − UBE) / Re， 由 Re 决定，几乎不随温度变；
  • 调零电位器 Rp：实际电路中两管不可能绝对对称，常在发射极串一个小电位器， 静态时调 Rp 使 uo = 0；
  • 两个输入、两个输出：可以双端输入/输出，也可以单端，共四种接法（第五节）。

三、共模信号与差模信号

差分电路的两个输入端电压 Ui1、Ui2 可以重新分解成两个分量：

U_id = U_i1 − U_i2　（差模信号）　　U_ic = (U_i1 + U_i2) / 2　（共模信号）

反过来也可以由这两个分量还原出原来的输入：

U_i1 = U_ic + U_id / 2　　　U_i2 = U_ic − U_id / 2

例：Ui1 = 3 mV，Ui2 = −1 mV。 则 Uid = 3 − (−1) = 4 mV，Uic = (3 − 1)/2 = 1 mV。

为什么长尾电阻只抑制共模、不影响差模

这是本课最重要的机理，务必理解而不是死记：

  • 共模：两管基极同时升高，两管电流同时增大。 流过 Re 的电流变化是 2Δie，于是 Re 上的压降变化为 2ΔieRe，对两管都形成强烈的负反馈（等效为每管 2Re）， 把共模增益压得很低；
  • 差模：一管电流增大、另一管等量减小，两者在 Re 中互相抵消， Re 上总电流不变、压降不变。对差模信号而言，Re 相当于交流接地 （叫“虚地”），完全不起负反馈作用，差模增益不受影响。
一句话总结 差模 → 发射极是虚地，半边电路就是普通共射； 共模 → 每管等效发射极电阻 2Re，增益被压到很低。 这就是“放大差别、抑制共同”的电路实现。

四、差模增益、共模增益与共模抑制比

1. 差模增益（双端输入、双端输出）

利用虚地，把差分电路沿中线劈开，取左半边：发射极接地，负载 Rc，就是标准共射电路。

A_ud = −β R_c / (R_b + r_be)

双端输出时 uo = uo1 − uo2，两管输出大小相等、方向相反，所以 uo = 2uo1；而输入 Uid = 2Ui1，分子分母的 2 约掉， 最终仍等于单管的增益表达式。

2. 共模增益（单端输出）

共模时每管发射极等效电阻为 2Re，用 Lesson 0008 的负反馈公式：

A_uc = −β R_c / [R_b + r_be + 2(1+β)R_e] ≈ −R_c / (2R_e)

近似式成立是因为 (1+β)Re 通常远大于 Rb + rbe。 双端输出时，若电路完全对称，两个集电极的共模变化相同，相减为零，理想 Auc = 0； 实际因失配只能做到很小。

3. 共模抑制比 KCMR

K_CMR = | A_ud / A_uc |　　　K_CMR(dB) = 20 lg | A_ud / A_uc |

KCMR 越大，说明电路对共模干扰（温漂、50 Hz 工频干扰、电源波动）的抑制越强。 理想双端输出 KCMR → ∞，实际 80~120 dB 都是常见值。

例题：单端输出差分电路

已知 β = 50，Rc = 10 kΩ，Rb + rbe = 2 kΩ，Re = 10 kΩ。 输入 Ui1 = 5 mV，Ui2 = 3 mV。求差模增益、共模增益、KCMR， 以及单端输出时的输出电压 uo1。

第 1 步：分解输入

U_id = 5 − 3 = 2 mV　　U_ic = (5 + 3)/2 = 4 mV

第 2 步：差模增益

A_ud = −β R_c / (R_b + r_be) = −50 × 10 k / 2 k = −250

第 3 步：共模增益

A_uc ≈ −R_c / (2R_e) = −10 k / (2 × 10 k) = −0.5

第 4 步：共模抑制比

K_CMR = |−250 / −0.5| = 500　　20 lg 500 ≈ 54 dB

第 5 步：叠加求输出

u_o1 = A_ud · U_id + A_uc · U_ic = (−250)(2 mV) + (−0.5)(4 mV)
= −500 mV − 2 mV = −502 mV

可以看到：4 mV 的共模输入只贡献了 2 mV 输出，而 2 mV 的差模输入贡献了 500 mV。 共模被压制了 250 倍，这正是差分电路的价值。

五、四种接法、恒流源与失调

1. 四种接法对比

接法AudRiRo共模抑制
双端输入 · 双端输出 −βRc/(Rb+rbe) 2(Rb+rbe) 2Rc 理想为 ∞，实际靠对称性
双端输入 · 单端输出 −βRc/[2(Rb+rbe)] 2(Rb+rbe) Rc 好（Re 起作用）
单端输入 · 双端输出 −βRc/(Rb+rbe) Rb+rbe 2Rc 较好
单端输入 · 单端输出 −βRc/[2(Rb+rbe)] Rb+rbe Rc 好
记忆规律 双端输出 → 增益是单端的两倍，Ro = 2Rc； 单端输出 → 增益减半，Ro = Rc； 双端输入 → Ri 是单端的两倍；单端输入 → 另一输入端接地，Ri 减半。

2. 恒流源偏置：把 KCMR 再抬一个数量级

从 Auc ≈ −Rc/(2Re) 看，Re 越大共模抑制越好。 但 Re 太大会吃掉大量电源电压，集成电路里也做不出大电阻。 工程上的办法是用恒流源代替 Re： 恒流源的直流电阻很小（不占电压），交流等效电阻 ro 却高达几百 kΩ 甚至 MΩ。

R_e → r_o（恒流源输出电阻） ⇒ A_uc ≈ −R_c / (2r_o) → 极小 ⇒ K_CMR 大幅提高

这就是集成运放输入级几乎一律采用“恒流源负载差分放大电路”的原因（0019 会再见到它）。

3. 失调与温漂

  • 输入失调电压 UIO：使输出为零所需在输入端加的补偿电压， 典型 1~10 mV，来源于两管 UBE 和 Rc 的不匹配；
  • 输入失调电流 IIO：两管基极电流之差，典型 nA~μA 级；
  • 温漂：UIO、IIO 随温度的变化率，单位 μV/℃。 它比失调本身更可怕，因为无法用一次调零解决；
  • 对策：调零电位器、提高对称性、恒流源偏置、斩波稳零（集成运放内部）。
