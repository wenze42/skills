Lesson 0030 — 电压比较器

模拟电子电路 · Lesson 0030 / 0035 · 约 50 分钟

前置知识 需要 Lesson 0019（运放基础与虚短虚断） 和 Lesson 0020（运放应用与正弦波振荡）。 0020 里已经出现过比较器和滞回比较器的影子，这一课把它们讲透： 虚短什么时候失效、门限怎么定、回差怎么算、波形怎么画。

前面二十几课，运放几乎都待在负反馈里：虚短、虚断、线性放大。 从这一课开始，我们故意把负反馈拆掉，让运放去干一件更粗糙也更常用的事—— 比较两个电压谁大。

比较器的输出只有两个状态：高电平或低电平。它不放大、不保真、不允许中间态， 本质是一个"1 位 ADC"。示波器触发、电源过压保护、方波发生、模数转换的前端， 全都要靠它。

路线：本质 → 单限 → 限幅 → 滞回 → 窗口 → 集成器件。

一、比较器的本质：只回答"谁大"

把运放的两个输入端当成两个"秤盘"：u_+ > u_− 时输出冲向正饱和， u_+ < u_− 时输出冲向负饱和。因为开环增益 A_od 有十万倍， 输入端只要差几十微伏，输出就已经撞到电源轨了。所以：

u_+ − u_− > 0　⟹　u_o = +U_OM　；　u_+ − u_− < 0　⟹　u_o = −U_OM
  • 输出只有两态，+U_OM 与 −U_OM 通常比电源低 1~2 V； 若输出加稳压管限幅，则变成干净的 ±U_Z。
  • 虚短失效：两个输入端不再等电位，差模电压可以很大（毫伏到伏级）。
  • 虚断仍成立：输入端几乎不取电流，列节点方程时照样可以当开路。
  • 翻转发生在 u_+ = u_− 的那一瞬间，这个输入电压就叫门限（阈值）U_T。
一条判据分清"放大器"还是"比较器" 看反馈极性：输出经电阻回到反相端是负反馈 → 线性放大（虚短成立）； 回到同相端是正反馈 → 滞回比较器（虚短失效）； 什么都不接是开环 → 单限比较器（虚短失效）。

1.1 比较器与运放的四个区别

项目集成运放集成比较器（LM339/LM311）

最后一行最容易考：OC 输出只能拉低、不能拉高， 所以电路图上一定有一个从输出接到 +V 的上拉电阻 R。 把它接到 +5 V 而器件用 ±15 V 供电，输出就是 0/5 V 的逻辑电平—— 这就是比较器能直接驱动数字电路的原因。

二、单限比较器：一个门限

2.1 过零比较器

最简单的接法：同相端接地，输入接反相端。门限就是 0 V。

输入接反相端，所以结论是"反"的：

u_i > 0　⟹　u_o = −U_Z　；　u_i < 0　⟹　u_o = +U_Z

输入是正弦，输出就是与它反相的方波，过零点处翻转。 如果把输入改接同相端、反相端接地，输出就与输入同相。 这一点在画波形题里是头号失分点，务必先看清输入接的是哪个端。

2.2 任意门限比较器

实际电路很少需要"过零"，更多是"到 3.2 V 就报警"。做法是在反相端用两个电阻 把 u_i 和参考电压 U_REF 加起来，同相端接地。

设反相端节点电压为 u_−，对节点列 KCL（虚断，流入运放的电流为零）：

(u_i − u_−)/R_1 + (U_REF − u_−)/R_2 = 0

翻转发生在 u_− = u_+ = 0 的时刻，代入 u_− = 0：

u_i/R_1 + U_REF/R_2 = 0　⟹　U_T = −(R_1 / R_2) · U_REF

这个式子的读法是：门限 = 参考电压被两个电阻"反向缩放"。 负号来自"参考电压加在反相端"——U_REF 为正时，门限反而是负的。 想把门限调正，要么把 U_REF 取负，要么把参考电压改接同相端。

另一种常见接法（分压型） 若把 R_2 从 U_REF 接到同相端、R_1 从同相端接地、 输入仍接反相端，则 u_+ = U_REF · R_1/(R_1+R_2)，门限为 U_T = +U_REF · R_1/(R_1+R_2)。两种接法都考，认准门限就是让 u_+ = u_− 的那个 u_i， 现场列方程最稳，不要背结论。

【例 1】任意门限比较器求门限与占空比

题：图 30-3 中 R_1 = 10 kΩ，R_2 = 20 kΩ，U_REF = −3 V， 输出限幅 ±U_Z = ±6 V。输入 u_i = 4 sin ωt (V)。 求门限 U_T，并估算输出高电平的占空比。

第一步：求门限

U_T = −(R_1/R_2)·U_REF = −(10/20)×(−3 V) = +1.5 V

第二步：判断输出极性。输入接反相端，故 u_i < 1.5 V 时 u_o = +6 V，u_i > 1.5 V 时 u_o = −6 V。

第三步：占空比。正弦超过 1.5 V 的角度区间由 sin θ = 1.5/4 = 0.375 给出，θ_1 = 22.0°， 超过门限的区间为 22.0° ~ 158.0°，占 136°/360° ≈ 37.8%。 但这段区间输出是低电平，所以高电平占空比为

1 − 37.8% ≈ 62.2%
为什么要算占空比 单限比较器把正弦变成方波时，门限决定占空比。 门限取 0 才是 50%；门限偏离 0，方波就"偏"。 这个结论在 0031 的方波发生器里会反过来用：想让占空比可调，就改门限或改充放电时间常数。

三、输出限幅：把两态变成干净的 ±U_Z

运放输出的 ±U_OM 随电源和负载变化，不是一个可靠的电平。工程上在输出端 并一只双向稳压管（两只稳压管背靠背，或一只稳压管串一只普通二极管）， 把输出钳在 ±U_Z：

  • 输出为正时，一只稳压管反向击穿，电压被钳在 +U_Z；
  • 输出为负时，另一只（或同一只反向）击穿，钳在 −U_Z；
  • 必须串限流电阻（图 30-1 中省略了，实际应串在运放输出与稳压管之间）， 否则运放输出电流会超过稳压管的功耗极限；
  • U_Z 必须小于 U_OM，否则稳压管不起作用——这一步要验算。
|U_Z| < U_OM　（否则限幅失效，输出仍是 ±U_OM）

限幅之后，比较器的输出电平就是"设计值"了：±6 V、±5 V、 甚至 0/5 V（配合 OC 输出上拉）。后面所有门限公式里的 U_Z 都指这个限幅值，不再提 U_OM。

四、滞回比较器：把"抖"变成"稳"

单限比较器有个致命弱点：输入在门限附近有噪声时，输出会跟着噪声来回翻转多次。 解决办法是引入正反馈，让门限"跟着输出走"——输出翻上去，门限也跟着抬高； 想翻回来，输入必须降得更多。这就是滞回比较器，也叫施密特触发器。

4.1 两个门限怎么算

先看同相端：R_2 接输出、R_1 接地，两个电阻串联在 u_o 与地之间，同相端取分压。虚断，所以 u_+ 直接由分压公式给出：

u_+ = u_o · R_1 / (R_1 + R_2)

输出只有 ±U_Z 两态，于是同相端也只有两个值，这就是两个门限：

U_T+ = +U_Z · R_1/(R_1+R_2)　　U_T− = −U_Z · R_1/(R_1+R_2)
ΔU = U_T+ − U_T− = 2 · U_Z · R_1/(R_1+R_2)

ΔU 叫回差（滞回宽度）。翻转条件仍然是 u_i = u_+， 但 u_+ 自己会随输出变化，所以"上升时的门限"和"下降时的门限"不是同一个值。

读图的顺序必须记死：

  1. 当前输出为 −U_Z（下方支路），u_i 一路下降， 直到 u_i = U_T− 才跳到 +U_Z；
  2. 跳上去以后门限立刻变成 U_T+，u_i 必须升回 U_T+ 才跳回 −U_Z。
方向别画反（阅卷必看） 传输特性是一条顺时针走的矩形环：上方支路从左边走到 U_T+， 竖直向下跳到 −U_Z；下方支路从右边向左走到 U_T−， 竖直向上跳回 +U_Z。 箭头一定画在"上升沿向上、下降沿向下"的方向上。写错方向，整道题的波形就全反了。

【例 2】滞回比较器的门限、回差与输出波形

题：图 30-4 中 R_1 = 10 kΩ，R_2 = 20 kΩ，U_Z = 6 V， u_i = 3 sin ωt (V)，设 t = 0 时输出为 +6 V。 求两个门限、回差，并说明输出在什么相位翻转。

第一步：门限

R_1/(R_1+R_2) = 10/30 = 1/3
U_T+ = +6 × 1/3 = +2 V　　U_T− = −6 × 1/3 = −2 V

第二步：回差

ΔU = 2 − (−2) = 4 V

第三步：翻转时刻。t = 0 时输出 +6 V，门限为 U_T− = −2 V， 输入从 0 开始上升，还不到门限，输出保持 +6 V；

  • u_i 升到 +2 V 时（θ = arcsin(2/3) = 41.8°）跳到 −6 V；
  • 跳变后门限变成 −2 V，u_i 回落到 −2 V 时 （θ = 180° + 41.8° = 221.8°）跳回 +6 V。

所以输出是一个正半周短、负半周长的方波：高电平只占 180° − 2×41.8° = 96.4°，占空比约 26.8%。 这正是"回差把占空比掰歪"的直观结果——只有当 u_i 的幅度远大于门限时， 方波才接近对称。

验算小技巧 门限必须满足 |U_T| < U_im（输入峰值），否则输入根本够不到门限，输出永不翻转。 本例 2 V < 3 V ✅。如果题目给 u_i = 1.5 sin ωt，输出就一直是 +6 V， 这是"电路不翻转"的常见考法。

五、窗口比较器：判断"在不在区间里"

有些场合要判断的不是"大于某个值"，而是"是否落在 [U_RL, U_RH] 之间"， 比如电池电压正常区间检测。用两只比较器 + 两只二极管构成"线与"逻辑：

A_1 检测上限：u_i 接反相端、U_RH 接同相端， u_i < U_RH 时输出高。A_2 检测下限：u_i 接同相端、 U_RL 接反相端，u_i > U_RL 时输出高。 两只二极管阳极接公共点、阴极接各比较器输出，公共点经 R 上拉到 +V：

输入范围A_1 输出A_2 输出二极管u_o
u_i > U_RH低高D_1 导通，公共点被拉低低
U_RL < u_i < U_RH高高都截止高（上拉）
u_i < U_RL高低D_2 导通，公共点被拉低低

所以窗口内输出高、窗口外输出低，这就是"区间判别器"。

【例 3】窗口比较器判别

题：图 30-6 中 U_RH = 4 V，U_RL = 1 V，比较器输出高电平 +5 V、低电平 0 V。分别求 u_i = 2.5 V、5 V、0.5 V 时的输出。

  1. u_i = 2.5 V：1 < 2.5 < 4，落在窗口内。 A_1 输出高（2.5 < 4），A_2 输出高（2.5 > 1）， 两只二极管都截止，u_o 被 R 上拉到 +5 V。
  2. u_i = 5 V：5 > 4，A_1 输出低， D_1 导通把公共点拉低，u_o = 0 V。
  3. u_i = 0.5 V：0.5 < 1，A_2 输出低， D_2 导通，u_o = 0 V。

注意二极管在这里不是整流，而是"线与"逻辑门：任一比较器输出低， 就能把公共点拉低。若把两只二极管反过来接，逻辑就变成"窗口内低、窗口外高"， 读题时务必看清二极管方向。

六、集成比较器：LM339 与 LM311

LM339 是四比较器（一片四个），LM311 是单比较器。 两者的共同点：集电极开路输出、无需相位补偿、响应快、可单电源工作。

参数LM339LM311
比较器数量41
输出级集电极开路（OC）集电极开路 / 发射极开路可选
响应时间约 1.3 μs约 200 ns
电源单电源 2~36 V 或双电源 ±18 V单电源 5~30 V 或双电源 ±15 V
典型用途电平检测、窗口判别、多路报警高速触发、脉冲整形
  • OC 输出必须上拉：R 取 1~10 kΩ。阻值越大越省电，但上升沿越慢 （t_r ≈ 2.2RC，C 含分布电容）。
  • 输出电平可独立设定：上拉接到 +5 V，即使器件由 ±15 V 供电， 输出也是 0/5 V，能直接接 TTL/CMOS。
  • 输出可以并联：多个 OC 输出直接连在一起就是"线与"， 任一为低则整条线为低——这就是"报警汇总"的硬件实现。
  • 输入共模范围含地（LM339 可低到 0 V），所以单电源下检测接近 0 V 的信号没问题； 但输入电压不能超过电源范围，否则会损坏。
为什么比较器不接负反馈 一旦接了负反馈，虚短成立，输出就被"拉"到线性区，跟着输入连续变化——那就不再是比较器了。 比较器要的就是"要么撞上轨、要么撞下轨"的两态，所以只接开环或正反馈。 另外，比较器内部不做相位补偿，接成负反馈极易自激。

七、判断与画波形的通用流程

考场上遇到比较器题，固定按这四步走，几乎不会错：

  1. 定门限：找出"使 u_+ = u_−"的 u_i。 单限比较器是一个值，滞回是两个值，窗口也是两个值。
  2. 定极性：u_i 接反相端则输出与"输入高于门限"反相； 接同相端则同相。这一步决定波形是"正着"还是"反着"。
  3. 定初始状态：画波形前先问"t = 0 时输出是什么"。 滞回比较器必须知道初始态才能确定用哪个门限。
  4. 逐段画：输入穿过门限就跳变，其余时间输出保持。跳变是竖直的， 不允许画成斜线。

【例 4】给定输入波形，画滞回比较器的输出

题：滞回比较器 U_T+ = +2 V，U_T− = −2 V，U_Z = ±6 V， 输入为三角波：0 → +4 V → −4 V → 0 线性变化。设初始输出为 +6 V。 画出输出波形并说明各段电平。

解：按"初始态 → 用对应门限 → 穿越才翻转"的顺序逐段推。

输入段当前输出有效门限是否穿越输出变化
0 → +4 V（上升）+6 VU_T+ = +2 V在 +2 V 处穿越+6 V → −6 V
+4 V → −4 V（下降）−6 VU_T− = −2 V在 −2 V 处穿越−6 V → +6 V
−4 V → 0（上升）+6 VU_T+ = +2 V未到 +2 V保持 +6 V

输出是一个"高—低—高"的矩形波：在输入第一次升到 +2 V 时下降，降到 −2 V 时上升， 最后一段因为输入最高只回到 0 V，够不到 +2 V，所以输出停在高电平不再翻转。 这个"回差导致末段不翻转"的细节，是区分"真懂"和"背公式"的关键。

八、易错点与速查表

六个高频错误

  1. 把输入接的端看反。反相端输入 → 输出与"高于门限"相反。画波形前先在图上标 + / −。
  2. 滞回比较器只记一个门限。它是两个门限，且"用哪个"由当前输出决定，必须跟踪状态。
  3. 回差算成 U_Z·R_1/(R_1+R_2)。那是单边门限，回差要乘 2。
  4. 忘记验算限幅是否有效。U_Z > U_OM 时稳压管不起作用，输出仍是 ±U_OM。
  5. 给比较器加负反馈。加了就不是比较器；判断"能否工作"的题常在这里设坑。
  6. OC 输出忘记上拉。没有上拉电阻，输出高电平是"悬空"，不是高电平。

九、Quiz — 考研风格题

4 道题覆盖本质、门限、回差与集成器件。先算再点，解析会告诉你错在哪一步。

这一课学到了什么

  1. 比较器 = 开环或正反馈的运放：输出两态，虚短失效、虚断仍成立。
  2. 门限就是 u_+ = u_− 的那个 u_i：现场列 KCL 比背公式可靠， U_T = −(R_1/R_2)U_REF 只是一个特例。
  3. 限幅让电平可控：双向稳压管把 ±U_OM 变成 ±U_Z，前提是 U_Z < U_OM。
  4. 正反馈产生回差：U_T± = ±U_Z R_1/(R_1+R_2)，回差 ΔU 换取抗干扰能力。
  5. 窗口比较器 = 两个单限 + 线与门：判断"在不在区间内"，输出是高/低两态之一。

下一课（Lesson 0031）把这套东西用起来：在滞回比较器的反相端接一个 RC， 让电容电压自己来回撞门限，就不再需要外部输入了——那是方波发生器。 本课的两个门限公式，正是下一课周期公式的分子。
