Lesson 0024 — 基本运算电路

模拟电子电路 · Lesson 0024 / 0026 · 约 55 分钟

前置知识 必须掌握 Lesson 0019（运放基础） 与 Lesson 0020（运放应用与振荡）。 尤其是：理想运放的 A_od → ∞、R_id → ∞、R_o → 0； 负反馈条件下 u₊ ≈ u₋；反相输入端在负反馈时是"虚地"。 这一课把这些结论变成一台"模拟计算机"：加减乘除、积分微分，全部由电阻、电容和运放搭出来。

1940 年代，模拟计算机用运放做微分方程的实时求解；今天，基本运算电路依然是传感器调理、 滤波器、PID 控制器和波形发生器的骨架。它们的共同点是：用负反馈把运放的闭环特性 交给外部无源网络决定。只要网络是线性的，闭环就是线性的；网络换成二极管， 闭环就变成对数；网络换成乘法器，闭环就能开方。

本课只做一件事：把"虚短 + 虚断"这两条规则，反复用到六种最基本的电路上， 直到你看到任何运放电路都能在三十秒内写出传输关系。

一、两把钥匙：虚短与虚断

1.1 从理想运放推出"虚短"

运放的开环传输是 u_o = A_od (u₊ − u₋)。理想运放 A_od → ∞， 而输出电压 u_o 被电源钳在有限范围（比如 ±12 V）。两边同时取极限：

u₊ − u₋ = u_o / A_od → 0　　⟹　　u₊ = u₋

两个输入端电位相等，但并没有用导线连起来，所以叫虚短。 注意"虚短"不是"短路"：短路后电流可以随便流，虚短时输入端之间仍然没有电流。

1.2 "虚断"

理想运放的输入电阻 R_id → ∞，所以 i₊ = i₋ = 0。输入端像断开一样，叫虚断。 虚断不是说外部没有电流，而是说流进运放输入端的电流为零， 因此外部节点仍然可以列 KCL。

1.3 虚地：虚短的特例

当同相端直接接地 u₊ = 0 时，由虚短得 u₋ = 0。 反相端电位被"钉"在零伏，但它并没有接地，叫虚地。 虚地只对反相输入、同相端接地、且存在负反馈的电路成立—— 这三个条件缺一不可，考试最喜欢在"同相端不接地"或"正反馈"上设坑。

四步分析法（本课通用）
  1. 确认负反馈：输出到反相端有通路，且闭环能稳定。没有负反馈，虚短不成立。
  2. 写虚短：u₋ = u₊；若同相端接地，直接写 u₋ = 0（虚地）。
  3. 写虚断：对反相节点列 KCL，流入运放的电流记为零。
  4. 解出 u_o：把所有电流用节点电压表示，整理成 u_o = f(u_i)。

1.4 为什么必须先判断负反馈

虚短来自 u_o = A(u₊ − u₋) 的极限，而这个极限只有在闭环稳定时才成立。 如果电路是正反馈（输出接到同相端），运放会一路冲到饱和，u₊ = u₋ 被打破， 此时只能用比较器的思路分析：输出非高即低。这是下一类"非线性应用"的入口， 本课的六个电路全部是负反馈，可以放心用虚短。

二、反相比例运算电路

这是所有运算电路的"母题"。输入 u_i 经 R₁ 接到反相端， 同相端接地，反馈电阻 R_f 从输出接回反相端。

2.1 推导

同相端接地，所以 u₊ = 0；由虚短 u₋ = 0，反相端是虚地。 对反相节点列 KCL（流出节点为正）：

(u₋ − u_i)/R₁ + (u₋ − u_o)/R_f = 0

代入 u₋ = 0：

−u_i/R₁ − u_o/R_f = 0　　⟹　　u_o = −(R_f/R₁) u_i

负号来自电流方向：输入为正时，电流只能从输入经 R₁ 流入虚地， 再经 R_f 从虚地流向输出，输出必须为负才能"吸"走这股电流。

2.2 三个关键参数

参数表达式物理意义
闭环增益A_u = −R_f/R₁只由外部电阻比决定，与运放本身无关
输入电阻R_in = R₁信号源看到的负载就是 R₁，不能靠增大 R_f 提高
输出电阻R_o ≈ 0电压源特性，带负载不跌
共模输入u_ic = 0两端都在 0 V 附近，对运放共模抑制要求最低

平衡电阻：实际运放有输入偏置电流 I_B。为了让两端看到的直流电阻相等， 在同相端串一只 R₂ = R₁ ∥ R_f。这样 I_B 在两端产生的压降相同， 被共模抑制掉。忽略它不会让电路不工作，但会让输出多一个几毫伏到几十毫伏的直流失调。

例 1：反相比例电路计算

电路如上图，R₁ = 10 kΩ，R_f = 100 kΩ，输入 u_i = −0.5 V， 运放电源 ±12 V。求输出电压、输入电流和输入电阻，并判断运放是否饱和。

第一步：列式

A_u = −R_f/R₁ = −100k/10k = −10

第二步：代入

u_o = A_u · u_i = (−10) × (−0.5 V) = +5 V

第三步：输入电流

i_i = (u_i − 0)/R₁ = −0.5 V / 10 kΩ = −50 μA

负号表示电流实际从虚地流向信号源（信号源在"吸收"电流），这与 u_i < 0 一致。

第四步：输入电阻与饱和判断

R_in = R₁ = 10 kΩ　；　|u_o| = 5 V < 12 V

物理意义：增益 10 倍、反相，输出 5 V 在电源轨内，运放工作在线性区， 虚短假设成立。若把 u_i 加到 −1.3 V，理论输出 +13 V 超过电源， 实际会被钳在约 +11 V，波形削顶——此时虚短失效，不能再套公式。

反相比例的"代价" 增益想做大，要么增大 R_f，要么减小 R₁。 增大 R_f 受限于电阻精度与漏电流；减小 R₁ 会直接压低输入电阻， 加重信号源负担。这就是高输入阻抗场合必须改用同相比例的原因。

三、同相比例运算电路与电压跟随器

把输入信号接到同相端，反馈网络仍然挂在反相端：R₁ 从反相端接地， R_f 从输出接回反相端。此时反相端不再是虚地，而是虚短到 u_i。

3.1 推导

由虚断，反相端没有电流流入运放；R₁ 与 R_f 串联分压， 但分压比由节点电压决定。先写虚短：

u₋ = u₊ = u_i

对反相节点列 KCL：

(u_i − 0)/R₁ + (u_i − u_o)/R_f = 0

整理：

u_i/R₁ + u_i/R_f = u_o/R_f　　⟹　　u_o = (1 + R_f/R₁) u_i

增益恒大于 1，且同相。当 R_f = 0（输出直接接反相端） 或 R₁ = ∞（反相端只接反馈、不接地）时，A_u = 1， 这就是电压跟随器。

3.2 同相比例的两大特点

  • 输入电阻极高：信号直接进运放同相端，输入电阻就是运放的共模输入电阻， 可达 10⁸～10¹² Ω。适合高内阻传感器（压电片、pH 电极、光电二极管跨阻前置）。
  • 存在共模电压：两端同时等于 u_i，运放必须承受与输入等幅的共模信号。 反相比例没有这个问题。共模抑制比不够高时，同相比例会引入共模误差。

平衡电阻接在反相端与地之间时，应取 R₁ ∥ R_f？不对——同相比例中， 反相端看到的直流电阻是 R₁ ∥ R_f，而同相端看到的是信号源内阻。 若信号源内阻为 R_s，则应在同相端串 R_s' = R₁ ∥ R_f − R_s 来平衡， 实际设计里常直接取 R_s' = R₁ ∥ R_f 并接受微小失配。

3.3 电压跟随器：最被低估的电路

跟随器 A_u = 1，看起来"什么都没做"，但它完成了两件电阻做不到的事：

  1. 阻抗变换：输入阻抗极高、输出阻抗极低，把高内阻信号源"隔离"开， 后级负载再重也不会把信号拉垮。
  2. 单向隔离：输出电流由运放电源提供，信号源只出"信息"不出"功率"。

例：一个 R_s = 1 MΩ 的传感器直接接 10 kΩ 负载，分压后只剩 10k/(1M+10k) ≈ 1% 的信号。加一级跟随器后，传感器几乎空载， 负载得到接近 100% 的电压。这就是"缓冲"的量化含义。

四、反相加法运算电路

多个输入各自经电阻接到同一个虚地节点，反馈电阻共用。因为虚地电位固定， 各路输入电流互不影响，可以直接代数相加——这是"模拟求和"的物理基础。

4.1 推导

反相端是虚地 u₋ = 0（同相端经平衡电阻接地，仍为 0）。 对虚地节点列 KCL，各输入电流分别为 u₁/R₁、u₂/R₂，反馈电流为 −u_o/R_f：

u₁/R₁ + u₂/R₂ + … + u_n/R_n + u_o/R_f = 0
u_o = −R_f (u₁/R₁ + u₂/R₂ + … + u_n/R_n)

每一项的系数是 −R_f/R_k，可以独立设计。若取 R₁ = R₂ = … = R_n = R，则 u_o = −(R_f/R)(u₁ + u₂ + … + u_n)， 变成纯加法器。

例 2：加法电路计算

R₁ = 10 kΩ，R₂ = 20 kΩ，R_f = 100 kΩ， u₁ = 0.2 V，u₂ = 0.3 V。求 u_o，并说明各路对输出的贡献。

第一步：列式

u_o = −(R_f/R₁ · u₁ + R_f/R₂ · u₂)

第二步：算权重

R_f/R₁ = 100/10 = 10　；　R_f/R₂ = 100/20 = 5

第三步：代入

u_o = −(10 × 0.2 + 5 × 0.3) = −(2.0 + 1.5) = −3.5 V

第四步：验算电流与饱和

i₁ = 0.2/10k = 20 μA　；　i₂ = 0.3/20k = 15 μA　；　i_f = 35 μA
u_o = −i_f · R_f = −35 μA × 100 kΩ = −3.5 V ✓

|−3.5 V| < 12 V，线性区。物理意义：两路电流在虚地节点代数相加， 权重由各自的输入电阻决定；R₂ 是 R₁ 的两倍， 所以 u₂ 的权重只有 u₁ 的一半。

平衡电阻 反相加法器的同相端应接 R₂' = R₁ ∥ R₂ ∥ … ∥ R_n ∥ R_f。 本例 10k ∥ 20k ∥ 100k ≈ 6.25 kΩ。 忽略它只影响直流失调，不影响交流增益。

五、同相加法电路及其缺点

同相加法把多路信号先"并"在同相端，再用同相比例放大。它能保持高输入电阻， 但代价是共模电压大、各路相互影响。

设各路经 R₁、R₂、… 接到同相节点，同相节点再经 R₃ 接地， 反馈仍是 R_f、R₁'（为避免符号冲突，这里把反馈下臂记作 R_a）。 由虚断，同相节点列 KCL：

(u₊ − u₁)/R₁ + (u₊ − u₂)/R₂ + u₊/R₃ = 0

解出 u₊：

u₊ = (u₁/R₁ + u₂/R₂) / (1/R₁ + 1/R₂ + 1/R₃)

再经同相比例放大：

u_o = (1 + R_f/R_a) · u₊

如果取 R₁ = R₂ = R 且 R₃ = R/2，分母变成 2/R + 2/R = 4/R，u₊ = (u₁ + u₂)/4， 再取 1 + R_f/R_a = 4，就得到 u_o = u₁ + u₂。 系数设计比反相加法麻烦得多。

5.1 三个硬伤

  1. 共模电压大：u₊ 是各路输入的加权平均， 运放两端都工作在这个共模电平上。共模抑制比不足时，输出会出现共模误差； 输入幅度大时还可能超出运放的共模输入范围。
  2. 输入电阻不高：每路看到的不是无穷大，而是 R_k + (其余电阻的并联)。想提高增益就得改 R_f/R_a， 想改权重又要动 R_k，两者耦合。
  3. 各路相互影响：改变一路的电阻会改变同相节点的等效阻抗， 从而改变其他路的权重。反相加法因为虚地电位固定，没有这个问题。

结论：需要求和时优先用反相加法；只有在"信号源内阻极高、不能承受 R₁ 负载"且共模范围允许时，才考虑同相加法（或先用跟随器缓冲，再做反相加法）。

比较项反相加法同相加法
权重−R_f/R_k，各路独立与所有电阻耦合
输入电阻R_k（较低）较高，但非无穷
共模电压≈ 0≈ 输入加权平均（大）
调整难度低高
典型用途求和、DAC、混音高阻多路信号合成

六、减法（差分）运算电路

减法电路要同时用到反相输入和同相输入：u₁ 经 R₁ 进反相端， u₂ 经 R₂、R₃ 分压后进同相端，R_f 从输出接回反相端。

6.1 用叠加定理推导

令 u₂ = 0，先看 u₁ 的作用。同相端经 R₂ 接地、 R₃ 接地，所以 u₊ = 0，反相端虚地。这就是反相比例：

u_o1 = −(R_f/R₁) u₁

令 u₁ = 0，再看 u₂。此时 R₁ 一端接地， 反相端到地有 R₁，反馈是 R_f；同相端由 R₂、R₃ 分压：

u₊ = [R₃/(R₂ + R₃)] u₂
u_o2 = (1 + R_f/R₁) u₊ = (1 + R_f/R₁) · R₃/(R₂ + R₃) · u₂

叠加：

u_o = (1 + R_f/R₁)·R₃/(R₂+R₃)·u₂ − (R_f/R₁)·u₁

当 R₁ = R₂ 且 R₃ = R_f 时，两个系数都等于 R_f/R₁， 于是：

u_o = (R_f/R₁)(u₂ − u₁)

这个条件不是"随便取"，而是让差模增益与共模增益解耦： 只有电阻严格匹配，共模分量才完全抵消。

例 3：差分电路的差模、共模与失配

R₁ = R₂ = 10 kΩ，R₃ = R_f = 100 kΩ， u₁ = 2.0 V，u₂ = 2.1 V。求输出，并分析电阻失配的影响。

第一步：分解差模与共模

u_id = u₂ − u₁ = 0.1 V　；　u_ic = (u₁ + u₂)/2 = 2.05 V

第二步：理想输出

A_d = R_f/R₁ = 10　；　u_o = 10 × 0.1 = 1.0 V

共模增益 A_c = 0，2.05 V 的共模被完全抑制。

第三步：考虑失配。若 R_f 实际为 101 kΩ，其余不变：

u_o2 = (1 + 10.1) × 100/110 × 2.1 = 11.1 × 0.9091 × 2.1 ≈ 21.19 V
u_o1 = 10.1 × 2.0 = 20.20 V
u_o = 21.19 − 20.20 = 0.99 V

理想值应为 10.1 × 0.1 = 1.01 V，误差约 2%。 把输出拆成差模、共模两部分：

A_d ≈ (10.091 + 10.1)/2 = 10.096　；　A_c ≈ 10.091 − 10.1 = −0.0091
CMRR = |A_d/A_c| ≈ 1100　⟹　20 lg 1100 ≈ 61 dB

物理意义：共模 2.05 V 乘上 −0.0091，贡献约 −18.6 mV， 正好解释了 1.01 → 0.99 V 的偏差。结论：差分电路的共模抑制能力 几乎完全由电阻匹配精度决定，而不是由运放本身的 CMRR 决定。 要 80 dB 以上的 CMRR，必须用 0.1% 电阻或集成仪表放大器。

差分电路的两个局限 输入电阻低：从 u₁、u₂ 看进去约为 2R₁（差模）， 高阻信号源会被拉低；增益调整影响共模抑制：只改 R_f 会破坏 R₃ = R_f 的匹配条件。 解决办法是仪表放大器（三运放结构）：前级两个跟随器提供高输入阻抗，后级一个差分电路做减法， 增益由一只电阻 R_G 调节，且不破坏匹配。

七、积分运算电路

把反相比例的反馈电阻换成电容，输出电压就变成输入电压的积分。它是波形变换、 PID 调节和模拟滤波的核心。

7.1 时域推导

反相端虚地：u₋ = 0。输入电流 i_R = u_i/R 全部流过反馈电容（虚断，运放不取电流）。 电容电流与电压的关系是 i_C = C · d(u₋ − u_o)/dt， 由于 u₋ = 0：

i_C = −C · du_o/dt

由 i_R = i_C：

u_i/R = −C · du_o/dt　　⟹　　du_o/dt = −u_i/(RC)

两边积分：

u_o(t) = u_o(0) − (1/RC) ∫₀ᵗ u_i(τ) dτ

负号是"反相"的体现：正输入使输出向下积分。 RC 叫积分时间常数，量纲是秒；RC 越大， 同样输入下输出变化越慢。

7.2 频域特性

把电容写成阻抗 1/(jωC)，反馈阻抗与输入阻抗之比：

A_u(jω) = −Z_f/Z₁ = −(1/(jωC))/R = −1/(jωRC) = j/(ωRC)
  • 幅频：|A_u| = 1/(ωRC)，频率每升高十倍，增益降为 1/10， 即 −20 dB/十倍频。它本质是一个一阶低通（只是通带在直流处增益无穷大）。
  • 相频：φ = +90°，输出超前输入 90°。 正弦输入 sin ωt 积分后是 −(1/ωRC)cos ωt， 再带上反相符号，正好是超前 90°。
  • 直流增益无穷大：直流输入会被一直积分到饱和。这是积分器最危险的特性， 实际电路必须加复位开关或并联大电阻 R_f 限制直流增益。

7.3 方波变三角波

方波是分段常数。每一段内 u_i = ±U，输出斜率恒定：

du_o/dt = −u_i/(RC) = ∓U/(RC)

所以输出是分段线性的三角波。输入跳变时输出斜率立刻反向，形成尖角； 输入平坦时输出线性变化，形成斜边。这就是"积分器把方波磨成三角波"的全部机理。

例 4：积分器输入方波

R = 10 kΩ，C = 0.1 μF，输入 ±2 V、500 Hz 的方波， t = 0 时 u_o(0) = +1 V。求输出波形及三要素 （斜率、幅值、周期），并验证运放是否饱和。

第一步：时间常数

RC = 10 kΩ × 0.1 μF = 1 × 10³ × 1 × 10⁻⁷ = 1 × 10⁻³ s = 1 ms

第二步：正半周斜率（u_i = +2 V，0～1 ms）

du_o/dt = −u_i/(RC) = −2 V / 1 ms = −2000 V/s = −2 V/ms
u_o(1 ms) = 1 V + (−2 V/ms) × 1 ms = −1 V

第三步：负半周斜率（u_i = −2 V，1～2 ms）

du_o/dt = +2 V/ms　；　u_o(2 ms) = −1 V + 2 V/ms × 1 ms = +1 V

第四步：三要素与饱和判断

要素结果
斜率∓2 V/ms（正输入下降，负输入上升）
幅值±1 V，峰峰值 2 V
周期与输入相同，T = 2 ms（500 Hz）
饱和|u_o| ≤ 1 V ≪ 12 V，线性工作 ✅

物理意义：积分器把"电平"变成"斜率"。输入正得越久，输出降得越低； 输入反向后，输出又以同样速率爬回来。幅度由 U·T/(2RC) 决定： 2 × 2 ms / (2 × 1 ms) = 2 V 峰峰值，正好是 ±1 V。

用基波验算（很漂亮的交叉验证） 方波 ±2 V 的基波幅度为 4U/π = 8/π ≈ 2.55 V； 在 500 Hz 处积分器增益 |A| = 1/(ωRC) = 1/(2π×500×10⁻³) = 0.318； 基波输出幅度 2.55 × 0.318 ≈ 0.81 V。 而 ±1 V 三角波的基波幅度为 8A/π² = 8/π² ≈ 0.81 V，两者一致 ✅ 这说明"方波→三角波"不是近似，而是积分器对每个谐波都做了 1/n 的衰减和 90° 移相。

7.4 工程上的积分器

  • 直流漂移：输入失调电压和偏置电流会被长期积分，几秒到几分钟就撞到电源轨。 解决办法：反馈电容两端并一只大电阻 R_f（如 1 MΩ），把直流增益限制在 −R_f/R，同时几乎不影响高频积分。
  • 复位开关：积分前用模拟开关短接电容，强制 u_o = 0。 ADC 前的双斜积分器就是这样工作的。
  • 频率下限：并 R_f 后，低于 f = 1/(2πR_fC) 时 电路从积分退化为反相比例。设计时要保证工作频段远高于这个转折频率。

八、微分运算电路

把电阻和电容的位置互换：电容串在输入，电阻挂在反馈。输出与输入的变化率成正比。

8.1 推导

反相端虚地。输入电流 i_C = C · d(u_i − 0)/dt = C · du_i/dt； 反馈电流 i_R = (0 − u_o)/R = −u_o/R。由 i_C = i_R：

C · du_i/dt = −u_o/R　　⟹　　u_o = −RC · du_i/dt

频域：

A_u(jω) = −Z_f/Z₁ = −R/(1/(jωC)) = −jωRC

幅值随频率线性上升，相移 −90°。 理想微分器对高频噪声的增益无穷大，这是它不能直接实用的根本原因。

例 5：微分器输入三角波

R = 10 kΩ，C = 0.01 μF，输入 ±1 V、1 kHz 的三角波。 求输出波形与幅度。

第一步：时间常数

RC = 10 kΩ × 0.01 μF = 10⁴ × 10⁻⁸ = 1 × 10⁻⁴ s = 0.1 ms

第二步：输入斜率。三角波周期 T = 1 ms， 从 −1 V 升到 +1 V 用半周期 0.5 ms：

du_i/dt = 2 V / 0.5 ms = 4 V/ms = 4000 V/s

第三步：输出

u_o = −RC · du_i/dt = −0.1 ms × 4000 V/s = −0.4 V

下降沿斜率为 −4 V/ms，输出翻转为 +0.4 V。 所以输出是与输入同频的方波，幅度 ±0.4 V。

第四步：验证

RC = 0.1 ms ≪ T/2 = 0.5 ms ✓

时间常数远小于半周期，电容在半个周期内基本充放完毕，微分近似成立。 若 RC 接近 T/2，输出会变成明显的指数尖峰，不再是方波。

8.2 高频噪声：理想微分器的致命伤

设输入端叠加 10 mV、100 kHz 的开关噪声。微分器对它的增益是：

|A| = ωRC = 2π × 10⁵ × 10⁻⁴ ≈ 62.8
u_o,noise = 62.8 × 10 mV ≈ 0.63 V

10 mV 的噪声被放大成 0.63 V，而真正的 1 kHz 信号只产生 0.4 V 输出—— 噪声比信号还大。这就是"微分器听不见信号，只听见噪声"。

8.3 实用微分器的两处修补

  1. 输入串小电阻 R₁：与 C 串联。 低频时 1/(ωC) ≫ R₁，仍是微分； 高频时 1/(ωC) → 0，输入阻抗趋于 R₁， 增益被限制在 −R_f/R₁。转折频率 f_h = 1/(2πR₁C)。
  2. 反馈并小电容 C_f：与 R_f 并联。 高频时 C_f 容抗下降，进一步压低增益，形成二阶低通， 把噪声"滚"下去。

例：取 R₁ = 1 kΩ，R_f = 10 kΩ，则高频增益上限为 −10，同样的 10 mV 噪声最多产生 0.1 V 输出，而不是 0.63 V。 代价是真正的微分频段被限制在 f < 1/(2πR₁C) ≈ 15.9 kHz。

九、误差来源与选型

9.1 直流误差

理想公式假设 u₊ = u₋ 且输入电流为零。实际运放有：

  • 输入失调电压 U_IO：等效为反相端串了一个小电压源。 反相比例中它被放大 1 + R_f/R₁ 倍？不是——对 U_IO 而言， 电路是"同相放大"，增益为 1 + R_f/R₁。所以高增益电路的输出失调可能达到几十毫伏。
  • 输入偏置电流 I_B：在 R₁ ∥ R_f 上产生压降。 平衡电阻就是为它准备的。
  • 失调电流 I_OS：两端偏置电流之差，平衡电阻也压不住， 只能靠低失调运放或调零。

9.2 交流误差

  • 增益带宽积 GBW：闭环增益 A 与带宽 f_BW 满足 A · f_BW ≈ GBW。要 100 倍增益、100 kHz 带宽，至少选 GBW = 10 MHz 的运放。
  • 压摆率 SR：输出最大变化速度。 正弦输出 U_om sin(2πft) 的最大斜率为 2πfU_om， 必须满足 2πfU_om ≤ SR，否则波形变成三角波。
  • 共模抑制比：同相比例和差分电路要特别关注。

9.3 设计检查清单

  1. 先算 u_o 的理论值，确认在电源轨以内（留 1～2 V 余量）。
  2. 检查输入电阻是否满足信号源要求；不够就加跟随器。
  3. 检查共模电压是否在运放允许范围内（同相比例、差分电路）。
  4. 检查带宽与压摆率：GBW ≥ A·f_max，SR ≥ 2πf_maxU_om。
  5. 积分器加复位或并 R_f；微分器串 R₁、并 C_f。
  6. 差分电路用匹配电阻；要求高 CMRR 时改用仪表放大器。

十一、Quiz — 考研风格题

下面 4 道题覆盖本课六种电路的核心结论，选完立刻能看到解析。

这一课学到了什么

  1. 两条规则打天下：负反馈 → 虚短；理想输入 → 虚断。反相端接地时虚短退化为虚地。
  2. 反相与同相的分工：反相比例输入电阻低、无共模；同相比例输入电阻高、有共模。
  3. 求和优先反相：虚地让各路电流独立相加；同相加法共模大、权重耦合。
  4. 差分靠匹配：R₁=R₂、R₃=R_f 时共模才抵消，CMRR 由电阻精度决定。
  5. 积分与微分是对偶：一个把电平变斜率，一个把斜率变电平；一个怕漂移，一个怕噪声。
