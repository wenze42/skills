Lesson 0020 — 运放应用与正弦波振荡

模拟电子电路 · Lesson 0020 / 0020 · 约 45 分钟

前置知识 需要 Lesson 0019（运放基础与虚短虚断）、 Lesson 0017（深度负反馈与稳定性） 和 Lesson 0014（频率响应）。 这一课要用到反馈、相位和频率三块知识。

运放本身只是增益极大的差分放大器，真正让它无处不在的是外面的电阻电容。 这一课把线性应用（比例、加减、积分、微分）、非线性应用（比较器、方波） 和 RC 桥式振荡串起来，把 Lesson 0017 的“自激”从敌人变成工具。

一、线性应用的总规则：虚短 + 虚断

运放的线性应用有两个前提：负反馈，且输出未饱和。满足后可用两条黄金法则：

虚短：u_+ = u_−　　虚断：i_+ = i_− = 0
  • 虚短：开环增益极大，输出未饱和时两个输入端电压差近似为零。
  • 虚断：输入电阻极大，输入端几乎不取电流，可当成开路。
  • 虚地：同相端接地时 u_+ = 0，于是 u_− ≈ 0，但反相端并没有真的接地。

分析线性运放电路固定三步：①标节点电压；②用虚断列节点 KCL； ③用虚短把未知端电位换成已知量，解出 u_o 与 u_i 的关系。

什么时候不能用 比较器、方波发生器、振荡器工作在非线性区或正反馈状态，输出饱和，虚短失效， 但虚断仍成立。先看有没有负反馈、有没有饱和，再决定能不能用虚短。

二、比例运算电路

2.1 反相比例

反相端是虚地，i_1 = u_i / R_1；虚断保证电流全部流过 R_f，i_f = −u_o / R_f。令 i_1 = i_f：

u_o = −(R_f / R_1) · u_i　　A_u = −R_f / R_1
  • 负号表示反相；|A_u| 只由电阻比决定，与运放本身无关。
  • 反相端虚地，输入电阻等于 R_1（较小），共模电压近似为零。
  • R_2 是平衡电阻，取 R_2 = R_1 ∥ R_f，用来抵消输入偏置电流造成的直流误差。

2.2 同相比例

同相端直接接输入，u_+ = u_i；虚短使 u_− = u_i。R_f 与 R_1 构成分压， 把 u_o 的一部分送回反相端：

u_− = u_o · R_1 / (R_1 + R_f) = u_i　　A_u = 1 + R_f / R_1
  • 输出与输入同相，增益最小为 1，永远不会小于 1。
  • 输入电阻极大，这是同相比例最突出的优点；但共模电压等于 u_i。
  • 令 R_f = 0（或 R_1 → ∞），A_u = 1，就是电压跟随器，常用作缓冲级。

三、加减、积分与微分

3.1 加法与减法

反相加法器：多个输入各经电阻接反相端，虚地使各路电流在节点相加：

u_o = −R_f · (u_i1/R_1 + u_i2/R_2 + u_i3/R_3)

若 R_1 = R_2 = R_3 = R，则 u_o = −(R_f/R)(u_i1 + u_i2 + u_i3)，实现等权加法。 减法（差分）电路用四个电阻，当 R_1 = R_2 = R、R_f = R_3 时：

u_o = (R_f / R) · (u_i2 − u_i1)

减法电路是“同相比例 + 反相比例”的叠加：u_i2 走同相端，u_i1 走反相端。 电阻不匹配会降低共模抑制，所以四个电阻要成对匹配。

3.2 积分与微分

把反馈电阻换成电容就是积分电路。虚地使 i = u_i/R，电流给电容充电，u_o = −u_C：

u_o = −(1 / RC) · ∫ u_i dt + u_o(0)

方波积分得到三角波，正弦波积分得到余弦波——这是波形变换题的标准答案。 实际积分器常在电容两端并联一个大电阻 R_f，防止直流漂移把运放慢慢推到饱和； 但 R_f 会限制低频增益，使极低频信号不再积分。

把电阻和电容位置对调，就得到微分电路：

u_o = −RC · (du_i / dt)

微分对输入的变化率敏感，也把高频噪声放大，所以实际电路常在输入串一个小电阻限制高频增益。 考研里积分、微分主要考“输入什么波形、输出什么波形”和 RC 时间常数，不考复杂推导。

四、非线性应用：比较器与方波发生器

比较器工作在开环或正反馈状态，输出只有两个值：正饱和 +U_om 或负饱和 −U_om； 若输出加稳压管限幅，就是 ±U_Z。此时虚短不成立，但虚断仍成立。

4.1 过零比较器

同相端接地、输入接反相端就是过零比较器：u_i < 0 输出 +U_om，u_i > 0 输出 −U_om。 它只有一个门限 0，零附近有毛刺就会反复翻转，抗干扰能力差。

4.2 滞回比较器

从输出引 R_2 到同相端，再用 R_1 接地，构成正反馈滞回比较器。 输出 ±U_Z 时同相端为 ±U_TH：

±U_TH = ±U_Z · R_1 / (R_1 + R_2)　　回差 ΔU = 2U_Z · R_1 / (R_1 + R_2)

翻转方向：输出 +U_Z 时，u_i 升到上门限 +U_TH 才翻成 −U_Z； 翻过去后门限立刻变成 −U_TH，要等 u_i 降到下门限才翻回。两门限之差就是回差， 它让电路对门限附近的干扰不敏感，代价是精度下降。这就是施密特触发器。

4.3 方波发生器

在滞回比较器反相端接 RC 积分环节，电容电压在 ±U_TH 间充放电，输出周期性翻转， 得到方波发生器。充放电目标为 ±U_Z，时间常数 RC，周期为：

T = 2RC · ln(1 + 2R_1 / R_2)　　f = 1 / T

无外部输入也能持续输出，本质是“带 RC 延迟的滞回比较器”，属张弛振荡器； 与正弦波振荡器只差波形和选频方式，都靠正反馈维持翻转。

比较器 vs 振荡器：有无稳态 比较器有稳态：无输入变化时输出停在 +U_om 或 −U_om，必须等输入越过门限才翻转。 振荡器没有稳态：不需要外部输入，输出自己周期变化。方波发生器把滞回比较器的一个稳态“拆掉”了， 所以它不再是比较器，而是振荡器。

五、RC 桥式正弦波振荡

正弦波振荡器由三部分组成：放大电路（同相比例）、 RC 串并联选频网络（只在 f_0 满足相位条件）、稳幅环节（稳定在 A_F = 1）。

5.1 选频网络的频率特性

RC 串并联网络的反馈系数为：

F = 1 / [3 + j(ωRC − 1/(ωRC))]

当 ω = 1/RC 时虚部为零，F = 1/3，φ_F = 0；同相放大 φ_A = 0，总相移 2nπ，满足相位条件。故：

f_0 = 1 / (2πRC)

5.2 起振与平衡

  • 起振条件：|A_F| > 1。f_0 处 F = 1/3，故 A > 3，即 R_f > 2R_1。
  • 平衡条件：|A_F| = 1 且总相移 2nπ。f_0 处就是 A = 3，即 R_f = 2R_1。
  • 起振略大于 3，稳幅后把 A 拉回 3，输出稳定为等幅正弦波。
怎么稳幅 R_f 用负温度系数热敏电阻：幅度增大 → 电流增大 → 温度升高 → R_f 减小 → A 下降，自动回到 3。 也可把 R_1 换成正温度系数热敏电阻，或用二极管限幅。方向别接反：幅度越大，增益必须越小。

5.3 考研例题

题：RC 桥式振荡电路中 R = 16 kΩ，C = 10 nF，R_1 = 10 kΩ。求 f_0 与 R_f 的范围。

  1. f_0 = 1/(2πRC) = 1/(2π × 16×10³ × 10×10⁻⁹) ≈ 995 Hz ≈ 1 kHz。
  2. 起振要求 A > 3，即 R_f > 2R_1 = 20 kΩ。
  3. 实际取 R_f = 22 kΩ，A = 3.2，略大于 3 保证起振，稳幅后回到 3。
易错点 ① f_0 由选频网络决定，但运放带宽必须覆盖 f_0。 ② 相位条件是总相移 2nπ，不只是“相移为零”。 ③ 起振用 >，平衡用 =。 ④ 振荡器是故意自激，负反馈放大器自激是意外振荡，数学条件相同、设计意图相反。

Quiz — 考研风格题

3 道题分别考比例运算、滞回门限和 RC 振荡器的起振条件。先算再点。

这一课学到了什么

  1. 线性应用三件套：虚短、虚断、节点 KCL，比例/加减/积分/微分都能现场推。
  2. 反相与同相的分界：反相端输入 → 反相比例（虚地、Ri 小）；同相端输入 → 同相比例（Ri 大、有共模）。
  3. 比较器看门限：过零比较器一个门限，滞回比较器两个门限，回差抗干扰。
  4. 振荡器看稳态：比较器有稳态，振荡器无稳态；起振 A_F > 1，平衡 A_F = 1。
  5. RC 桥式的三个数：F = 1/3、A ≥ 3、f_0 = 1/(2πRC)。
