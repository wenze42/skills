Lesson 0011 — 场效应管放大电路

模拟电子电路 · Lesson 0011 / 0035 · 约 40 分钟

前置知识 必须掌握 Lesson 0010（JFET 与 MOSFET） 的平方律 I_D = I_DSS(1 − U_GS/U_P)²、跨导 g_m，以及 Lesson 0007（共射放大电路） 的微变等效分析法。 这一课就是把「共射那一套」原封不动搬到 FET 上，只把 β/r_be 换成 g_m。

FET 是压控器件，栅极几乎不取电流。这带来一个 BJT 没有的便利：偏置电路可以做得极省事， 分压电阻可以取到几百 kΩ 甚至 MΩ，输入电阻随之水涨船高。但它也带来一个新问题： FET 的参数离散性比 β 还大，IDSS、UP 同一型号不同批次能差一倍， 所以偏置电路必须能自动稳定 Q 点。这一课的主角——分压式自偏置共源电路——就是为此而生。

一、FET 放大电路怎么偏置

偏置的目标和 BJT 完全一样：给管子一个合适的静态工作点，让它在恒流区， 并且 Q 点不随器件参数和温度乱跑。常见的三种方案：

方案电路特征UGS 怎么来适用性
固定偏置 栅极经大电阻接电源，源极接地 UGS = 固定值 只适合增强型；Q 点对参数敏感，少用
自偏置 源极串 Rs，栅极经 Rg 接地 UGS = −IDRs（负值） 只适合 JFET / 耗尽型（需要负栅压）
分压式自偏置 Rg1、Rg2 分压 + 源极 Rs UGS = UG − IDRs JFET、耗尽型、增强型都能用；考研主力

为什么分压式能稳定 Q 点？假设温度升高使 ID 增大，则 Rs 上的压降增大， UGS = UG − IDRs 变得更负，反过来把 ID 压回去。 这是直流负反馈，与 BJT 分压偏置中 Re 的作用相同。

二、分压式自偏置共源电路

每个元件都有明确分工，别把它们记成一堆电阻：

  • Rg1、Rg2：分压固定栅极电位 UG；同时它们并联构成输入电阻（栅极不取电流，所以可以取得很大）。
  • Rd：把漏极电流的变化转换成输出电压，决定电压增益；同时提供直流通路。
  • Rs：产生 UGS 的自偏置电压，并提供直流负反馈稳定 Q 点。
  • Cs：把 Rs 在交流上短路，避免交流负反馈把增益压低。没有它，增益要除以 (1+gmRs)。
  • C1、C2：耦合电容，隔直通交，把静态工作点和前后级隔开。

三、直流分析：联立转移特性求 Q

求 Q 点只有四步，顺序不能乱：

四步法
  1. 求 UG：栅极不取电流，分压公式直接成立，U_G = V_DD·R_g2/(R_g1+R_g2)。
  2. 写 UGS：U_GS = U_G − I_D·R_s（源极电流就是 ID）。
  3. 联立平方律：把 UGS 代入 I_D = I_DSS(1 − U_GS/U_P)²，解一元二次方程，按物理意义取舍。
  4. 求 UDS 并校验：U_DS = V_DD − I_D(R_d+R_s)，必须满足 U_DS > U_GS − U_P，否则不在恒流区。

来看一道完整例题。参数：VDD = 20 V，Rg1 = 1.8 MΩ，Rg2 = 200 kΩ， Rd = 5 kΩ，Rs = 2 kΩ，RL = 5 kΩ， IDSS = 8 mA，UP = −4 V。

  1. UG = 20×200/(1800+200) = 2 V。
  2. UGS = 2 − 2ID（ID 用 mA，Rs 用 kΩ，结果就是 V）。
  3. 代入平方律：
    I_D = 8(1 + U_GS/4)² = 8[1 + (2 − 2I_D)/4]² = (6 − 2I_D)² / 2
    整理得 2I_D² − 13I_D + 18 = 0，即 (2I_D − 9)(I_D − 2) = 0， 两个根 ID = 4.5 mA 或 2 mA。
  4. 取舍：若 ID = 4.5 mA，则 UGS = 2 − 9 = −7 V < UP = −4 V， 管子已夹断，不合物理。故 ID = 2 mA，UGS = −2 V。
  5. UDS = 20 − 2×(5+2) = 6 V；校验 6 V > UGS − UP = 2 V ✅ 在恒流区。

解出 Q 点后，跨导立刻可得：

g_m = 2√(I_D · I_DSS) / |U_P| = 2√(2×8)/4 = 2 mS

如果题目给的是增强型 MOS，只是把平方律换成 I_D = I_DO(U_GS/U_GS(th) − 1)²，四步法完全不变。

四、微变等效与动态参数

恒流区内，FET 对交流小信号等效为：栅极开路（ig = 0），漏源之间一个受控电流源 gmugs 并联输出电阻 rds；rds 通常远大于 Rd∥RL，可忽略。

A_u = −g_m(R_d∥R_L)　　R_i = R_g1∥R_g2　　R_o ≈ R_d

把例题数字代进去：Rd∥RL = 5∥5 = 2.5 kΩ， Au = −2 mS × 2.5 kΩ = −5（反相）； Ri = 1.8 MΩ∥200 kΩ = 180 kΩ；Ro ≈ 5 kΩ。

对照共射的 A_u = −βR_L′/r_be，结构完全一样：gm 扮演了 β/rbe 的角色。 但两者的输入电阻差两个数量级——共射只有约 rbe（kΩ 级），共源则是偏置电阻的并联（百 kΩ 以上）。

如果 R_s 没有旁路电容 增益要修正为 A_u = −g_mR_L′/(1 + g_mR_s)，输入电阻不变。 分母的 (1+gmRs) 就是交流负反馈的代价。

五、共漏电路与共射/共源对比

把输出从漏极挪到源极、漏极直接接 VDD（交流地），就是共漏电路， 也叫源极输出器。它和共集（射极跟随器）一一对应：

A_u = g_m(R_s∥R_L) / [1 + g_m(R_s∥R_L)] < 1（同相）　　R_i = R_g1∥R_g2　　R_o = R_s ∥ (1/g_m) ≈ 1/g_m

它就是一个「FET 版射极跟随器」：电压不放大、同相、输入电阻大、输出电阻小（约 1/gm， 几 mS 对应几百 Ω）。用途也完全相同——缓冲级、阻抗变换、驱动低阻负载。 若 gm = 2 mS、Rs∥RL = 2 kΩ，则 Au = 4/5 = 0.8。

对比项共射（BJT）共源（FET）共集（BJT）共漏（FET）
Au −βR_L′/r_be（大） −g_mR_L′（中） ≈1 ≈1（略小于 1）
相位反相反相同相同相
Ri ≈rbe（kΩ 级） Rg1∥Rg2（百 kΩ~MΩ） 大 大（同左）
Ro ≈Rc ≈Rd 小（几十 Ω） 小（≈1/gm）
典型用途 电压放大 高阻输入放大 缓冲、输出级 缓冲、阻抗变换

六、易错点与 Quiz

易错点

  1. 二次方程必须取舍。 两个根里通常有一个使 UGS < UP（已夹断），必须用物理条件排除，不能只看数学解。
  2. UGS = UG − IDRs 不能漏项。 源极电流等于漏极电流，Rs 上的压降就是 IDRs。
  3. Ri 就是 Rg1∥Rg2。 栅极开路，不要再并其他电阻。
  4. Rs 有没有旁路，增益公式不同。 有 Cs 用 −gmRL′；没有则除以 (1+gmRs)。
  5. 共漏电压增益小于 1，但电流、功率增益仍大于 1。
  6. gm(mS) × R(kΩ) 直接得增益，不要乘 10−3。
