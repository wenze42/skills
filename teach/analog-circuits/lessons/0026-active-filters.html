Lesson 0026 — 有源滤波电路

模拟电子电路 · Lesson 0026 / 0026 · 约 60 分钟

前置知识 本课是第 7 章的收尾。需要 Lesson 0024 的虚短虚断与积分器，以及 Lesson 0017（频率响应与波特图） 的 −20 dB/十倍频、−3 dB 截止频率概念。 如果波特图还看不熟，先回去把一阶 RC 的幅频曲线画三遍。

无源 RC 滤波器便宜，但有三个硬伤：带负载后截止频率漂移、 通带内有衰减、不能级联（后级会加载前级）。 把 RC 网络放进运放的负反馈环，运放的低输出阻抗和高输入阻抗把这三个问题一次解决， 这就是有源滤波器。

本课从四种基本类型出发，先做一阶，再做二阶压控电压源（Sallen-Key）结构， 最后把阶数、Q 值和衰减斜率串成一张设计表。所有推导仍然只用两招：虚短、虚断。

一、四种基本滤波类型

按通带位置分四类：

类型英文通带阻带典型用途
低通LPFf < f_pf > f_p抗混叠、去高频噪声、积分
高通HPFf > f_pf < f_p隔直、去工频干扰、交流耦合
带通BPFf_L < f < f_H两侧选频、通信中频、振动监测
带阻BRF两侧f_L < f < f_H陷波、50 Hz 工频抑制

1.1 三个关键指标

  • 通带增益 A_up：通带内（远离截止频率）的电压放大倍数。 一阶/二阶低通的通带都在直流处，高通的通带在无穷高处。
  • 截止频率 f_p：幅值下降到 A_up/√2 （即 −3 dB）处的频率。一阶只有一个 f_p； 二阶有两个特征频率，通常用自然频率 f₀ 和品质因数 Q 描述。
  • 过渡带斜率：阻带内幅值随频率下降（或上升）的速率， 单位 dB/十倍频。一阶 ±20 dB/十倍频， 二阶 ±40 dB/十倍频，n 阶 ±20n dB/十倍频。
阶数从哪来 每增加一个独立的储能元件（一个电容），传递函数就多一个极点，阶数加一， 过渡带就陡 20 dB/十倍频。 一阶只有一个电容；二阶有两个电容；四阶有四个。 想要 60 dB/十倍频，就必须三阶——没有例外。

二、一阶低通有源滤波器

最简单的有源低通：R 串联、C 并联到地，后面接一级同相跟随器。 跟随器的输入电阻极高，所以 RC 节点几乎不被后级加载， 截止频率严格等于 1/(2πRC)。

2.1 推导

设 RC 节点电压为 u_A，跟随器使 u_o = u_A。 对节点 A 列 KCL（运放输入不取电流）：

(u_A − u_i)/R + u_A · jωC = 0

整理：

u_A (1 + jωRC) = u_i　　⟹　　u_o/u_i = 1/(1 + jωRC)

令 ω_p = 1/(RC)，即 f_p = 1/(2πRC)：

A_u = 1/(1 + j f/f_p)

幅频与相频：

|A_u| = 1/√(1 + (f/f_p)²)　；　φ = −arctan(f/f_p)
  • f ≪ f_p：|A_u| ≈ 1，相移≈0，信号原样通过；
  • f = f_p：|A_u| = 1/√2 = 0.707（−3 dB），相移 −45°；
  • f ≫ f_p：|A_u| ≈ f_p/f，每升高十倍频下降十倍，即 −20 dB/十倍频，相移趋于 −90°。

如果要在通带内放大，把跟随器换成同相比例，增益为 A_up = 1 + R_f/R₁，传递函数变成 A_u = A_up/(1 + jf/f_p)。注意：增益不改变截止频率， 只把整条曲线上下平移。这是因为反馈网络只放大 u_A，没有改变 RC 的时间常数。

2.2 幅频特性

例 1：设计 f_p = 1 kHz 的一阶低通

要求 f_p = 1 kHz，通带增益 A_up = 2。 选择 C = 10 nF，求 R、反馈电阻，并计算 10 kHz 处的衰减。

第一步：求 R

R = 1/(2π f_p C) = 1/(2π × 10³ × 10 × 10⁻⁹)
R = 1/(6.283 × 10⁻⁵) ≈ 15.9 kΩ

第二步：取标称值并验算

R = 15.9 kΩ　⟹　f_p = 1/(2π × 15.9k × 10n) ≈ 1.001 kHz ✓

第三步：反馈电阻。同相比例 A_up = 1 + R_f/R₁，取 R₁ = 10 kΩ：

2 = 1 + R_f/10k　⟹　R_f = 10 kΩ

第四步：10 kHz 处的衰减

f/f_p = 10　；　|A_u| = 2/√(1 + 10²) = 2/10.05 = 0.199
20 lg(0.199/2) = 20 lg(0.0995) ≈ −20.1 dB

物理意义：一阶滤波器每升高十倍频，增益降为十分之一。 10 kHz 比截止频率高一个十倍频，所以相对通带衰减 20 dB。 若要把 10 kHz 压到 −40 dB，必须用二阶。

为什么不用无源 RC 无源 RC 接上负载 R_L 后，截止频率变成 1/(2π(R∥R_L)C)，随负载漂移；而且通带本身就有 R_L/(R+R_L) 的衰减。有源滤波器用跟随器隔离， f_p 与负载无关，通带增益还可以大于 1。

三、一阶高通有源滤波器

把 R 和 C 的位置互换：C 串联、R 并联。 低频时电容容抗大，信号被挡住；高频时容抗趋零，信号直通。

3.1 推导

对 RC 节点列 KCL，电容电流为 (u_A − u_i) jωC：

(u_A − u_i) jωC + u_A/R = 0
u_A (jωC + 1/R) = u_i jωC
A_u = u_o/u_i = (jωRC)/(1 + jωRC) = (j f/f_p)/(1 + j f/f_p)

幅频：

|A_u| = (f/f_p)/√(1 + (f/f_p)²)
  • f ≪ f_p：|A_u| ≈ f/f_p，每升高十倍频上升十倍，即 +20 dB/十倍频，相移 +90°；
  • f = f_p：|A_u| = 0.707（−3 dB），相移 +45°；
  • f ≫ f_p：|A_u| ≈ 1，相移趋于 0。

一阶高通的设计步骤与低通完全对称：先定 f_p 和 C， 再算 R = 1/(2π f_p C)。若用同相比例提高通带增益， A_up = 1 + R_f/R₁，不影响 f_p。

四、二阶压控电压源低通滤波器（Sallen-Key）

一阶滤波器的过渡带只有 −20 dB/十倍频，对付强干扰不够。 在 RC 网络里再加一节，并让运放提供增益，就得到二阶 压控电压源（VCVS，Sallen-Key）结构。它只需要一个运放、两只电阻、两只电容， 是有源滤波器里性价比最高的拓扑。

4.1 传递函数推导

设两个 R 相等、两个 C 相等，中间节点为 A， 运放同相端为 B。运放接成同相放大：

u_o = A_up · u_B　，　A_up = 1 + R_f/R₁

对节点 A 列 KCL（C 从 A 接到输出 u_o）：

(u_A − u_i)/R + (u_A − u_B)/R + (u_A − u_o) jωC = 0

对节点 B 列 KCL（C 从 B 接地）：

(u_B − u_A)/R + u_B · jωC = 0

两式联立，消去 u_A、u_B，得到标准二阶低通形式：

A_u(jω) = A_up / [ 1 + jωRC(3 − A_up) + (jωRC)² ]

把它写成标准式：

A_u = A_up / [ 1 − (f/f₀)² + j (1/Q)(f/f₀) ]

对比系数，得到三个设计公式：

f₀ = 1/(2πRC)　；　1/Q = 3 − A_up　；　Q = 1/(3 − A_up)

幅频特性：

|A_u| = A_up / √[ (1 − (f/f₀)²)² + (f/(Q f₀))² ]

4.2 Q 值是二阶滤波器的灵魂

Q 描述"极点离虚轴有多近"，直接决定幅频曲线在 f₀ 附近是 下凹、平坦还是凸起：

QA_up = 3 − 1/Q幅频形状用途
0.51.0两个实极点，临界阻尼，f₀ 处 −6 dB最平坦无峰值，但过渡带最缓
0.7071.586巴特沃斯，最大平坦，f₀ 处 −3 dB通用低通、抗混叠
12.0f₀ 处 0 dB，峰值 +1.25 dB略提升高频边缘
22.5峰值 +6.3 dB窄带选频、需要陡峭边缘
→∞→3自激振荡不能用于滤波

关键结论：A_up 必须小于 3。当 A_up → 3 时 Q → ∞，极点跑到虚轴上，电路自激；超过 3 则极点进入右半平面， 电路不稳定。设计时通常留 20% 余量，把 A_up 控制在 2.5 以下。

例 2：Sallen-Key 二阶低通的参数

取 R = 10 kΩ，C = 16 nF，R₁ = 10 kΩ，R_f = 5.86 kΩ。 求 f₀、A_up、Q，并判断是否为巴特沃斯响应。

第一步：f₀

f₀ = 1/(2πRC) = 1/(2π × 10k × 16n)
f₀ = 1/(1.005 × 10⁻³) ≈ 995 Hz

第二步：A_up

A_up = 1 + R_f/R₁ = 1 + 5.86/10 = 1.586

第三步：Q

Q = 1/(3 − A_up) = 1/(3 − 1.586) = 1/1.414 = 0.707

第四步：判断

Q = 0.707 = 1/√2，正是巴特沃斯（最大平坦）响应。 f = f₀ 处：

|A_u| = A_up · Q = 1.586 × 0.707 = 1.121 = A_up/√2

正好是 −3 dB，且通带内没有峰值。这就是"截止频率处恰好 −3 dB"的由来。

例 3：给定 A_up = 2，求 Q 与峰值

其余参数不变，只把 R_f 调到 10 kΩ，使 A_up = 2。 求 Q、峰值频率、峰值幅度。

第一步：Q

Q = 1/(3 − 2) = 1

第二步：峰值频率。对幅频公式求极值，令 d|A_u|/d(f/f₀) = 0：

f_pk = f₀ √(1 − 1/(2Q²)) = f₀ √(1 − 0.5) = 0.707 f₀

第三步：峰值幅度

|A_u|max = A_up · Q / √(1 − 1/(4Q²)) = 2 × 1 / √(0.75) = 2.309
相对通带：2.309/2 = 1.1547　⟹　20 lg 1.1547 = +1.25 dB

物理意义：Q = 1 时曲线在 0.707f₀ 处鼓起 1.25 dB，然后才下降到 −3 dB。如果输入信号含有该频率附近的成分， 会被轻微放大。对多数抗混叠应用，1.25 dB 的凸起可以接受； 对增益平坦度要求高的测量电路，应选 Q = 0.707。

对照：A_up = 2.5 时 Q = 2，峰值 2.5 × 2/√(1 − 1/16) ≈ 5.16，相对提升 6.3 dB， 已经非常尖锐；再往上就逼近自激。

五、二阶高通、带通与带阻

5.1 二阶高通：电容电阻互换

把 Sallen-Key 低通里的两只 R 换成 C、两只 C 换成 R，就得到二阶高通。传递函数变成

A_u = A_up (j f/f₀)² / [ 1 − (f/f₀)² + j (1/Q)(f/f₀) ]

f₀、Q、A_up 的公式完全不变： f₀ = 1/(2πRC)，Q = 1/(3 − A_up)。 低频段以 +40 dB/十倍频 上升，高频段平坦。

5.2 带通：低通 + 高通级联

把高通和低通串联，让高通的 f_L 远低于低通的 f_H， 中间就形成通带。总增益是两级增益之积：

A_up = A_up1 · A_up2

中心频率与带宽：

f₀ = √(f_L · f_H)　；　BW = f_H − f_L　；　Q = f₀/BW

例：f_L = 300 Hz，f_H = 3 kHz，则 f₀ = √(300 × 3000) ≈ 949 Hz， BW = 2700 Hz，Q ≈ 0.35。 两级级联的过渡带更陡：低端 +20 dB/十倍频，高端 −20 dB/十倍频；若每级都用二阶，则两侧各 ±40 dB/十倍频。

级联的加载问题 无源 RC 级联时，后级输入阻抗会加载前级，导致 f_L、f_H 都偏移。 有源滤波器每级都有运放缓冲，输出阻抗接近零，才能按公式直接相乘。 这就是"有源"最实际的价值。

5.3 带阻：双 T 网络

带阻（陷波）最经典的实现是双 T 网络：两个 T 型网络并联， 一个由两只 R 和一只 C 组成，另一个由两只 C 和一只 R 组成。在中心频率

f₀ = 1/(2πRC)

两条支路的信号大小相等、相位相反，互相抵消，输出出现很深的陷波。 把双 T 网络接在运放的反馈里，并用同相放大提供少量正反馈， 可以提高 Q、加深陷波。无源双 T 的 Q 只有 0.25， 加入正反馈后可做到 5～50。

陷波深度受元件匹配限制：电阻、电容只要有 1% 失配，凹陷就不再是"无穷深"。 50 Hz 工频陷波器通常需要 0.1% 的 RC 匹配， 或者用开关电容/数字滤波方案。

例 4：某频率处的衰减

二阶巴特沃斯低通（Q = 0.707，A_up = 1.586），f₀ = 1 kHz。 求 2 kHz 和 10 kHz 处相对通带的衰减，并与一阶比较。

第一步：2 kHz，f/f₀ = 2

|A_u|/A_up = 1/√[ (1 − 2²)² + (2/0.707)² ]
= 1/√[ (−3)² + (2.828)² ] = 1/√(9 + 8) = 1/√17
= 0.2425　⟹　20 lg 0.2425 = −12.3 dB

第二步：10 kHz，f/f₀ = 10

|A_u|/A_up = 1/√[ (1 − 100)² + (10/0.707)² ]
= 1/√(9801 + 200) = 1/√10001 ≈ 0.01
20 lg 0.01 = −40 dB

第三步：与一阶比较

频率一阶衰减二阶巴特沃斯衰减
2 kHz−7.0 dB−12.3 dB
10 kHz−20.0 dB−40.0 dB

物理意义：二阶在 2f₀ 处只比一阶多衰减 5.3 dB， 但在 10f₀ 处多衰减 20 dB。阶数的优势要在远离 f₀ 的阻带才充分体现。如果干扰频率紧贴截止频率， 单纯提高阶数不如先把 f₀ 挪近干扰源。

六、设计流程与工程陷阱

6.1 五步设计法

  1. 定指标：通带增益 A_up、截止频率 f_p（或 f₀）、 阻带衰减要求、过渡带宽度。
  2. 定阶数：根据衰减斜率选 n。例如要求 10f_p 处 −40 dB，一阶只有 −20 dB，必须二阶。
  3. 选电容：先取一个标称电容（如 10 nF、16 nF、100 nF）， 再算电阻。电容比电阻更难凑，先定电容更容易落到标称值。
  4. 算电阻与增益：一阶 R = 1/(2πf_pC)； 二阶 f₀ = 1/(2πRC)，Q = 1/(3 − A_up)， A_up = 1 + R_f/R₁。
  5. 验算：检查 A_up < 3、运放带宽、压摆率、 电容耐压与温漂，并用实际标称值重算 f₀。

6.2 常见陷阱

  • A_up 太接近 3：Q 对 A_up 极其敏感。 A_up = 2.9 时 Q = 10，元件误差 1% 就可能让 Q 翻倍甚至自激。设计值不要超过 2.5。
  • 把跟随器当万能缓冲：Sallen-Key 的 C 从中间节点接输出， 运放输出阻抗在高频下不是零，会引入相位滞后，可能导致峰值偏高。 高频应用要选高带宽、低输出阻抗的运放。
  • 忽略运放带宽：运放的闭环带宽必须远高于 f₀， 否则实际 Q 和 f₀ 都会偏移。经验值：GBW ≥ 20 f₀。
  • 电容介质选错：陶瓷 Y5V 的容量随电压、温度变化可达 50%， 会直接把 f₀ 拉走。滤波电容优先 C0G/NP0 或薄膜电容。
  • 二阶高通直接套低通公式：f₀、Q 公式相同，但 A_up 对 Q 的影响方向不变，仍要 A_up < 3。

九、Quiz — 考研风格题

下面 4 道题覆盖一阶、二阶、稳定性与斜率四个高频考点。

这一课学到了什么

  1. 四种类型一张图：低通、高通、带通、带阻，靠通带位置区分；指标是 A_up、f_p、斜率。
  2. 一阶靠 RC：f_p = 1/(2πRC)，过渡带 −20 dB/十倍频； 运放只负责缓冲和增益，不改变 f_p。
  3. 二阶靠 Q：Sallen-Key 的 Q = 1/(3−A_up)， A_up < 3 是稳定底线；Q = 0.707 是巴特沃斯。
  4. 阶数决定斜率：n 阶 = ±20n dB/十倍频， 但优势只在远离 f₀ 的阻带体现。
  5. 有源的价值是隔离：输入阻抗高、输出阻抗低，f_p 不随负载漂移，才能级联。

到这里，第 7 章"信号的运算和处理"完整闭环： 0024 用线性网络做加减积分，0025 用非线性网络做对数指数与乘法，0026 用复数网络做频率选择。 三条路都从同一个起点出发——负反馈 + 虚短虚断。 下一章进入波形发生与信号转换，这套分析工具仍然不会过时。
