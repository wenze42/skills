受控源：把“放大”变成一道电路题

三极管不是电阻，运放也不是魔法。它们之所以能用电路方程算，是因为都被等效成了同一种东西：受控源。这一课只做一件事——让你看到“放大”两个字时，脑子里出现的是一张可计算的电路。

本课服务于 能独立分析放大电路的静态工作点、输入输出电阻与增益

练习进度 一次答对 0 / 7
01

先解决一个矛盾

你学过戴维南、叠加、节点法，它们都假设电路里只有独立源：电压源的值是 5 V 就是 5 V，电流源的值是 2 mA 就是 2 mA，不受别人影响。

但三极管不是这样。它的集电极电流 iC 由基极电流 iB 控制：iC = βiB。输出端的电流，取决于输入端的一条支路。运放也是：输出电压取决于同相端与反相端之间的电压差。

于是电路理论里补了一种元件：受控源（dependent source，又叫相关源）。它的值由另一条支路的电压或电流控制。它不是独立源，不能自己决定输出；它只是把“器件的行为”翻译成电路语言。教材 §1.1.2（书 p.5 / PDF p.16）

一句话 独立源自己决定自己；受控源由别人决定自己。放大电路的核心，就是把器件换成一个受控源，然后按你熟悉的电路方法去算。

02

四种受控源，一张图认全

只有两个问题：控制量是电压还是电流？输出量是电压还是电流？两两组合，正好四种。

记忆不用背表，先看单位：

系数单位含义直接暴露的类型
AV无量纲电压 / 电压VCVS
gmS（A/V）电流 / 电压VCCS
rmΩ（V/A）电压 / 电流CCVS
Ai无量纲电流 / 电流CCCS

别急着背符号。先问“谁控制谁、输出是什么量”，再写关系式。符号只是关系式的图。教材在 §1.1.2 明确给了四种对应：BJT 的 iC = βiB 是 CCCS；MOS 的 iD 受 vGS 控制，是 VCCS；运放输出与输入电压成线性关系，是 VCVS。书 p.6 / PDF p.17

04

放大器：一个受控源 + 两个电阻

在单向化近似下，一个线性电压放大器可以用三个参数描述：输入端口看进去的电阻 Ri；输出端口的一个受控电压源 AVvi 串联输出电阻 Ro。就这三样。

于是总增益不是 AV，而是三段相乘：

vi = vs · Ri / (Rs + Ri) vo = AVvi · RL / (Ro + RL) A = vo / vs = [Ri/(Rs+Ri)] · AV · [RL/(Ro+RL)] 输入分压 × 本征增益 × 输出分压

这就是“加载效应”。只要信号源有内阻、输出接负载，你测到的增益就不是 AV，而是被 Rs 和 RL 各砍一刀之后的结果。分析放大电路时，先算 Ri、Ro，再谈增益，顺序不能反。

05

练习 B：把数字代进去

05Rs = 1 kΩ，Ri = 9 kΩ，AV = 100，Ro = 1 kΩ，RL = 9 kΩ。总电压增益 A = vo/vs 约为？

想看完整代入过程

输入分压：Ri/(Rs+Ri) = 9/(1+9) = 0.9。
输出分压：RL/(Ro+RL) = 9/(1+9) = 0.9。
总增益：0.9 × 100 × 0.9 = 81。如果忽略输入输出电阻，你会得到 100——高估了 23%。

06判断：输出电阻 Ro 越小，接上负载后电压增益下降越少。

06

一个必须记住的边界

受控源长得很像独立源，但它不能像独立源那样“置零”。求戴维南等效电阻时，独立电压源短路、独立电流源开路；但受控源必须保留，因为它还受电路里的变量控制。正确做法是外加测试源，再求 vt/it。

这条规则在教材 §1.2.3 戴维南定理（书 p.9 / PDF p.20）里出现，也是后面分析放大器输出电阻的关键。下一课会专门练。

07判断：求戴维南等效电阻时，受控源可以像独立源一样直接置零。

07

带走三句话

  1. 受控源的类型 = 控制量（电压/电流）× 输出量（电压/电流）；先看单位，能秒判类型。
  2. 放大器 = Ri + 受控源 AVvi + Ro；真实增益 = 输入分压 × 本征增益 × 输出分压。
  3. 受控源不是独立源：求戴维南等效时不能置零，必须保留控制关系。
